#LC 704 • 7. Searching & Sorting

Binary Search

Easy LeetCode
1. Problem Statement

Given an array of integers nums sorted in ascending order and a target integer target, write a function to search target in nums. Return index if present else -1.

2. Understanding & Key Observations

Eliminate half of the remaining search space on each step in a sorted array.

3. Naive Solution — Brute Force

Scan every element linearly from index 0 to n-1.

class Solution:
    def search(self, nums, target):
        for i, num in enumerate(nums):
            if num == target:
                return i

        return -1

public:

            if (num == target) {
                return i;
            }
        }
        return -1;
    }
};

    public int search(int[] nums, int target) {

            if (num == target) {
                return i;
            }
        }
        return -1;
    }
}
4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(1)
5. Intuition — For Optimization

Use two pointers left and right. Calculate mid = left + (right - left) // 2. If nums[mid] == target return mid, else adjust boundaries.

6. Approach — Step-by-Step Algorithm
  1. Initialize left = 0, right = len(nums) - 1.
  2. Loop while left <= right:
  3. Compute mid = left + (right - left) // 2.
  4. If nums[mid] == target, return mid.
  5. If nums[mid] < target, set left = mid + 1.
  6. Else, set right = mid - 1.
  7. Return -1 if target not found.
7. Optimized Code (Python 3)

                return mid

            else:
                right = mid - 1

        return -1

Search a 2D Matrix

Medium LeetCode
1. Problem Statement

Write an efficient algorithm that searches for a value target in an m x n integer matrix where each row is sorted and the first element of each row is greater than the last of the previous row.

2. Understanding & Key Observations

The entire matrix behaves like one contiguous sorted 1D array of size m * n.

3. Naive Solution — Brute Force

Nested row and column loops checking every matrix cell.

class Solution:
    def searchMatrix(self, matrix, target):

        for row in matrix:
            for value in row:
                if value == target:
                    return True

        return False

                if (value == target) {
                    return true;

        }
        return false;
    }
};

4. Time & Space Complexity Analysis (Naive)
Time: O(m × n) Space: O(1)
5. Intuition — For Optimization

Treat 2D matrix as a virtual 1D sorted array of length rows * cols. Map 1D index to 2D cell via: row = index // cols, col = index % cols.

6. Approach — Step-by-Step Algorithm
  1. Set left = 0, right = rows * cols - 1.
  2. Loop while left <= right:
  3. Compute mid = left + (right - left) // 2.
  4. Map row = mid // cols, col = mid % cols.
  5. If matrix[row][col] == target, return True.
  6. If matrix[row][col] < target, left = mid + 1; else right = mid - 1.
7. Optimized Code (Python 3)
class Solution:
    def searchMatrix(self, matrix, target):

        rows = len(matrix)
        cols = len(matrix[0])

        left = 0
        right = rows * cols - 1

        while left <= right:
            mid = left + (right - left) // 2

            row = mid // cols
            col = mid % cols

            value = matrix[row][col]

            if value == target:
                return True

            if value < target:
                left = mid + 1
            else:
                right = mid - 1

        return False

Koko Eating Bananas

Medium LeetCode
1. Problem Statement

Koko can decide her eating speed k per hour. Return minimum integer k such that she can eat all bananas within h hours.

2. Understanding & Key Observations

The answer space of speeds $k \in [1, \max(\text{piles})]$ is monotonic: if speed $k$ is valid, all speeds $> k$ are also valid.

3. Naive Solution — Brute Force

Linear search trying every speed $k = 1, 2, 3 \dots \max(\text{piles})$ and checking total hours.

class Solution:
    def minEatingSpeed(self, piles, h):

        for speed in range(1, max(piles) + 1):

            hours = 0

            for pile in piles:
                hours += (
                    pile + speed - 1
                ) // speed

            if hours <= h:
                return speed

        return max(piles)

public:

            hours = 0;
            for (auto pile : piles) {
                hours += (;
                pile + speed - 1;
                ) // speed;
            }
            if (hours <= h) {
                return speed;
            }
        }
        return max(piles);
    }
};

Time: O(n × max(piles)) Space: O(1)
5. Intuition — For Optimization

Binary search on the answer space range $[1, \max(\text{piles})]$. Find the first speed where total hours $\le h$.

6. Approach — Step-by-Step Algorithm
  1. Set left = 1, right = max(piles).
  2. Loop while left <= right:
  3. Set speed = left + (right - left) // 2.
  4. Compute hours = sum((pile + speed - 1) // speed for pile in piles).
  5. If hours <= h: speed is valid! Record answer = speed and try smaller speeds right = speed - 1.
  6. Else: speed is too slow, try faster speeds left = speed + 1.

Find Minimum in Rotated Sorted Array

Medium LeetCode
1. Problem Statement

Given sorted rotated array of unique elements nums, return the minimum element in $O(\log n)$ time.

2. Understanding & Key Observations

The minimum element is the pivot point separating the two sorted halves.

3. Naive Solution — Brute Force

Linear scan keeping track of minimum value.

class Solution:
    def findMin(self, nums):
        answer = nums[0]

        for num in nums:
            answer = min(answer, num)

        return answer
class Solution {
public:
    vector<int> findMin(vector<int>& nums) {
        answer = nums[0];
        for (auto num : nums) {
            answer = min(answer, num);
        }
        return answer;
    }
};
class Solution {
    public List<Integer> findMin(int[] nums) {
        answer = nums[0];
        for (int num : nums) {
            answer = min(answer, num);
        }
        return answer;
    }
}
4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(1)
5. Intuition — For Optimization

Compare nums[mid] against the right boundary nums[right]. If nums[mid] > nums[right], minimum lies in right half; else minimum lies in left half including mid.

6. Approach — Step-by-Step Algorithm
  1. Set left = 0, right = len(nums) - 1.
  2. Loop while left < right:
  3. Compute mid = left + (right - left) // 2.
  4. If nums[mid] > nums[right]: minimum must be in right half left = mid + 1.
  5. Else: minimum could be mid or to the left right = mid.
  6. Return nums[left].
7. Optimized Code (Python 3)

            mid = left + (right - left) // 2

            if nums[mid] > nums[right]:
                left = mid + 1
            else:
                right = mid

        return nums[left]

Medium LeetCode
1. Problem Statement

Given array nums rotated at an unknown pivot and integer target, return index of target or -1 in $O(\log n)$ time.

2. Understanding & Key Observations

At least one half of the array (left or right) is guaranteed to be strictly sorted at any step.

3. Naive Solution — Brute Force

Linear scan checking each element.

class Solution:
    def search(self, nums, target):

        for i, num in enumerate(nums):
            if num == target:
                return i

        return -1

public:

            }
        }

    }
};

                return i;

    }

4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(1)
5. Intuition — For Optimization

Check if nums[left] <= nums[mid]. If True, left half is sorted: check if target is inside [nums[left], nums[mid]). Else right half is sorted: check if target is inside (nums[mid], nums[right]].

6. Approach — Step-by-Step Algorithm
  1. Set left = 0, right = len(nums) - 1.
  2. Loop while left <= right:
  3. If nums[mid] == target, return mid.
  4. If nums[left] <= nums[mid] (Left half sorted):
  5. If nums[left] <= target < nums[mid], move right = mid - 1; else left = mid + 1.
  6. Else (Right half sorted):
  7. If nums[mid] < target <= nums[right], move left = mid + 1; else right = mid - 1.
7. Optimized Code (Python 3)
class Solution:
    def search(self, nums, target):

        right = len(nums) - 1

            mid = left + (right - left) // 2

                return mid

            if nums[left] <= nums[mid]:

                else:
                    left = mid + 1

            # Right half is sorted
            else:

                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1

        return -1

1. Problem Statement

Design a key-value data structure that can store multiple values for the same key at different timestamps and retrieve key value at timestamp_prev <= timestamp.

#LC 4 • 7. Searching & Sorting

Median of Two Sorted Arrays

Hard LeetCode
1. Problem Statement

Given two sorted arrays nums1 and nums2 of size m and n respectively, return the median of the two sorted arrays in $O(\log(m+n))$ time.

2. Understanding & Key Observations

Partition both arrays into equal left and right halves such that $\max(\text{left}_1, \text{left}_2) \le \min(\text{right}_1, \text{right}_2)$.

3. Naive Solution — Brute Force

Merge both sorted arrays into a combined array of size $m+n$ and pick median.

class Solution:
    def findMedianSortedArrays(self, nums1, nums2):

        merged = []

        i = 0
        j = 0

        while i < len(nums1) and j < len(nums2):

            if nums1[i] <= nums2[j]:
                merged.append(nums1[i])
                i += 1
            else:
                merged.append(nums2[j])
                j += 1

        merged.extend(nums1[i:])
        merged.extend(nums2[j:])

        n = len(merged)

        if n % 2:
            return merged[n // 2]

        return (
            merged[n // 2 - 1]
            + merged[n // 2]
        ) / 2

    public int findMedianSortedArrays(int nums1, int nums2) {
        merged = [];
        i = 0;
        j = 0;
        while (i < nums1.length && j < nums2.length) {
            if (nums1[i] <= nums2[j]) {
                merged.add(nums1[i]);
                i += 1;
            }
            else:;
            merged.add(nums2[j]);
            j += 1;
        }
        merged.extend(nums1[i:]);
        merged.extend(nums2[j:]);
        n = merged.length;
        if (n % 2) {
            return merged[n // 2];
        }
        return (;
        merged[n // 2 - 1];
        + merged[n // 2];
        ) / 2;
    }
}

5. Intuition — For Optimization

Binary search partition on the smaller array nums1. Calculate partition indices in both arrays so total left elements equals total right elements.

6. Approach — Step-by-Step Algorithm
  1. Ensure len(nums1) <= len(nums2) (swap if necessary).
  2. Set left = 0, right = len(nums1).
  3. Calculate partition1 = (left + right) // 2 and partition2 = (m + n + 1) // 2 - partition1.
  4. Determine left1, right1, left2, right2 boundary values.
  5. If left1 <= right2 and left2 <= right1: partition is valid!
  6. Return $\max(\text{left}_1, \text{left}_2)$ (if odd total length) or average of max left and min right (if even).
  7. If left1 > right2: move partition left right = partition1 - 1; else move right left = partition1 + 1.

🔥 The 4 Core Binary Search Patterns

Every binary search problem fits into one of these four master templates.

1. Standard Binary Search

Direct lookup in sorted array. Compare mid to target. Eliminate half (LC 704, LC 74).

2. Binary Search on Answer

Search monotonic answer space [Invalid ... Invalid | Valid ... Valid]. Find first valid speed/capacity (LC 875).

3. Rotated Binary Search

Identify which half is sorted, then test if target falls inside sorted range bounds (LC 153, LC 33).

4. Boundary / Partition Search

Search rightmost value $\le$ target (LC 981), or binary search partition point between 2 sorted arrays (LC 4).

  • "Minimum X such that..." / "Maximum X such that...": Binary Search on Answer Space.

  • "Largest value <= target": Rightmost valid element binary search.
  • "Median of 2 Sorted Arrays": Binary search partition on smaller array ($O(\log \min(m, n))$).
