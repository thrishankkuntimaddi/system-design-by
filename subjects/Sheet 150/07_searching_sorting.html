#LC 704 • Searching & Sorting

Binary Search

Easy LeetCode
1. Problem Statement

Given sorted integer array nums and target, return index of target if found, else -1.

2. Understanding & Key Observations

Halve search space each step: compare target with nums[mid].

3. Naive Solution — Basic Approach

Linear scan over array.

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(1)

Linear scan.

5. Intuition — For Optimization

Binary Search algorithm on sorted array.

6. Approach — Step-by-Step Algorithm
  1. Pointers l = 0, r = len(nums) - 1.
  2. While l <= r: m = l + (r - l) // 2. If nums[m] > target r = m - 1; elif nums[m] < target l = m + 1; else return m.
7. Optimized Code (Python 3)
Python 3 Implementation 
def search(nums: list[int], target: int) -> int:
    l, r = 0, len(nums) - 1

    while l <= r:
        m = l + ((r - l) // 2)
        if nums[m] > target:
            r = m - 1
        elif nums[m] < target:
            l = m + 1
        else:
            return m
    return -1
8. Time and Space Complexity Analysis (Optimized)
Time: O(log N) Space: O(1)

Logarithmic binary search.

#LC 74 • Searching & Sorting

Search a 2D Matrix

Medium LeetCode
1. Problem Statement

Search target in m x n matrix where rows are sorted and first integer of row > last of prev row.

2. Understanding & Key Observations

Treat 2D matrix as virtual 1D array of size M * N, mapping mid -> matrix[mid // N][mid % N].

3. Naive Solution — Basic Approach

Binary search row first, then binary search column.

4. Time & Space Complexity Analysis (Naive)
Time: O(log M + log N) Space: O(1)

Two binary searches.

5. Intuition — For Optimization

Virtual 1D array binary search in single pass.

6. Approach — Step-by-Step Algorithm
  1. l = 0, r = M * N - 1.
  2. While l <= r: mid = (l + r) // 2; val = matrix[mid // N][mid % N]. If val == target return True. Adjust l or r.
7. Optimized Code (Python 3)
Python 3 Implementation 
def searchMatrix(matrix: list[list[int]], target: int) -> bool:
    ROWS, COLS = len(matrix), len(matrix[0])

    l, r = 0, ROWS * COLS - 1
    while l <= r:
        m = (l + r) // 2
        val = matrix[m // COLS][m % COLS]
        if val > target:
            r = m - 1
        elif val < target:
            l = m + 1
        else:
            return True
    return False
8. Time and Space Complexity Analysis (Optimized)
Time: O(log(M * N)) Space: O(1)

Virtual 1D matrix binary search.

#LC 875 • Searching & Sorting

Koko Eating Bananas

Medium LeetCode
1. Problem Statement

Find minimum eating speed k (bananas/hour) such that Koko can eat all bananas within h hours.

2. Understanding & Key Observations

Binary Search on Answer! Range for k is 1 to max(piles).

3. Naive Solution — Basic Approach

Linear scan for k from 1 up to max(piles).

4. Time & Space Complexity Analysis (Naive)
Time: O(max(P) * N) Space: O(1)

Linear search.

5. Intuition — For Optimization

Binary search on speed k. Total hours formula: sum(math.ceil(p / k)).

6. Approach — Step-by-Step Algorithm
  1. l = 1, r = max(piles). res = r.
  2. While l <= r: k = (l + r) // 2. Calculate hours needed for speed k. If hours <= h: update res = min(res, k) and search left r = k - 1. Else search right l = k + 1.
7. Optimized Code (Python 3)
Python 3 Implementation 
import math

def minEatingSpeed(piles: list[int], h: int) -> int:
    l, r = 1, max(piles)
    res = r

    while l <= r:
        k = (l + r) // 2
        totalTime = 0
        for p in piles:
            totalTime += math.ceil(p / k)
        if totalTime <= h:
            res = min(res, k)
            r = k - 1
        else:
            l = k + 1
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N log(max(P))) Space: O(1)

Binary search on solution space.

#LC 153 • Searching & Sorting

Find Minimum in Rotated Sorted Array

Medium LeetCode
1. Problem Statement

Given rotated sorted array of unique elements, find minimum element in O(log n) time.

2. Understanding & Key Observations

If nums[m] >= nums[l], left portion is sorted, so min MUST be in right portion!

3. Naive Solution — Basic Approach

Linear scan min().

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(1)

Linear search.

5. Intuition — For Optimization

Binary Search checking which half is sorted.

6. Approach — Step-by-Step Algorithm
  1. l = 0, r = len(nums) - 1, res = nums[0].
  2. While l <= r: if nums[l] < nums[r]: res = min(res, nums[l]); break. m = (l + r) // 2. res = min(res, nums[m]). If nums[m] >= nums[l] l = m + 1 else r = m - 1.
7. Optimized Code (Python 3)
Python 3 Implementation 
def findMin(nums: list[int]) -> int:
    res = nums[0]
    l, r = 0, len(nums) - 1

    while l <= r:
        if nums[l] < nums[r]:
            res = min(res, nums[l])
            break
            
        m = (l + r) // 2
        res = min(res, nums[m])
        if nums[m] >= nums[l]:
            l = m + 1
        else:
            r = m - 1
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(log N) Space: O(1)

Binary search on rotated array.

#LC 33 • Searching & Sorting

Search in Rotated Sorted Array

Medium LeetCode
1. Problem Statement

Given rotated sorted array nums and target, return index of target or -1.

2. Understanding & Key Observations

Determine which half (left or right) is normally sorted, then check if target lies within that half's bounds.

3. Naive Solution — Basic Approach

Linear search.

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(1)

Linear search.

5. Intuition — For Optimization

One side of mid is guaranteed to be strictly sorted.

6. Approach — Step-by-Step Algorithm
  1. l = 0, r = len(nums) - 1.
  2. While l <= r: m = (l + r) // 2. If nums[m] == target return m.
  3. If left half sorted (nums[l] <= nums[m]): if nums[l] <= target < nums[m] r = m - 1 else l = m + 1.
  4. Else (right half sorted): if nums[m] < target <= nums[r] l = m + 1 else r = m - 1.
7. Optimized Code (Python 3)
Python 3 Implementation 
def search(nums: list[int], target: int) -> int:
    l, r = 0, len(nums) - 1

    while l <= r:
        mid = (l + r) // 2
        if target == nums[mid]:
            return mid

        # Left sorted portion
        if nums[l] <= nums[mid]:
            if target > nums[mid] or target < nums[l]:
                l = mid + 1
            else:
                r = mid - 1
        # Right sorted portion
        else:
            if target < nums[mid] or target > nums[r]:
                r = mid - 1
            else:
                l = mid + 1
    return -1
8. Time and Space Complexity Analysis (Optimized)
Time: O(log N) Space: O(1)

Modified Binary Search.

#LC 981 • Searching & Sorting

Time Based Key-Value Store

Medium LeetCode
1. Problem Statement

Design time-based key-value data structure with set(key, val, timestamp) and get(key, timestamp).

2. Understanding & Key Observations

HashMap mapping key -> list of [val, timestamp]. Binary search get call for max prev_timestamp <= timestamp.

3. Naive Solution — Basic Approach

Linear scan timestamps backward.

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(N)

Linear scan on get.

5. Intuition — For Optimization

Binary Search on strictly increasing timestamp list in O(log N) time.

6. Approach — Step-by-Step Algorithm
  1. Dict store = defaultdict(list).
  2. set: append [value, timestamp] to store[key].
  3. get: binary search list for store[key] matching largest timestamp_prev <= timestamp.
7. Optimized Code (Python 3)
Python 3 Implementation 
class TimeMap:
    def __init__(self):
        self.store = {}  # key : list of [val, timestamp]

    def set(self, key: str, value: str, timestamp: int) -> None:
        if key not in self.store:
            self.store[key] = []
        self.store[key].append([value, timestamp])

    def get(self, key: str, timestamp: int) -> str:
        res = ""
        values = self.store.get(key, [])
        l, r = 0, len(values) - 1
        while l <= r:
            m = (l + r) // 2
            if values[m][1] <= timestamp:
                res = values[m][0]
                l = m + 1
            else:
                r = m - 1
        return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(log N) Space: O(N)

Binary search on timestamp array.

#LC 4 • Searching & Sorting

Median of Two Sorted Arrays

Hard LeetCode
1. Problem Statement

Given two sorted arrays nums1 and nums2, return median of combined sorted array in O(log(m+n)) time.

2. Understanding & Key Observations

Binary Search on smaller array A to partition combined elements into equal left and right halves.

3. Naive Solution — Basic Approach

Merge arrays and return median.

4. Time & Space Complexity Analysis (Naive)
Time: O(M + N) Space: O(M + N)

Array merging.

5. Intuition — For Optimization

Binary Search partition index on smaller array A.

6. Approach — Step-by-Step Algorithm
  1. Ensure A is smaller array. total = len(A) + len(B), half = total // 2.
  2. Binary search l = 0, r = len(A) - 1. Partition i = (l + r) // 2, j = half - i - 2.
  3. Check partition bounds: Aleft <= Bright and Bleft <= Aright. If matched return median! Else adjust binary search.
7. Optimized Code (Python 3)
Python 3 Implementation 
def findMedianSortedArrays(nums1: list[int], nums2: list[int]) -> float:
    A, B = nums1, nums2
    total = len(nums1) + len(nums2)
    half = total // 2

    if len(B) < len(A):
        A, B = B, A

    l, r = 0, len(A) - 1
    while True:
        i = (l + r) // 2  # A
        j = half - i - 2  # B

        Aleft = A[i] if i >= 0 else float("-inf")
        Aright = A[i + 1] if (i + 1) < len(A) else float("inf")
        Bleft = B[j] if j >= 0 else float("-inf")
        Bright = B[j + 1] if (j + 1) < len(B) else float("inf")

        # Partition is correct
        if Aleft <= Bright and Bleft <= Aright:
            # Odd total
            if total % 2:
                return min(Aright, Bright)
            # Even total
            return (max(Aleft, Bleft) + min(Aright, Bright)) / 2
        elif Aleft > Bright:
            r = i - 1
        else:
            l = i + 1
8. Time and Space Complexity Analysis (Optimized)
Time: O(log(min(M, N))) Space: O(1)

Binary Search on partition boundary.
