#LC 703 • 5. Heap & Hash

Kth Largest Element in a Stream

Easy LeetCode
1. Problem Statement

Design a class to find the kth largest element in a stream. The stream receives numbers dynamically, and after every insertion we need the kth largest.

2. Understanding & Key Observations

The kth largest element corresponds to the smallest element among the top k largest elements.

3. Naive Solution — Brute Force

Store all incoming numbers in a list and re-sort descending on every add() call.

Naive Solution (Python 3) 
class KthLargest:

    def __init__(self, k, nums):
        self.k = k
        self.nums = nums

    def add(self, val):
        self.nums.append(val)
        self.nums.sort(reverse=True)

        return self.nums[self.k - 1]
4. Time & Space Complexity Analysis (Naive)
Time: O(n log n) per add() Space: O(n)
5. Intuition — For Optimization

Maintain a Min Heap of size exactly k. The root of the Min Heap heap[0] will always be the kth largest element.

6. Approach — Step-by-Step Algorithm
  1. Initialize a min heap with array nums and call heapq.heapify().
  2. Pop elements until size is k.
  3. On add(val): push val into heap.
  4. If heap size exceeds k, pop smallest element.
  5. Return heap[0] in O(1) time.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
import heapq

class KthLargest:

    def __init__(self, k, nums):
        self.k = k
        self.heap = nums

        heapq.heapify(self.heap)

        while len(self.heap) > k:
            heapq.heappop(self.heap)

    def add(self, val):
        heapq.heappush(self.heap, val)

        if len(self.heap) > self.k:
            heapq.heappop(self.heap)

        return self.heap[0]
8. Time and Space Complexity Analysis (Optimized)
Time: O(log k) per add() Space: O(k)
9. Pattern / Key Takeaway

Pattern — Kth largest in stream → Min Heap of size K

#LC 1046 • 5. Heap & Hash

Last Stone Weight

Easy LeetCode
1. Problem Statement

Simulate stone smashing: each step choose the two heaviest stones x and y (with x <= y). If x == y both destroyed, else remaining stone is y - x.

2. Understanding & Key Observations

Repeatedly extract the 2 maximum elements until at most 1 stone remains.

3. Naive Solution — Brute Force

Sort the stones array descending on every iteration and pop the two largest.

Naive Solution (Python 3) 
class Solution:
    def lastStoneWeight(self, stones):

        while len(stones) > 1:
            stones.sort()

            y = stones.pop()
            x = stones.pop()

            if y != x:
                stones.append(y - x)

        return stones[0] if stones else 0
4. Time & Space Complexity Analysis (Naive)
Time: O(n² log n) Space: O(1) aux
5. Intuition — For Optimization

Use a Max Heap. In Python, invert stone weights (negate values) to build a max heap with heapq.

6. Approach — Step-by-Step Algorithm
  1. Convert stones to negative values: heap = [-s for s in stones].
  2. Heapify array in O(n) time.
  3. While len(heap) > 1: pop y and x.
  4. If y != x, push negated difference -(y - x) back into heap.
  5. Return -heap[0] if heap non-empty else 0.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
import heapq

class Solution:
    def lastStoneWeight(self, stones):

        heap = [-stone for stone in stones]
        heapq.heapify(heap)

        while len(heap) > 1:
            y = -heapq.heappop(heap)
            x = -heapq.heappop(heap)

            if y != x:
                heapq.heappush(
                    heap,
                    -(y - x)
                )

        return -heap[0] if heap else 0
8. Time and Space Complexity Analysis (Optimized)
Time: O(n log n) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Repeatedly extract maximum element → Max Heap

#LC 973 • 5. Heap & Hash

K Closest Points to Origin

Medium LeetCode
1. Problem Statement

Given an array of points where points[i] = [xi, yi] and an integer k, return the k closest points to origin (0,0).

2. Understanding & Key Observations

Distance formula $x^2 + y^2$. We don't need square root since relative ordering is identical.

3. Naive Solution — Brute Force

Calculate distance squared for all points and sort array.

Naive Solution (Python 3) 
class Solution:
    def kClosest(self, points, k):

        points.sort(
            key=lambda p: p[0] ** 2 + p[1] ** 2
        )

        return points[:k]
4. Time & Space Complexity Analysis (Naive)
Time: O(n log n) Space: O(n)
5. Intuition — For Optimization

Maintain a Max Heap of size k. The top of the heap is the farthest point among the top k closest, allowing us to drop points with distance greater than current kth closest.

6. Approach — Step-by-Step Algorithm
  1. Iterate through points (x, y).
  2. Compute distance = x * x + y * y.
  3. Push (-distance, x, y) into max heap.
  4. If heap size exceeds k, pop top (farthest point).
  5. Return [[x, y] for _, x, y in heap].
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
import heapq

class Solution:
    def kClosest(self, points, k):

        heap = []

        for x, y in points:
            distance = x * x + y * y

            heapq.heappush(
                heap,
                (-distance, x, y)
            )

            if len(heap) > k:
                heapq.heappop(heap)

        return [
            [x, y]
            for _, x, y in heap
        ]
8. Time and Space Complexity Analysis (Optimized)
Time: O(n log k) Space: O(k)
9. Pattern / Key Takeaway

Pattern — Need K smallest items → Max Heap of size K

#LC 215 • 5. Heap & Hash

Kth Largest Element in an Array

Medium LeetCode
1. Problem Statement

Given an integer array nums and an integer k, return the kth largest element in the array.

2. Understanding & Key Observations

Find element at rank k without sorting the entire array.

3. Naive Solution — Brute Force

Sort array in descending order and return element at index k - 1.

Naive Solution (Python 3) 
class Solution:
    def findKthLargest(self, nums, k):
        nums.sort(reverse=True)

        return nums[k - 1]
4. Time & Space Complexity Analysis (Naive)
Time: O(n log n) Space: O(1) aux
5. Intuition — For Optimization

Min Heap of size k gives $O(n \log k)$ time. Alternatively, Quickselect achieves $O(n)$ average time in $O(1)$ auxiliary space.

6. Approach — Step-by-Step Algorithm
  1. Method 1 (Min Heap): Push elements into min heap of size k. Return heap[0].
  2. Method 2 (Quickselect): Target index target = len(nums) - k.
  3. Partition array around pivot. Recurse only into side containing target index.
  4. Average time: O(n), Worst time: O(n²).
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
import heapq

class Solution:
    def findKthLargest(self, nums, k):

        heap = []

        for num in nums:
            heapq.heappush(heap, num)

            if len(heap) > k:
                heapq.heappop(heap)

        return heap[0]

# --- Alternative: Quickselect O(n) average ---
class SolutionQuickselect:
    def findKthLargest(self, nums, k):

        target = len(nums) - k

        def quickselect(left, right):
            pivot = nums[right]
            partition_index = left

            for i in range(left, right):
                if nums[i] <= pivot:
                    nums[i], nums[partition_index] = nums[partition_index], nums[i]
                    partition_index += 1

            nums[partition_index], nums[right] = nums[right], nums[partition_index]

            if partition_index == target:
                return nums[partition_index]

            if partition_index < target:
                return quickselect(partition_index + 1, right)

            return quickselect(left, partition_index - 1)

        return quickselect(0, len(nums) - 1)
8. Time and Space Complexity Analysis (Optimized)
Heap: O(n log k) | Quickselect: O(n) avg Heap: O(k) | Quickselect: O(1) aux
9. Pattern / Key Takeaway

Pattern — Kth Largest → Min Heap of size K OR Quickselect

#LC 621 • 5. Heap & Hash

Task Scheduler

Medium LeetCode
1. Problem Statement

Given CPU tasks represented by letters and cooldown n between identical tasks, return minimum CPU units of time to finish all tasks.

2. Understanding & Key Observations

Prioritize tasks with highest remaining frequency to minimize idle CPU slots.

3. Naive Solution — Brute Force

Simulate CPU cycles by re-sorting task frequency count every round.

Naive Solution (Python 3) 
from collections import Counter

class Solution:
    def leastInterval(self, tasks, n):

        count = Counter(tasks)
        time = 0

        while count:

            executed = 0

            # Sort by frequency each round
            available = sorted(
                count,
                key=count.get,
                reverse=True
            )

            for task in available[:n + 1]:

                if task in count:
                    count[task] -= 1
                    executed += 1

                    if count[task] == 0:
                        del count[task]

            if count:
                time += n + 1
            else:
                time += executed

        return time
4. Time & Space Complexity Analysis (Naive)
Time: O(T × m log m) Space: O(m)
5. Intuition — For Optimization

Max Heap stores available task frequencies; Dequeue stores tasks in cooldown (freq, available_time).

6. Approach — Step-by-Step Algorithm
  1. Count frequencies using Counter(tasks).
  2. Push negated frequencies into max heap.
  3. Use a queue cooldown = deque() storing (remaining_freq, ready_time).
  4. Increment time. Re-add ready tasks from queue to max heap.
  5. Pop most frequent task, decrement frequency, and push to cooldown queue with ready_time = time + n + 1.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
import heapq
from collections import Counter, deque

class Solution:
    def leastInterval(self, tasks, n):

        count = Counter(tasks)

        heap = [
            -freq
            for freq in count.values()
        ]

        heapq.heapify(heap)

        cooldown = deque()

        time = 0

        while heap or cooldown:
            time += 1

            # Add tasks whose cooldown is over
            while (
                cooldown
                and cooldown[0][1] == time
            ):
                freq, _ = cooldown.popleft()
                heapq.heappush(heap, freq)

            if heap:
                freq = heapq.heappop(heap)
                freq += 1

                if freq != 0:
                    cooldown.append(
                        (freq, time + n + 1)
                    )

        return time
8. Time and Space Complexity Analysis (Optimized)
Time: O(T log m) Space: O(m)
9. Pattern / Key Takeaway

Pattern — Frequency + Max Heap + Cooldown Queue

#LC 355 • 5. Heap & Hash

Design Twitter

Medium LeetCode
1. Problem Statement

Design a simplified Twitter with operations: postTweet(), getNewsFeed() (10 most recent tweets), follow(), unfollow().

2. Understanding & Key Observations

Newsfeed must retrieve the 10 most recent tweets posted by user or anyone they follow.

3. Naive Solution — Brute Force

Gather all tweets from followed users into one list and sort by timestamp.

Naive Solution (Python 3) 
from collections import defaultdict

class Twitter:

    def __init__(self):
        self.time = 0
        self.tweets = defaultdict(list)
        self.following = defaultdict(set)

    def postTweet(self, userId, tweetId):
        self.time += 1

        self.tweets[userId].append(
            (self.time, tweetId)
        )

    def getNewsFeed(self, userId):

        users = self.following[userId] | {userId}

        all_tweets = []

        for user in users:
            all_tweets.extend(
                self.tweets[user]
            )

        all_tweets.sort(
            reverse=True
        )

        return [
            tweet_id
            for _, tweet_id in all_tweets[:10]
        ]

    def follow(self, followerId, followeeId):
        if followerId != followeeId:
            self.following[followerId].add(
                followeeId
            )

    def unfollow(self, followerId, followeeId):
        self.following[followerId].discard(
            followeeId
        )
4. Time & Space Complexity Analysis (Naive)
getNewsFeed: O(T log T) Space: O(T + F)
5. Intuition — For Optimization

K-Way Merge with Heap: each user's tweets are already chronological. Push latest tweet from each followed user into heap, pop top 10.

6. Approach — Step-by-Step Algorithm
  1. Store tweets per user in list self.tweets[userId] = [(time, tweetId)].
  2. For getNewsFeed(userId): collect candidate users following[userId] | {userId}.
  3. Push latest tweet tuple (-time, tweetId, user, index) for each user into heap.
  4. Pop 10 times: append tweetId to result and push previous tweet index - 1 from same user if exists.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
import heapq
from collections import defaultdict

class Twitter:

    def __init__(self):
        self.time = 0
        self.tweets = defaultdict(list)
        self.following = defaultdict(set)

    def postTweet(self, userId, tweetId):
        self.time += 1

        self.tweets[userId].append(
            (self.time, tweetId)
        )

    def follow(self, followerId, followeeId):
        if followerId != followeeId:
            self.following[followerId].add(
                followeeId
            )

    def unfollow(self, followerId, followeeId):
        self.following[followerId].discard(
            followeeId
        )

    def getNewsFeed(self, userId):

        users = self.following[userId] | {userId}

        heap = []

        for user in users:
            tweets = self.tweets[user]

            if tweets:
                index = len(tweets) - 1
                time, tweet_id = tweets[index]

                heapq.heappush(
                    heap,
                    (-time, tweet_id, user, index)
                )

        result = []

        while heap and len(result) < 10:

            _, tweet_id, user, index = (
                heapq.heappop(heap)
            )

            result.append(tweet_id)

            index -= 1

            if index >= 0:
                time, tweet_id = (
                    self.tweets[user][index]
                )

                heapq.heappush(
                    heap,
                    (-time, tweet_id, user, index)
                )

        return result
8. Time and Space Complexity Analysis (Optimized)
getNewsFeed: O(F + 10 log F) Space: O(F)
9. Pattern / Key Takeaway

Pattern — Sorted streams + Top K → K-Way Merge with Heap

#LC 295 • 5. Heap & Hash

Find Median From Data Stream

Hard LeetCode
1. Problem Statement

Design a data structure supporting addNum(num) and findMedian() on continuous stream of integers.

2. Understanding & Key Observations

Median is middle element (odd count) or average of two middle elements (even count).

3. Naive Solution — Brute Force

Append numbers to list and sort array every time findMedian() is called.

Naive Solution (Python 3) 
class MedianFinder:

    def __init__(self):
        self.nums = []

    def addNum(self, num):
        self.nums.append(num)

    def findMedian(self):
        self.nums.sort()

        n = len(self.nums)

        if n % 2:
            return self.nums[n // 2]

        return (
            self.nums[n // 2 - 1]
            + self.nums[n // 2]
        ) / 2
4. Time & Space Complexity Analysis (Naive)
add: O(1), findMedian: O(n log n) Space: O(n)
5. Intuition — For Optimization

Two Heaps Pattern: Max Heap small for smaller half of numbers, Min Heap large for larger half of numbers.

6. Approach — Step-by-Step Algorithm
  1. Maintain small (Max Heap) and large (Min Heap).
  2. Push num into small.
  3. If -small[0] > large[0], move root from small to large.
  4. Rebalance sizes so len(small) == len(large) or len(small) == len(large) + 1.
  5. findMedian() returns -small[0] (if odd) or average of roots (if even) in O(1) time.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
import heapq

class MedianFinder:

    def __init__(self):
        self.small = []  # max heap
        self.large = []  # min heap

    def addNum(self, num):

        heapq.heappush(
            self.small,
            -num
        )

        # Ensure every small <= every large
        if (
            self.small
            and self.large
            and -self.small[0] > self.large[0]
        ):
            value = -heapq.heappop(self.small)

            heapq.heappush(
                self.large,
                value
            )

        # Balance sizes
        if len(self.small) > len(self.large) + 1:
            value = -heapq.heappop(self.small)

            heapq.heappush(
                self.large,
                value
            )

        elif len(self.large) > len(self.small):
            value = heapq.heappop(self.large)

            heapq.heappush(
                self.small,
                -value
            )

    def findMedian(self):

        if len(self.small) > len(self.large):
            return -self.small[0]

        return (
            -self.small[0]
            + self.large[0]
        ) / 2
8. Time and Space Complexity Analysis (Optimized)
add: O(log n), findMedian: O(1) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Dynamic Median → Two Heaps (Max Heap + Min Heap)
