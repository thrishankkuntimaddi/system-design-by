#LC 703 • Heap & Hash

Kth Largest Element in a Stream

Easy LeetCode
1. Problem Statement

Design a class to find k-th largest element in a stream.

2. Understanding & Key Observations

Maintain a min-heap of size k. The root of the min-heap (minHeap[0]) is always the k-th largest element overall.

3. Naive Solution — Basic Approach

Sort full array on every new element stream insertion.

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(N)

Sorting takes N log N per add.

5. Intuition — For Optimization

Min-heap of fixed size K gives O(log K) insertion time.

6. Approach — Step-by-Step Algorithm
  1. Min-heap minHeap initialized with nums.
  2. Heapify minHeap. While len(minHeap) > k: heappop(minHeap).
  3. add(val): heappush(minHeap, val). If len(minHeap) > k: heappop(minHeap). Return minHeap[0].
7. Optimized Code (Python 3)
Python 3 Implementation 
import heapq

class KthLargest:
    def __init__(self, k: int, nums: list[int]):
        self.minHeap, self.k = nums, k
        heapq.heapify(self.minHeap)
        while len(self.minHeap) > k:
            heapq.heappop(self.minHeap)

    def add(self, val: int) -> int:
        heapq.heappush(self.minHeap, val)
        if len(self.minHeap) > self.k:
            heapq.heappop(self.minHeap)
        return self.minHeap[0]
8. Time and Space Complexity Analysis (Optimized)
Time: O(log K) Space: O(K)

Min-heap size capped at K.

#LC 1046 • Heap & Hash

Last Stone Weight

Easy LeetCode
1. Problem Statement

Smash heaviest 2 stones together until 1 or 0 stones remain. Return weight of last stone or 0.

2. Understanding & Key Observations

Max-Heap repeatedly yields 2 largest stones: y and x. If x != y, push y - x back.

3. Naive Solution — Basic Approach

Sort array repeatedly after every collision.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2 log N) Space: O(1)

Repeated sorting.

5. Intuition — For Optimization

Max-Heap (negated values in Python min-heap) supports O(log N) pops.

6. Approach — Step-by-Step Algorithm
  1. Negate all weights: stones = [-s for s in stones]. Heapify.
  2. While len(stones) > 1: first = -heappop(); second = -heappop(). If first != second: heappush(stones, -(first - second)).
  3. Return -stones[0] if stones else 0.
7. Optimized Code (Python 3)
Python 3 Implementation 
import heapq

def lastStoneWeight(stones: list[int]) -> int:
    stones = [-s for s in stones]
    heapq.heapify(stones)

    while len(stones) > 1:
        first = heapq.heappop(stones)
        second = heapq.heappop(stones)
        if second > first:
            heapq.heappush(stones, first - second)

    stones.append(0)
    return abs(stones[0])
8. Time and Space Complexity Analysis (Optimized)
Time: O(N log N) Space: O(N)

Max-heap simulation.

#LC 973 • Heap & Hash

K Closest Points to Origin

Medium LeetCode
1. Problem Statement

Given array of points, return k closest points to origin (0,0).

2. Understanding & Key Observations

Distance metric: x^2 + y^2 (no need for sqrt).

3. Naive Solution — Basic Approach

Sort all points by Euclidean distance.

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(N)

Full array sorting.

5. Intuition — For Optimization

Max-Heap of size K or QuickSelect algorithm achieves linear time.

6. Approach — Step-by-Step Algorithm
  1. Min-heap: store tuples (x^2 + y^2, x, y).
  2. Heapify in O(N). Pop top K elements.
7. Optimized Code (Python 3)
Python 3 Implementation 
import heapq

def kClosest(points: list[list[int]], k: int) -> list[list[int]]:
    minHeap = []
    for x, y in points:
        dist = (x ** 2) + (y ** 2)
        minHeap.append([dist, x, y])
        
    heapq.heapify(minHeap)
    res = []
    for _ in range(k):
        dist, x, y = heapq.heappop(minHeap)
        res.append([x, y])
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(K log N) Space: O(N)

Heapify takes O(N), K pops take O(K log N).

#LC 215 • Heap & Hash

Kth Largest Element in an Array

Medium LeetCode
1. Problem Statement

Return k-th largest element in unsorted array without full sorting.

2. Understanding & Key Observations

QuickSelect algorithm (partitioning around pivot) gives O(N) average time.

3. Naive Solution — Basic Approach

Sort array and return nums[len(nums)-k].

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(1)

Full sorting overhead.

5. Intuition — For Optimization

Min-heap of size K keeps K largest elements at O(N log K) time, or QuickSelect in O(N) average.

6. Approach — Step-by-Step Algorithm
  1. Target index k = len(nums) - k.
  2. QuickSelect partition function: place pivot in correct sorted position.
  3. If pivot index == target return nums[p]. Else recurse left or right.
7. Optimized Code (Python 3)
Python 3 Implementation 
def findKthLargest(nums: list[int], k: int) -> int:
    k = len(nums) - k

    def quickSelect(l, r):
        pivot, p = nums[r], l
        for i in range(l, r):
            if nums[i] <= pivot:
                nums[p], nums[i] = nums[i], nums[p]
                p += 1
        nums[p], nums[r] = nums[r], nums[p]

        if p > k: return quickSelect(l, p - 1)
        elif p < k: return quickSelect(p + 1, r)
        else: return nums[p]

    return quickSelect(0, len(nums) - 1)
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Avg Space: O(1)

QuickSelect algorithm average runtime.

#LC 621 • Heap & Hash

Task Scheduler

Medium LeetCode
1. Problem Statement

Given CPU tasks and cooldown interval n, return minimum units of time to complete all tasks.

2. Understanding & Key Observations

Greedy choice: process highest frequency tasks first. Max-Heap + Queue tracks cooling tasks.

3. Naive Solution — Basic Approach

Simulate CPU cycles step by step checking full task map.

4. Time & Space Complexity Analysis (Naive)
Time: O(Time) Space: O(26)

Simulates idle cycles.

5. Intuition — For Optimization

Formula OR Max-Heap + Deque storing (cnt, idleTime).

6. Approach — Step-by-Step Algorithm
  1. Count task frequencies. Max-Heap maxHeap = [-cnt for cnt in count.values()].
  2. Queue q = deque() storing (cnt, availableTime).
  3. Loop time += 1: pop from heap, decrement cnt. If cnt > 0, push (cnt, time + n) to q. If q[0] == time, push back to heap.
7. Optimized Code (Python 3)
Python 3 Implementation 
import heapq
from collections import Counter, deque

def leastInterval(tasks: list[str], n: int) -> int:
    count = Counter(tasks)
    maxHeap = [-cnt for cnt in count.values()]
    heapq.heapify(maxHeap)

    time = 0
    q = deque()  # pairs of [-cnt, idleTime]

    while maxHeap or q:
        time += 1
        if maxHeap:
            cnt = 1 + heapq.heappop(maxHeap)
            if cnt != 0:
                q.append([cnt, time + n])
        if q and q[0][1] == time:
            heapq.heappush(maxHeap, q.popleft()[0])

    return time
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(26)

N is number of tasks. Max-heap operations bounded by 26 letters.

#LC 355 • Heap & Hash

Design Twitter

Medium LeetCode
1. Problem Statement

Design simplified Twitter with postTweet, getNewsFeed (10 most recent), follow, unfollow.

2. Understanding & Key Observations

Each user follows a set of users. Feed merges sorted lists of tweets from followees using Max-Heap.

3. Naive Solution — Basic Approach

Collect all tweets into array, sort by timestamp.

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(N)

Sorting all user tweets.

5. Intuition — For Optimization

Min/Max-heap merges K most recent tweets from followees like Merge K Lists.

6. Approach — Step-by-Step Algorithm
  1. HashMaps: tweetMap = defaultdict(list) (userId -> [(count, tweetId)]), followMap = defaultdict(set).
  2. getNewsFeed(userId): add self to follow set. Min-heap pops 10 most recent tweets.
7. Optimized Code (Python 3)
Python 3 Implementation 
import heapq
from collections import defaultdict

class Twitter:
    def __init__(self):
        self.count = 0
        self.tweetMap = defaultdict(list)  # userId -> list of [count, tweetIds]
        self.followMap = defaultdict(set)  # userId -> set of followeeId

    def postTweet(self, userId: int, tweetId: int) -> None:
        self.tweetMap[userId].append([self.count, tweetId])
        self.count -= 1

    def getNewsFeed(self, userId: int) -> list[int]:
        res = []
        minHeap = []
        self.followMap[userId].add(userId)

        for followeeId in self.followMap[userId]:
            if followeeId in self.tweetMap:
                index = len(self.tweetMap[followeeId]) - 1
                count, tweetId = self.tweetMap[followeeId][index]
                minHeap.append([count, tweetId, followeeId, index - 1])

        heapq.heapify(minHeap)
        while minHeap and len(res) < 10:
            count, tweetId, followeeId, index = heapq.heappop(minHeap)
            res.append(tweetId)
            if index >= 0:
                count, tweetId = self.tweetMap[followeeId][index]
                heapq.heappush(minHeap, [count, tweetId, followeeId, index - 1])
        return res

    def follow(self, followerId: int, followeeId: int) -> None:
        self.followMap[followerId].add(followeeId)

    def unfollow(self, followerId: int, followeeId: int) -> None:
        if followeeId in self.followMap[followerId]:
            self.followMap[followerId].remove(followeeId)
8. Time and Space Complexity Analysis (Optimized)
Time: O(10 log K) Space: O(Users + Tweets)

K is followees count.

#LC 295 • Heap & Hash

Find Median From Data Stream

Hard LeetCode
1. Problem Statement

Design data structure supporting addNum(num) and findMedian() in streaming data.

2. Understanding & Key Observations

Two heaps: Max-Heap small for lower half, Min-Heap large for upper half.

3. Naive Solution — Basic Approach

Maintain sorted array using binary search insertion.

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(N)

Array shifting takes O(N) per add.

5. Intuition — For Optimization

Two Heaps maintain equal size balance (diff <= 1). Median is heap tops!

6. Approach — Step-by-Step Algorithm
  1. addNum(num): push to small (max-heap). If small[0] > large[0], pop and push to large. Rebalance sizes so abs(len(small) - len(large)) <= 1.
  2. findMedian(): if odd size return top of larger heap; else average of both tops.
7. Optimized Code (Python 3)
Python 3 Implementation 
import heapq

class MedianFinder:
    def __init__(self):
        self.small = []  # Max-heap (lower half)
        self.large = []  # Min-heap (upper half)

    def addNum(self, num: int) -> None:
        heapq.heappush(self.small, -num)

        # Make sure every element in small <= every element in large
        if self.small and self.large and (-self.small[0]) > self.large[0]:
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)

        # Handle size imbalance
        if len(self.small) > len(self.large) + 1:
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)
        if len(self.large) > len(self.small) + 1:
            val = heapq.heappop(self.large)
            heapq.heappush(self.small, -val)

    def findMedian(self) -> float:
        if len(self.small) > len(self.large):
            return -self.small[0]
        if len(self.large) > len(self.small):
            return self.large[0]
        return (-self.small[0] + self.large[0]) / 2.0
8. Time and Space Complexity Analysis (Optimized)
Time: O(log N) Space: O(N)

Two-heap streaming median algorithm.
