#LC 20 • 6. Stack & Queue

Valid Parentheses

Easy LeetCode
1. Problem Statement

Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

2. Understanding & Key Observations

Brackets must close in exact LIFO (last-in, first-out) order.

3. Naive Solution — Brute Force

Repeatedly scan string and remove matching adjacent pairs '()', '[]', '{}' using string replacement.

Naive Solution (Python 3) 
class Solution:
    def isValid(self, s):
        changed = True

        while changed:
            changed = False

            for pair in ["()", "[]", "{}"]:
                if pair in s:
                    s = s.replace(pair, "")
                    changed = True

        return len(s) == 0
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(n)
5. Intuition — For Optimization

Push opening brackets onto a stack. When encountering a closing bracket, pop the stack top and verify it matches the expected opening pair.

6. Approach — Step-by-Step Algorithm
  1. Use empty list stack and dictionary pairs = {')': '(', ']': '[', '}': '{'}.
  2. For each char: if opening bracket '([{', push to stack.
  3. Else (closing bracket): return False if stack is empty or stack.pop() != pairs[char].
  4. Return True if stack is completely empty at the end.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def isValid(self, s):
        stack = []

        pairs = {
            ")": "(",
            "]": "[",
            "}": "{"
        }

        for char in s:
            if char in "([{":
                stack.append(char)

            else:
                if not stack:
                    return False

                if stack.pop() != pairs[char]:
                    return False

        return not stack
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Opening bracket → push; Closing bracket → pop & compare with stack top

#LC 155 • 6. Stack & Queue

Min Stack

Medium LeetCode
1. Problem Statement

Design a stack that supports push, pop, top, and retrieving the minimum element getMin in O(1) time.

2. Understanding & Key Observations

All 4 operations must execute in constant time $O(1)$.

3. Naive Solution — Brute Force

Use a normal stack and compute min(self.stack) dynamically inside getMin().

Naive Solution (Python 3) 
class MinStack:

    def __init__(self):
        self.stack = []

    def push(self, val):
        self.stack.append(val)

    def pop(self):
        return self.stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return min(self.stack)
4. Time & Space Complexity Analysis (Naive)
getMin: O(n), Others: O(1) Space: O(n)
5. Intuition — For Optimization

Maintain an auxiliary stack minimum that tracks the minimum element at each depth of the stack.

6. Approach — Step-by-Step Algorithm
  1. Maintain main stack and parallel minimum stack.
  2. On push(val): append val to main stack, and append min(val, minimum[-1]) to minimum stack.
  3. On pop(): pop from both main and minimum stacks simultaneously.
  4. getMin() simply returns minimum[-1] in O(1) time.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class MinStack:

    def __init__(self):
        self.stack = []
        self.minimum = []

    def push(self, val):
        self.stack.append(val)

        if not self.minimum:
            self.minimum.append(val)
        else:
            self.minimum.append(
                min(val, self.minimum[-1])
            )

    def pop(self):
        self.minimum.pop()
        return self.stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.minimum[-1]
8. Time and Space Complexity Analysis (Optimized)
All operations: O(1) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Auxiliary stack tracking answer query at each stack depth

#LC 150 • 6. Stack & Queue

Evaluate Reverse Polish Notation

Medium LeetCode
1. Problem Statement

Evaluate the value of an arithmetic expression in Reverse Polish Notation (postfix). Valid operators are '+', '-', '*', and '/'.

2. Understanding & Key Observations

In RPN, operators follow their operands: e.g. ['2', '1', '+', '3', '*'] = (2 + 1) * 3 = 9.

3. Naive Solution — Brute Force

Repeatedly scan token array, find first operator, evaluate previous 2 operands, and replace sub-slice in token list.

Naive Solution (Python 3) 
class Solution:
    def evalRPN(self, tokens):

        tokens = tokens[:]

        operators = {"+", "-", "*", "/"}

        while len(tokens) > 1:
            for i, token in enumerate(tokens):

                if token not in operators:
                    continue

                a = int(tokens[i - 2])
                b = int(tokens[i - 1])

                if token == "+":
                    result = a + b
                elif token == "-":
                    result = a - b
                elif token == "*":
                    result = a * b
                else:
                    result = int(a / b)

                tokens[i - 2:i + 1] = [str(result)]
                break

        return int(tokens[0])
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(n)
5. Intuition — For Optimization

Use an operand stack. Push numbers. On operator, pop top 2 numbers (second popped is left operand), evaluate result, and push back.

6. Approach — Step-by-Step Algorithm
  1. Initialize empty stack.
  2. Iterate through tokens.
  3. If integer: push int(token) to stack.
  4. If operator: pop b = stack.pop(), a = stack.pop().
  5. Perform operation (truncating division toward zero int(a / b)), push result to stack.
  6. Return stack[-1].
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def evalRPN(self, tokens):
        stack = []

        operators = {"+", "-", "*", "/"}

        for token in tokens:

            if token not in operators:
                stack.append(int(token))
                continue

            b = stack.pop()
            a = stack.pop()

            if token == "+":
                result = a + b
            elif token == "-":
                result = a - b
            elif token == "*":
                result = a * b
            else:
                result = int(a / b)

            stack.append(result)

        return stack[-1]
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Operand → push; Operator → pop two → calculate → push result

#LC 22 • 6. Stack & Queue

Generate Parentheses

Medium LeetCode
1. Problem Statement

Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

2. Understanding & Key Observations

Generate valid strings of length $2n$ where open count $\le n$ and close count $\le$ open count at all steps.

3. Naive Solution — Brute Force

Generate all $2^{2n}$ possible bracket strings recursively and validate each using a balance counter.

Naive Solution (Python 3) 
class Solution:
    def generateParenthesis(self, n):

        result = []

        def valid(s):
            balance = 0

            for char in s:
                if char == "(":
                    balance += 1
                else:
                    balance -= 1

                if balance < 0:
                    return False

            return balance == 0

        def generate(s):
            if len(s) == 2 * n:
                if valid(s):
                    result.append(s)
                return

            generate(s + "(")
            generate(s + ")")

        generate("")

        return result
4. Time & Space Complexity Analysis (Naive)
Time: O(2^(2n) × n) Space: O(n) recursion
5. Intuition — For Optimization

Backtracking with constraints: only add '(' if open_count < n; only add ')' if close_count < open_count. Prunes invalid branches early.

6. Approach — Step-by-Step Algorithm
  1. Recursive helper backtrack(current, open_count, close_count).
  2. Base Case: len(current) == 2 * n, append to result.
  3. Branch 1: If open_count < n, recurse with '('.
  4. Branch 2: If close_count < open_count, recurse with ')'.
  5. Number of valid strings is given by the $n$th Catalan number $C_n = \frac{1}{n+1}\binom{2n}{n}$.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def generateParenthesis(self, n):

        result = []

        def backtrack(current, open_count, close_count):

            if len(current) == 2 * n:
                result.append(current)
                return

            if open_count < n:
                backtrack(
                    current + "(",
                    open_count + 1,
                    close_count
                )

            if close_count < open_count:
                backtrack(
                    current + ")",
                    open_count,
                    close_count + 1
                )

        backtrack("", 0, 0)

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(C(n) × n) Space: O(n) recursion
9. Pattern / Key Takeaway

Pattern — Backtracking with constraints (prune impossible branches)

#LC 739 • 6. Stack & Queue

Daily Temperatures

Medium LeetCode
1. Problem Statement

Given an array of integers temperatures, return an array answer such that answer[i] is the number of days you have to wait after the ith day to get a warmer temperature.

2. Understanding & Key Observations

Find the index distance to the Next Greater Element for each index.

3. Naive Solution — Brute Force

For each day i, iterate through future days j = i+1 ... n-1 until a warmer temperature is found.

Naive Solution (Python 3) 
class Solution:
    def dailyTemperatures(self, temperatures):
        n = len(temperatures)
        result = [0] * n

        for i in range(n):

            for j in range(i + 1, n):

                if temperatures[j] > temperatures[i]:
                    result[i] = j - i
                    break

        return result
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(1) aux
5. Intuition — For Optimization

Monotonic Decreasing Stack storing indices. When current temperature > temperature at top index, pop index and compute day gap curr_index - prev_index.

6. Approach — Step-by-Step Algorithm
  1. Initialize result = [0] * len(temperatures) and empty stack.
  2. Iterate index i and temperature.
  3. While stack and temperature > temperatures[stack[-1]]:
  4. Pop prev_index = stack.pop().
  5. Set result[prev_index] = i - prev_index.
  6. Push current index i onto stack.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def dailyTemperatures(self, temperatures):

        result = [0] * len(temperatures)

        stack = []

        for i, temperature in enumerate(temperatures):

            while (
                stack
                and temperature > temperatures[stack[-1]]
            ):
                previous = stack.pop()

                result[previous] = i - previous

            stack.append(i)

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Next Greater Element → Monotonic Decreasing Stack

#LC 853 • 6. Stack & Queue

Car Fleet

Medium LeetCode
1. Problem Statement

Cars travel to target destination. A faster car catching a slower fleet merges into that fleet. Return total number of fleets that arrive at destination.

2. Understanding & Key Observations

Car arrival time = (target - position) / speed. Sorting cars by starting position descending lets us evaluate fleet merging.

3. Naive Solution — Brute Force

Simulate positions over continuous time steps or iteratively merge adjacent fleets.

Naive Solution (Python 3) 
class Solution:
    def carFleet(self, target, position, speed):

        cars = sorted(
            zip(position, speed)
        )

        fleets = []

        for pos, spd in cars:
            time = (target - pos) / spd

            while (
                fleets
                and time <= fleets[-1]
            ):
                fleets.pop()

            fleets.append(time)

        return len(fleets)
4. Time & Space Complexity Analysis (Naive)
Time: O(n log n) Space: O(n)
5. Intuition — For Optimization

Sort cars by position descending (closest to target first). Compute target arrival time. If current car's arrival time $\le$ last fleet's arrival time, it merges into that fleet.

6. Approach — Step-by-Step Algorithm
  1. Pair position & speed, sort descending by position: sorted(zip(position, speed), reverse=True).
  2. Initialize stack storing fleet arrival times.
  3. For each car: compute time = (target - pos) / spd.
  4. If stack is empty or time > stack[-1], push time to stack (forms a new distinct fleet).
  5. Return len(stack).
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def carFleet(self, target, position, speed):

        cars = sorted(
            zip(position, speed),
            reverse=True
        )

        stack = []

        for pos, spd in cars:
            time = (
                target - pos
            ) / spd

            if (
                not stack
                or time > stack[-1]
            ):
                stack.append(time)

        return len(stack)
8. Time and Space Complexity Analysis (Optimized)
Time: O(n log n) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Sort by position descending → Target Arrival Time Stack

#LC 84 • 6. Stack & Queue

Largest Rectangle in Histogram

Hard LeetCode
1. Problem Statement

Given an array of integers heights representing the histogram's bar height where width of each bar is 1, find the area of the largest rectangle in the histogram.

2. Understanding & Key Observations

For a bar at index i with height h, the max width rectangle extending this height spans between the Previous Smaller Element and Next Smaller Element.

3. Naive Solution — Brute Force

For every bar i, expand left and right pointers while bar heights are $\ge heights[i]$, then compute area.

Naive Solution (Python 3) 
class Solution:
    def largestRectangleArea(self, heights):

        answer = 0
        n = len(heights)

        for i in range(n):

            left = i
            right = i

            while (
                left - 1 >= 0
                and heights[left - 1] >= heights[i]
            ):
                left -= 1

            while (
                right + 1 < n
                and heights[right + 1] >= heights[i]
            ):
                right += 1

            width = right - left + 1

            answer = max(
                answer,
                heights[i] * width
            )

        return answer
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(1) aux
5. Intuition — For Optimization

Monotonic Increasing Stack storing bar indices. When a shorter bar is encountered, taller bars at top of stack can no longer extend rightward; pop and calculate rectangle area.

6. Approach — Step-by-Step Algorithm
  1. Append sentinel 0 height to heights to flush stack at end.
  2. Maintain monotonic increasing stack of bar indices.
  3. When current height < heights[stack[-1]]:
  4. Pop h = heights[stack.pop()].
  5. Left boundary is new stack[-1] if stack non-empty else -1.
  6. Compute width = current_index - left_boundary - 1 and update max area.
  7. Push current index.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def largestRectangleArea(self, heights):

        stack = []
        answer = 0

        heights.append(0)

        for i, height in enumerate(heights):

            while (
                stack
                and heights[stack[-1]] > height
            ):
                h = heights[stack.pop()]

                left_boundary = (
                    stack[-1]
                    if stack
                    else -1
                )

                width = (
                    i
                    - left_boundary
                    - 1
                )

                answer = max(
                    answer,
                    h * width
                )

            stack.append(i)

        heights.pop()

        return answer
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Next / Previous Smaller Element → Monotonic Increasing Stack

⚡ The Most Important Connection & Amortized Proof

Comparing the two flagship Monotonic Stack problems and understanding why nested while loops remain O(N).

┌────────────────────────────────────────────────────────────────────────┐ │ MONOTONIC STACK DUALITY │ └───────────────────────────────────┬────────────────────────────────────┘ │ ┌───────────────────────────┴───────────────────────────┐ ▼ ▼ [ Daily Temperatures — LC 739 ] [ Largest Rectangle — LC 84 ] • Next Greater Element • Next/Previous Smaller Element • Stack is Decreasing • Stack is Increasing • Pop when curr > top • Pop when curr < top • Popped element finds warmer day • Popped element calculates height × width

The Killer Interview Proof: Why Monotonic Stacks are strictly O(n)

Even though a monotonic stack algorithm contains a nested while loop, every array index is pushed onto the stack exactly once and popped at most once throughout the entire execution of the loop.

Total push operations = $N$. Total pop operations $\le N$. Therefore, the total work spent inside the nested loop across all elements combined is $O(N + N) = O(N)$.
