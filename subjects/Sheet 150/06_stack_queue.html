#LC 20 • Stack & Queue

Valid Parentheses

Easy LeetCode
1. Problem Statement

Given string containing '(', ')', '{', '}', '[', ']', determine if input string is valid.

2. Understanding & Key Observations

Open brackets must be closed by same type in correct LIFO order.

3. Naive Solution — Basic Approach

Repeatedly replace (), {}, [] with empty string until unchanged.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(N)

String replacement.

5. Intuition — For Optimization

Stack LIFO popping matching closing bracket in O(N) time.

6. Approach — Step-by-Step Algorithm
  1. Map closeToOpen = {')':'(', '}':'{', ']':'['}.
  2. For c in s: if c in closeToOpen: if stack and stack[-1] == closeToOpen[c] pop; else return False. Else push c to stack.
  3. Return len(stack) == 0.
7. Optimized Code (Python 3)
Python 3 Implementation 
def isValid(s: str) -> bool:
    stack = []
    closeToOpen = {")": "(", "}": "{", "]": "["}

    for c in s:
        if c in closeToOpen:
            if stack and stack[-1] == closeToOpen[c]:
                stack.pop()
            else:
                return False
        else:
            stack.append(c)
    return len(stack) == 0
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)

LIFO stack matching.

#LC 155 • Stack & Queue

Min Stack

Medium LeetCode
1. Problem Statement

Design a stack that supports push, pop, top, and retrieving minimum element in O(1) time.

2. Understanding & Key Observations

Maintain parallel minStack storing minimum value present at each depth level.

3. Naive Solution — Basic Approach

Scan entire stack to find minimum on getMin() call.

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(1)

Linear scan on getMin.

5. Intuition — For Optimization

Parallel min stack stores current min value for each state.

6. Approach — Step-by-Step Algorithm
  1. Two stacks: stack and minStack.
  2. push(val): stack.append(val); val = min(val, minStack[-1] if minStack else val); minStack.append(val).
  3. pop(): pop from both stacks.
7. Optimized Code (Python 3)
Python 3 Implementation 
class MinStack:
    def __init__(self):
        self.stack = []
        self.minStack = []

    def push(self, val: int) -> None:
        self.stack.append(val)
        val = min(val, self.minStack[-1] if self.minStack else val)
        self.minStack.append(val)

    def pop(self) -> None:
        self.stack.pop()
        self.minStack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.minStack[-1]
8. Time and Space Complexity Analysis (Optimized)
Time: O(1) Space: O(N)

O(1) operations for all methods.

#LC 150 • Stack & Queue

Evaluate Reverse Polish Notation

Medium LeetCode
1. Problem Statement

Evaluate arithmetic expression in Reverse Polish Notation (Postfix).

2. Understanding & Key Observations

Operands pushed to stack. Operator pops top 2 operands b, a, evaluates a op b, pushes result.

3. Naive Solution — Basic Approach

String parsing replacing postfix tokens in-place.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(N)

Array shifting.

5. Intuition — For Optimization

Stack LIFO evaluation handles postfix order naturally.

6. Approach — Step-by-Step Algorithm
  1. Stack st = [].
  2. For token in tokens: if operator pop b, a, compute a + b, a - b, a * b, int(a / b), push result. Else push int(token).
7. Optimized Code (Python 3)
Python 3 Implementation 
def evalRPN(tokens: list[str]) -> int:
    stack = []
    for c in tokens:
        if c == "+":
            stack.append(stack.pop() + stack.pop())
        elif c == "-":
            a, b = stack.pop(), stack.pop()
            stack.append(b - a)
        elif c == "*":
            stack.append(stack.pop() * stack.pop())
        elif c == "/":
            a, b = stack.pop(), stack.pop()
            stack.append(int(b / a))
        else:
            stack.append(int(c))
    return stack[0]
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)

Single pass evaluation.

Generate Parentheses

Medium LeetCode
1. Problem Statement

Given n pairs of parentheses, generate all combinations of well-formed parentheses.

2. Understanding & Key Observations

Valid condition: open count openN < n; close count closedN < openN.

3. Naive Solution — Basic Approach

Generate all 2^(2N) strings of '(' and ')' and validate each.

4. Time & Space Complexity Analysis (Naive)
Time: O(2^(2N) * N) Space: O(N)

Explores invalid parenthesizations.

5. Intuition — For Optimization

Backtracking only adds valid open/close brackets.

6. Approach — Step-by-Step Algorithm
  1. In backtrack(openN, closedN): if openN == closedN == n append .join(stack).
  2. If openN < n: append '(', recurse, pop.
  3. If closedN < openN: append ')', recurse, pop.
7. Optimized Code (Python 3)
Python 3 Implementation 
def generateParenthesis(n: int) -> list[str]:
    stack = []
    res = []

    def backtrack(openN, closedN):
        if openN == closedN == n:
            res.append("".join(stack))
            return

        if openN < n:
            stack.append("(")
            backtrack(openN + 1, closedN)
            stack.pop()

        if closedN < openN:
            stack.append(")")
            backtrack(openN, closedN + 1)
            stack.pop()

    backtrack(0, 0)
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(4^N / sqrt(N)) Space: O(N)

Catalan number valid parenthesization count.

#LC 739 • Stack & Queue

Daily Temperatures

Medium LeetCode
1. Problem Statement

Given array of temperatures, return array answer such that answer[i] is number of days until warmer temperature.

2. Understanding & Key Observations

Monotonic Decreasing Stack storing (temp, index) pairs.

3. Naive Solution — Basic Approach

For each day, scan future days using nested loop.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(1)

Nested loop forward scan.

5. Intuition — For Optimization

Monotonic stack pops indices as soon as a warmer temperature is encountered.

6. Approach — Step-by-Step Algorithm
  1. res = [0] * len(temperatures), stack = [] (index).
  2. For i, t in enumerate(temperatures): while stack and t > temperatures[stack[-1]]: prev_i = stack.pop(); res[prev_i] = i - prev_i.
  3. Push i to stack.
7. Optimized Code (Python 3)
Python 3 Implementation 
def dailyTemperatures(temperatures: list[int]) -> list[int]:
    res = [0] * len(temperatures)
    stack = []  # index

    for i, t in enumerate(temperatures):
        while stack and t > temperatures[stack[-1]]:
            prev_i = stack.pop()
            res[prev_i] = i - prev_i
        stack.append(i)
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)

Monotonic stack single pass.

#LC 853 • Stack & Queue

Car Fleet

Medium LeetCode
1. Problem Statement

n cars driven to target destination. Return number of car fleets that arrive at target.

2. Understanding & Key Observations

Time to target = (target - position) / speed. Sort cars by position descending. If car behind takes LESS time than car ahead, it joins the fleet of car ahead!

3. Naive Solution — Basic Approach

Simulate car position movement frame by frame.

4. Time & Space Complexity Analysis (Naive)
Time: O(Target * N) Space: O(N)

Frame-by-frame simulation.

5. Intuition — For Optimization

Sort by position descending. Monotonic stack tracks fleet times.

6. Approach — Step-by-Step Algorithm
  1. Pair positions and speeds: pair = [[p, s] for p, s in zip(position, speed)]. Sort descending by position.
  2. For p, s in sorted pair: time (target - p) / s pushed to stack. If len(stack) >= 2 and stack[-1] <= stack[-2]: stack.pop().
  3. Return len(stack).
7. Optimized Code (Python 3)
Python 3 Implementation 
def carFleet(target: int, position: list[int], speed: list[int]) -> int:
    pair = [[p, s] for p, s in zip(position, speed)]
    stack = []

    for p, s in sorted(pair)[::-1]:
        stack.append((target - p) / s)
        if len(stack) >= 2 and stack[-1] <= stack[-2]:
            stack.pop()
            
    return len(stack)
8. Time and Space Complexity Analysis (Optimized)
Time: O(N log N) Space: O(N)

Sorting takes O(N log N).

#LC 84 • Stack & Queue

Largest Rectangle in Histogram

Hard LeetCode
1. Problem Statement

Given array of heights representing histogram, return area of largest rectangle in histogram.

2. Understanding & Key Observations

A height h can extend left to index start. Monotonic Increasing Stack stores (start_index, height).

3. Naive Solution — Basic Approach

Check all N^2 pairs of left and right boundaries.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(1)

Evaluates all pairs.

5. Intuition — For Optimization

Monotonic stack pops taller bars when a shorter bar is encountered, calculating area with popped height and extended width.

6. Approach — Step-by-Step Algorithm
  1. Stack st = [] storing (index, height). maxArea = 0.
  2. For i, h in enumerate(heights): start = i; while st and st[-1][1] > h: index, height = st.pop(); maxArea = max(maxArea, height * (i - index)); start = index. Push (start, h) to stack.
  3. Pop remaining items in stack calculating area to len(heights).
7. Optimized Code (Python 3)
Python 3 Implementation 
def largestRectangleArea(heights: list[int]) -> int:
    maxArea = 0
    stack = []  # pair: (index, height)

    for i, h in enumerate(heights):
        start = i
        while stack and stack[-1][1] > h:
            index, height = stack.pop()
            maxArea = max(maxArea, height * (i - index))
            start = index
        stack.append((start, h))

    for i, h in stack:
        maxArea = max(maxArea, h * (len(heights) - i))
    return maxArea
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)

Monotonic stack single pass algorithm.
