Implement Trie (Prefix Tree)

Medium LeetCode
1. Problem Statement

Implement Trie data structure with insert, search, and startsWith operations.

2. Understanding & Key Observations

Each TrieNode contains children = {} map and endOfWord = False boolean flag.

3. Naive Solution — Basic Approach

Store words in a list/set and scan prefixes using string startswith.

4. Time & Space Complexity Analysis (Naive)
Time: O(N * L) Space: O(N * L)

List scanning.

5. Intuition — For Optimization

Trie tree nodes store character transitions providing O(L) lookup independent of total word count.

6. Approach — Step-by-Step Algorithm
  1. TrieNode class: self.children = {}; self.endOfWord = False.
  2. insert(word): iterate chars, create nodes if missing, set curr.endOfWord = True at end.
  3. search(word): return True iff path exists and curr.endOfWord is True.
  4. startsWith(prefix): return True iff path exists.
7. Optimized Code (Python 3)
Python 3 Implementation 
class TrieNode:
    def __init__(self):
        self.children = {}
        self.endOfWord = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        curr = self.root
        for c in word:
            if c not in curr.children:
                curr.children[c] = TrieNode()
            curr = curr.children[c]
        curr.endOfWord = True

    def search(self, word: str) -> bool:
        curr = self.root
        for c in word:
            if c not in curr.children:
                return False
            curr = curr.children[c]
        return curr.endOfWord

    def startsWith(self, prefix: str) -> bool:
        curr = self.root
        for c in prefix:
            if c not in curr.children:
                return False
            curr = curr.children[c]
        return True
8. Time and Space Complexity Analysis (Optimized)
Time: O(L) Space: O(N * L)

L is string length, N is word count.

Design Add and Search Words Data Structure

Medium LeetCode
1. Problem Statement

Design data structure supporting addWord(word) and wildcard search(word) where '.' matches any letter.

2. Understanding & Key Observations

When encountering '.' during search, launch recursive DFS across ALL existing child nodes of current node!

3. Naive Solution — Basic Approach

Regex matching over full word list.

4. Time & Space Complexity Analysis (Naive)
Time: O(N * L) Space: O(N * L)

Regex engine evaluation.

5. Intuition — For Optimization

Trie + DFS backtracking on wildcard dots.

6. Approach — Step-by-Step Algorithm
  1. TrieNode class. addWord inserts chars normally.
  2. dfs(j, root): if c == '.': loop all child in root.children.values(): if dfs(j+1, child) return True. Else if c not in root.children return False; else recurse dfs(j+1, root.children[c]).
7. Optimized Code (Python 3)
Python 3 Implementation 
class TrieNode:
    def __init__(self):
        self.children = {}
        self.isWord = False

class WordDictionary:
    def __init__(self):
        self.root = TrieNode()

    def addWord(self, word: str) -> None:
        curr = self.root
        for c in word:
            if c not in curr.children:
                curr.children[c] = TrieNode()
            curr = curr.children[c]
        curr.isWord = True

    def search(self, word: str) -> bool:
        def dfs(j, root):
            curr = root
            for i in range(j, len(word)):
                c = word[i]
                if c == ".":
                    for child in curr.children.values():
                        if dfs(i + 1, child):
                            return True
                    return False
                else:
                    if c not in curr.children:
                        return False
                    curr = curr.children[c]
            return curr.isWord

        return dfs(0, self.root)

Word Search II

Hard LeetCode
1. Problem Statement

Given m x n board of characters and list of words, return all words on board.

2. Understanding & Key Observations

Insert all target words into a Trie. Run 2D Grid DFS backtracking simultaneously navigating the Trie!

3. Naive Solution — Basic Approach

Run LC 79 Word Search DFS for every single word independently.

4. Time & Space Complexity Analysis (Naive)
Time: O(W * M * N * 3^L) Space: O(L)

Repeats grid DFS per word.

5. Intuition — For Optimization

Single grid DFS using Trie prefix tree prunes invalid word branches immediately.

6. Approach — Step-by-Step Algorithm
  1. Build Trie of all input words.
  2. Define dfs(r, c, node, word): if node.isWord add word to res and set node.isWord = False.
  3. Mark grid cell '#'. Recurse 4 directions. Restore cell.
7. Optimized Code (Python 3)
Python 3 Implementation 
class TrieNode:
    def __init__(self):
        self.children = {}
        self.isWord = False

    def addWord(self, word):
        curr = self
        for c in word:
            if c not in curr.children:
                curr.children[c] = TrieNode()
            curr = curr.children[c]
        curr.isWord = True

def findWords(board: list[list[str]], words: list[str]) -> list[str]:
    root = TrieNode()
    for w in words:
        root.addWord(w)

    ROWS, COLS = len(board), len(board[0])
    res, visit = set(), set()

    def dfs(r, c, node, word):
        if (r < 0 or c < 0 or r >= ROWS or c >= COLS or
            (r, c) in visit or board[r][c] not in node.children):
            return

        visit.add((r, c))
        node = node.children[board[r][c]]
        word += board[r][c]
        if node.isWord:
            res.add(word)

        dfs(r + 1, c, node, word)
        dfs(r - 1, c, node, word)
        dfs(r, c + 1, node, word)
        dfs(r, c - 1, node, word)
        visit.remove((r, c))

    for r in range(ROWS):
        for c in range(COLS):
            dfs(r, c, root, "")

    return list(res)
8. Time and Space Complexity Analysis (Optimized)
Time: O(M * N * 3^L) Space: O(W * L)

Trie prefix matching avoids redundant grid searches.
