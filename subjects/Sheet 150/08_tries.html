#LC 208 • 8. Tries

Implement Trie (Prefix Tree)

Medium LeetCode
1. Problem Statement

Implement a trie data structure supporting insert(word), search(word), and startsWith(prefix).

2. Understanding & Key Observations

A Trie stores strings character-by-character as a tree. Each node tracks its children and whether a complete word ends there.

3. Naive Solution — Brute Force

Store all words in a list and perform string operations on every query.

class Trie:

    def __init__(self):
        self.words = []

    def insert(self, word):
        if word not in self.words:
            self.words.append(word)

    def search(self, word):
        return word in self.words

    def startsWith(self, prefix):
        for word in self.words:
            if word.startswith(prefix):
                return True

        return False

4. Time & Space Complexity Analysis (Naive)
insert/search/startsWith: O(N × L) Space: O(N × L)
5. Intuition — For Optimization

Store characters in a tree where each edge is a character. Traverse character-by-character for O(L) insert, search, and prefix checks.

6. Approach — Step-by-Step Algorithm
  1. Define TrieNode with children = {} and is_word = False.
  2. insert(word): Walk node-by-node from root, creating missing children. Set node.is_word = True at last character.
  3. search(word): Walk node-by-node. Return False if any character is missing. Return node.is_word at end.
  4. startsWith(prefix): Same traversal as search but return True regardless of is_word at end.

Design Add and Search Words Data Structure

Medium LeetCode
1. Problem Statement

Design a data structure supporting addWord(word) and search(word) where '.' in search patterns matches any single character.

2. Understanding & Key Observations

A wildcard '.' means branching into every child of the current Trie node simultaneously — a DFS over all children.

3. Naive Solution — Brute Force

Store words in a list and compare each candidate against the search pattern character-by-character.

class WordDictionary:

    def __init__(self):
        self.words = []

    def addWord(self, word):
        self.words.append(word)

    def search(self, word):

        for candidate in self.words:

            if len(candidate) != len(word):
                continue

            match = True

            for i in range(len(word)):

                if (
                    word[i] != "."
                    and word[i] != candidate[i]
                ):
                    match = False
                    break

            if match:
                return True

        return False

4. Time & Space Complexity Analysis (Naive)
addWord: O(1), search: O(N × L) Space: O(N × L)
5. Intuition — For Optimization

Build a Trie for fast prefix traversal. When encountering '.', branch into all children via DFS and return True if any branch succeeds.

6. Approach — Step-by-Step Algorithm
  1. Build Trie with TrieNode(children, is_word) exactly as LC 208.
  2. addWord inserts into the Trie identically.
  3. search(word) calls dfs(index, node).
  4. Base case: index == len(word) → return node.is_word.
  5. If word[index] != '.': advance into node.children[char] if exists.
  6. If word[index] == '.': iterate all node.children.values() and return True if any recursive call returns True.

class WordDictionary:

    def __init__(self):
        self.root = TrieNode()

    def addWord(self, word):

        node = self.root

        for char in word:

            if char not in node.children:
                node.children[char] = TrieNode()

            node = node.children[char]

        node.is_word = True

    def search(self, word):

        def dfs(index, node):

            if index == len(word):
                return node.is_word

            char = word[index]

            if char != ".":

                if char not in node.children:
                    return False

                return dfs(
                    index + 1,
                    node.children[char]
                )

            # Wildcard: try all children
            for child in node.children.values():

                if dfs(index + 1, child):
                    return True

            return False

        return dfs(0, self.root)

#LC 212 • 8. Tries

Word Search II

Hard LeetCode
1. Problem Statement

Given an m x n board of characters and a list of strings words, return all words from the list that can be found in the board (adjacent horizontal/vertical cells, no cell reused).

2. Understanding & Key Observations

Running separate board-DFS for each word is wasteful when words share prefixes. A Trie over all words enables prefix pruning — a non-matching prefix stops all further exploration.

3. Naive Solution — Brute Force

For every word, start a full board DFS from every matching cell.

class Solution:

    def findWords(self, board, words):

        rows = len(board)
        cols = len(board[0])
        result = []

        def exists(word):

            def dfs(r, c, index):
                if index == len(word):
                    return True

                if (
                    r < 0 or r >= rows or c < 0 or c >= cols
                    or board[r][c] != word[index]
                ):
                    return False

                temp = board[r][c]
                board[r][c] = "#"

                found = (
                    dfs(r + 1, c, index + 1)
                    or dfs(r - 1, c, index + 1)
                    or dfs(r, c + 1, index + 1)
                    or dfs(r, c - 1, index + 1)
                )

                board[r][c] = temp
                return found

            for r in range(rows):
                for c in range(cols):
                    if board[r][c] == word[0]:
                        if dfs(r, c, 0):
                            return True

            return False

        for word in words:
            if exists(word):
                result.append(word)

        return result

4. Time & Space Complexity Analysis (Naive)
Time: O(W × R × C × 4^L) Space: O(L) recursion
5. Intuition — For Optimization

Build a single Trie from all words. Run one DFS from every board cell navigating the Trie simultaneously. When the current character is not in the Trie node's children, prune immediately — this avoids exploring invalid prefixes shared across many words.

6. Approach — Step-by-Step Algorithm
  1. Build Trie from all words, storing node.word = word (not is_word) at terminal nodes.
  2. Outer loops: iterate every board cell (r, c) and call dfs(r, c, root).
  3. DFS checks: out-of-bounds, visited marker '#', or char not in node.children → return immediately.
  4. If next_node.word is not None: append to result and set next_node.word = None to prevent duplicates.
  5. Mark cell board[r][c] = '#', recurse in 4 directions with next_node, then restore cell.
7. Optimized Code (Python 3)

        self.word = None


class Solution:

    def findWords(self, board, words):

        root = TrieNode()

        # Build Trie from all words
        for word in words:

            node = root

            for char in word:

                if char not in node.children:
                    node.children[char] = TrieNode()

                node = node.children[char]

            node.word = word

        rows = len(board)
        cols = len(board[0])
        result = []

        def dfs(r, c, node):

            if r < 0 or r >= rows or c < 0 or c >= cols:
                return

            char = board[r][c]

            if char == "#":
                return

            if char not in node.children:
                return

            next_node = node.children[char]

            # Complete word found
            if next_node.word is not None:
                result.append(next_node.word)
                next_node.word = None  # prevent duplicates

            board[r][c] = "#"  # mark visited

            dfs(r + 1, c, next_node)
            dfs(r - 1, c, next_node)
            dfs(r, c + 1, next_node)
            dfs(r, c - 1, next_node)

            board[r][c] = char  # restore

        for r in range(rows):
            for c in range(cols):
                dfs(r, c, root)

        return result

🔥 The LC 208 → 211 → 212 Progression

These three problems aren't separate — they're one idea built up step by step.

LC 208 — The Foundation

Learn node.children (hash map) and node.is_word. Master the insert/search/prefix template. Everything else builds on this.

LC 211 — Trie + DFS

Add wildcard '.': branch into all children when char == '.'. Same Trie traversal, but now with recursive backtracking.

LC 212 — Trie + Board DFS + Pruning

Build Trie from all words. Navigate Trie and board simultaneously. The line if char not in node.children: return is the prefix pruning that makes this efficient.
