#LC 57 • Intervals

Insert Interval

Medium LeetCode
1. Problem Statement

Insert newInterval into sorted non-overlapping intervals and merge if necessary.

2. Understanding & Key Observations

Three phases: 1) add intervals before newInterval; 2) merge overlapping intervals; 3) add intervals after newInterval.

3. Naive Solution — Basic Approach

Append newInterval, sort full list, and run Merge Intervals.

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(N)

Sorting overhead.

5. Intuition — For Optimization

Single pass iteration taking advantage of already sorted input intervals.

6. Approach — Step-by-Step Algorithm
  1. res = [].
  2. For i, interval: if newInterval[1] < interval[0] append newInterval and return res + intervals[i:].
  3. Elif newInterval[0] > interval[1] append interval.
  4. Else overlap: merge newInterval = [min(newInterval[0], interval[0]), max(newInterval[1], interval[1])].
  5. Append newInterval and return.
7. Optimized Code (Python 3)
Python 3 Implementation 
def insert(intervals: list[list[int]], newInterval: list[int]) -> list[list[int]]:
    res = []
    for i in range(len(intervals)):
        if newInterval[1] < intervals[i][0]:
            res.append(newInterval)
            return res + intervals[i:]
        elif newInterval[0] > intervals[i][1]:
            res.append(intervals[i])
        else:
            newInterval = [
                min(newInterval[0], intervals[i][0]),
                max(newInterval[1], intervals[i][1])
            ]
    res.append(newInterval)
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)

Single pass merging.

#LC 56 • Intervals

Merge Intervals

Medium LeetCode
1. Problem Statement

Merge all overlapping intervals in array intervals.

2. Understanding & Key Observations

Sort intervals by start time. Two intervals overlap if current_start <= last_end.

3. Naive Solution — Basic Approach

Graph connected components approach.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(N)

Graph construction.

5. Intuition — For Optimization

Sorting by start time allows linear merge pass.

6. Approach — Step-by-Step Algorithm
  1. Sort intervals by start time. res = [intervals[0]].
  2. For start, end in intervals[1:]: lastEnd = res[-1][1].
  3. If start <= lastEnd: res[-1][1] = max(lastEnd, end). Else append [start, end].
7. Optimized Code (Python 3)
Python 3 Implementation 
def merge(intervals: list[list[int]]) -> list[list[int]]:
    intervals.sort(key=lambda i: i[0])
    output = [intervals[0]]

    for start, end in intervals[1:]:
        lastEnd = output[-1][1]
        if start <= lastEnd:
            output[-1][1] = max(lastEnd, end)
        else:
            output.append([start, end])
    return output
8. Time and Space Complexity Analysis (Optimized)
Time: O(N log N) Space: O(N)

Sorting takes O(N log N).

#LC 435 • Intervals

Non-Overlapping Intervals

Medium LeetCode
1. Problem Statement

Return minimum number of intervals to remove to make remaining intervals non-overlapping.

2. Understanding & Key Observations

Greedy choice: when two intervals overlap, REMOVE the interval with the LARGER end time to leave maximum room for future intervals!

3. Naive Solution — Basic Approach

Recursion checking subset combinations.

4. Time & Space Complexity Analysis (Naive)
Time: O(2^N) Space: O(N)

Subsets.

5. Intuition — For Optimization

Sort by start time and greedily keep interval with smaller end time.

6. Approach — Step-by-Step Algorithm
  1. Sort intervals by start time. res = 0, prevEnd = intervals[0][1].
  2. For start, end in intervals[1:]: if start >= prevEnd prevEnd = end. Else res += 1; prevEnd = min(end, prevEnd).
7. Optimized Code (Python 3)
Python 3 Implementation 
def eraseOverlapIntervals(intervals: list[list[int]]) -> int:
    intervals.sort(key=lambda i: i[0])
    res = 0
    prevEnd = intervals[0][1]

    for start, end in intervals[1:]:
        if start >= prevEnd:
            prevEnd = end
        else:
            res += 1
            prevEnd = min(end, prevEnd)
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N log N) Space: O(1)

Greedy interval removal.

Meeting Rooms

Easy LeetCode
1. Problem Statement

Determine if a person could attend all meetings (no overlapping meetings).

2. Understanding & Key Observations

Sort meetings by start time. Check if i.end > (i+1).start.

3. Naive Solution — Basic Approach

Compare all pairs of meetings.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(1)

Pairwise comparison.

5. Intuition — For Optimization

Sorting brings potential overlaps adjacent to each other.

6. Approach — Step-by-Step Algorithm
  1. Sort intervals by start time.
  2. Loop i from 0..len-2: if intervals[i][1] > intervals[i+1][0] return False. Return True.
7. Optimized Code (Python 3)
Python 3 Implementation 
def canAttendMeetings(intervals: list[list[int]]) -> bool:
    intervals.sort(key=lambda i: i[0])
    for i in range(len(intervals) - 1):
        if intervals[i][1] > intervals[i + 1][0]:
            return False
    return True
8. Time and Space Complexity Analysis (Optimized)
Time: O(N log N) Space: O(1)

Sorting takes O(N log N).

Meeting Rooms II

Medium LeetCode
1. Problem Statement

Return minimum number of conference rooms required for all meetings.

2. Understanding & Key Observations

Separate start times and end times into 2 sorted arrays. Track max concurrent ongoing meetings using 2 pointers.

3. Naive Solution — Basic Approach

Min-heap storing end times.

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(N)

Min-heap storing end times.

5. Intuition — For Optimization

Two pointers on sorted start and end arrays avoid heap overhead.

6. Approach — Step-by-Step Algorithm
  1. start = sorted([i[0] for i in intervals]), end = sorted([i[1] for i in intervals]).
  2. Pointers s = 0, e = 0, count = 0, res = 0.
  3. While s < len(intervals): if start[s] < end[e] s += 1; count += 1 else e += 1; count -= 1. res = max(res, count).
7. Optimized Code (Python 3)
Python 3 Implementation 
def minMeetingRooms(intervals: list[list[int]]) -> int:
    start = sorted([i[0] for i in intervals])
    end = sorted([i[1] for i in intervals])

    res, count = 0, 0
    s, e = 0, 0

    while s < len(intervals):
        if start[s] < end[e]:
            s += 1
            count += 1
        else:
            e += 1
            count -= 1
        res = max(res, count)
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N log N) Space: O(N)

Two-pointer sweep line.

#LC 1851 • Intervals

Minimum Interval to Include Each Query

Hard LeetCode
1. Problem Statement

For each query point, return size of smallest interval containing query. If none return -1.

2. Understanding & Key Observations

Sort intervals and queries. Min-heap stores (interval_size, interval_end) for all intervals covering current query.

3. Naive Solution — Basic Approach

Scan all intervals for each query.

4. Time & Space Complexity Analysis (Naive)
Time: O(N * Q) Space: O(1)

Nested loop.

5. Intuition — For Optimization

Offline queries processing + Min-Heap yields O((N + Q) log N) time.

6. Approach — Step-by-Step Algorithm
  1. Sort intervals by start. Sort queries with original index q = sorted([(q, i) for i, q in enumerate(queries)]).
  2. Min-heap minHeap = [] (size, end). Pointer i = 0.
  3. For query q, q_idx: add all intervals with start <= q to heap. Pop expired intervals with end < q. Store res[q_idx] = minHeap[0][0].
7. Optimized Code (Python 3)
Python 3 Implementation 
import heapq

def minInterval(intervals: list[list[int]], queries: list[int]) -> list[int]:
    intervals.sort()
    minHeap = []
    res = {}
    i = 0
    
    for q in sorted(queries):
        while i < len(intervals) and intervals[i][0] <= q:
            l, r = intervals[i]
            heapq.heappush(minHeap, (r - l + 1, r))
            i += 1
            
        while minHeap and minHeap[0][1] < q:
            heapq.heappop(minHeap)
            
        res[q] = minHeap[0][0] if minHeap else -1
        
    return [res[q] for q in queries]
8. Time and Space Complexity Analysis (Optimized)
Time: O((N + Q) log N) Space: O(N + Q)

Offline queries processing with Min-Heap.
