#LC 57 • 10. Intervals

Insert Interval

Medium LeetCode
1. Problem Statement

Given a list of non-overlapping, sorted intervals and a new interval, insert the new interval and merge any overlapping intervals. Return the result.

2. Understanding & Key Observations

The intervals are already sorted. Exploit that structure: everything before the new interval is untouched, everything overlapping gets merged, and everything after is also untouched. Three regions — three passes.

3. Naive Solution — Brute Force

Append the new interval, sort everything, then run standard merge-intervals.

Naive Solution (Python 3) 
class Solution:
    def insert(self, intervals, newInterval):
        intervals.append(newInterval)
        intervals.sort()

        result = []

        for start, end in intervals:
            if not result or start > result[-1][1]:
                result.append([start, end])
            else:
                result[-1][1] = max(result[-1][1], end)

        return result
4. Time & Space Complexity Analysis (Naive)
Time: O(n log n) Space: O(n)
5. Intuition — For Optimization

The list is already sorted — no need to re-sort. Scan in three explicit phases: (1) intervals ending before the new one starts, (2) overlapping intervals that get absorbed into newInterval, (3) intervals starting after the new one ends.

6. Approach — Step-by-Step Algorithm
  1. Walk while intervals[i][1] < newInterval[0] — append directly to result.
  2. Walk while intervals[i][0] <= newInterval[1] — merge: take min of starts and max of ends into newInterval.
  3. Append the merged newInterval.
  4. Append all remaining intervals.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def insert(self, intervals, newInterval):
        result = []
        i = 0
        n = len(intervals)

        # Phase 1 — completely before new interval
        while i < n and intervals[i][1] < newInterval[0]:
            result.append(intervals[i])
            i += 1

        # Phase 2 — overlapping: merge into newInterval
        while i < n and intervals[i][0] <= newInterval[1]:
            newInterval[0] = min(newInterval[0], intervals[i][0])
            newInterval[1] = max(newInterval[1], intervals[i][1])
            i += 1

        result.append(newInterval)

        # Phase 3 — completely after new interval
        while i < n:
            result.append(intervals[i])
            i += 1

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(n) output
9. Pattern / Key Takeaway

Pattern — Already-sorted list → Three-phase scan (before / overlap-merge / after)

#LC 56 • 10. Intervals

Merge Intervals

Medium LeetCode
1. Problem Statement

Given an array of intervals, merge all overlapping intervals and return the resulting array.

2. Understanding & Key Observations

Once intervals are sorted by start time, any overlap can only occur with the previous interval in the result list. A single left-to-right scan is sufficient.

3. Naive Solution — Brute Force

Repeatedly scan for any overlapping pair and merge them until no overlaps remain.

Naive Solution (Python 3) 
class Solution:
    def merge(self, intervals):
        intervals = [x[:] for x in intervals]
        changed = True

        while changed:
            changed = False
            result = []
            used = [False] * len(intervals)

            for i in range(len(intervals)):
                if used[i]:
                    continue

                current = intervals[i]

                for j in range(i + 1, len(intervals)):
                    if used[j]:
                        continue

                    other = intervals[j]

                    if (
                        current[0] <= other[1]
                        and other[0] <= current[1]
                    ):
                        current = [
                            min(current[0], other[0]),
                            max(current[1], other[1]),
                        ]
                        used[j] = True
                        changed = True

                result.append(current)

            intervals = result

        return intervals
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) worst case Space: O(n)
5. Intuition — For Optimization

Sort by start time. After sorting, overlapping intervals must be adjacent. Walk once: if the current interval's start is within the last result interval's end, extend; otherwise append fresh.

6. Approach — Step-by-Step Algorithm
  1. Sort intervals by start time.
  2. Initialize result = [].
  3. For each [start, end]: if result is empty or start > result[-1][1], append [start, end].
  4. Otherwise: result[-1][1] = max(result[-1][1], end).
  5. Return result.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def merge(self, intervals):
        intervals.sort()
        result = []

        for start, end in intervals:
            if not result or start > result[-1][1]:
                result.append([start, end])
            else:
                result[-1][1] = max(result[-1][1], end)

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(n log n) Space: O(n) output
9. Pattern / Key Takeaway

Pattern — Sort by start → compare current start with previous end

#LC 435 • 10. Intervals

Non-Overlapping Intervals

Medium LeetCode
1. Problem Statement

Given an array of intervals, return the minimum number of intervals to remove so that the rest are non-overlapping.

2. Understanding & Key Observations

When two intervals overlap, greedy insight: keep the one that ends earlier — it leaves the most room for future intervals. This is the classic Interval Scheduling Maximization problem.

3. Naive Solution — Brute Force

DFS: try all combinations of kept/removed intervals and find the minimum removals.

Naive Solution (Python 3) 
class Solution:
    def eraseOverlapIntervals(self, intervals):
        n = len(intervals)
        best = [n]

        def overlaps(a, b):
            return a[0] < b[1] and b[0] < a[1]

        def dfs(index, chosen):
            if index == n:
                best[0] = min(best[0], n - len(chosen))
                return

            # Skip this interval
            dfs(index + 1, chosen)

            # Take if compatible
            if all(
                not overlaps(intervals[index], x)
                for x in chosen
            ):
                chosen.append(intervals[index])
                dfs(index + 1, chosen)
                chosen.pop()

        dfs(0, [])
        return best[0]
4. Time & Space Complexity Analysis (Naive)
Time: O(2ⁿ × n) Space: O(n)
5. Intuition — For Optimization

Sort by end time. Scan left to right: if the current interval overlaps the previous kept one, remove it (increment counter). If it does not overlap, keep it and update previous_end.

6. Approach — Step-by-Step Algorithm
  1. Sort intervals by end time: key=lambda x: x[1].
  2. Initialize removed = 0, previous_end = -inf.
  3. For each [start, end]: if start < previous_end → conflict, increment removed.
  4. Else: keep this interval, set previous_end = end.
  5. Return removed.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def eraseOverlapIntervals(self, intervals):
        intervals.sort(key=lambda x: x[1])

        removed = 0
        previous_end = float("-inf")

        for start, end in intervals:
            if start < previous_end:
                removed += 1
            else:
                previous_end = end

        return removed
8. Time and Space Complexity Analysis (Optimized)
Time: O(n log n) Space: O(1) auxiliary
9. Pattern / Key Takeaway

Pattern — Sort by END → Earliest Finish Time (keep the interval ending soonest to maximize future room)

#LC 252 • 10. Intervals

Meeting Rooms

Easy LeetCode
1. Problem Statement

Given a list of meeting time intervals, determine if a single person can attend all meetings (no two meetings may overlap).

2. Understanding & Key Observations

After sorting by start, any overlap can only occur between consecutive meetings. A single adjacent comparison pass suffices.

3. Naive Solution — Brute Force

Compare every pair of meetings for overlap.

Naive Solution (Python 3) 
class Solution:
    def canAttendMeetings(self, intervals):
        n = len(intervals)

        for i in range(n):
            for j in range(i + 1, n):
                start1, end1 = intervals[i]
                start2, end2 = intervals[j]

                if start1 < end2 and start2 < end1:
                    return False

        return True
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(1)
5. Intuition — For Optimization

Sort by start time. After sorting, any two overlapping intervals must be adjacent. A single pass comparing each meeting's start to the previous meeting's end is enough.

6. Approach — Step-by-Step Algorithm
  1. Sort intervals by start time.
  2. Iterate from index 1.
  3. If intervals[i][0] < intervals[i-1][1]: overlap found, return False.
  4. Return True.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def canAttendMeetings(self, intervals):
        intervals.sort()

        for i in range(1, len(intervals)):
            if intervals[i][0] < intervals[i - 1][1]:
                return False

        return True
8. Time and Space Complexity Analysis (Optimized)
Time: O(n log n) Space: O(1) auxiliary
9. Pattern / Key Takeaway

Pattern — Sort by start → compare adjacent pairs

#LC 253 • 10. Intervals

Meeting Rooms II

Medium LeetCode
1. Problem Statement

Given meeting intervals, find the minimum number of conference rooms required to host all meetings simultaneously.

2. Understanding & Key Observations

When a new meeting starts, check the room that becomes free earliest. If it frees up before the new meeting starts, reuse it. Otherwise, open a new room. A min-heap of end times models this perfectly.

3. Naive Solution — Brute Force

For every meeting, count how many other meetings overlap with it.

Naive Solution (Python 3) 
class Solution:
    def minMeetingRooms(self, intervals):
        answer = 0

        for start, end in intervals:
            rooms = 0

            for other_start, other_end in intervals:
                if other_start < end and start < other_end:
                    rooms += 1

            answer = max(answer, rooms)

        return answer
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(1)
5. Intuition — For Optimization

Sort meetings by start time. Use a min-heap to track the earliest end time among ongoing meetings. When a new meeting starts: if the heap's top (earliest ending room) is free, pop and reuse; otherwise push a new room. Heap size = rooms needed.

6. Approach — Step-by-Step Algorithm
  1. Sort intervals by start time.
  2. Initialize rooms = [] (min-heap of end times).
  3. For each [start, end]: if rooms is non-empty and rooms[0] <= start, pop (reuse that room).
  4. Push end onto the heap.
  5. Return len(rooms).
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
import heapq

class Solution:
    def minMeetingRooms(self, intervals):
        if not intervals:
            return 0

        intervals.sort()
        rooms = []

        for start, end in intervals:
            # Reuse the room that ends earliest
            if rooms and rooms[0] <= start:
                heapq.heappop(rooms)

            heapq.heappush(rooms, end)

        return len(rooms)
8. Time and Space Complexity Analysis (Optimized)
Time: O(n log n) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Sort by start + Min-Heap of end times (earliest available room at the top)

#LC 1851 • 10. Intervals

Minimum Interval to Include Each Query

Hard LeetCode
1. Problem Statement

Given intervals and queries, for each query return the size of the smallest interval that contains it, or -1 if none exists.

2. Understanding & Key Observations

Sorting both intervals and queries lets us add intervals incrementally as queries grow. A min-heap ordered by interval size keeps the best candidate at the top. Expired intervals (those ending before the current query) are lazily removed.

3. Naive Solution — Brute Force

For every query, scan all intervals linearly and find the smallest containing one.

Naive Solution (Python 3) 
class Solution:
    def minInterval(self, intervals, queries):
        result = []

        for query in queries:
            best = float("inf")

            for start, end in intervals:
                if start <= query <= end:
                    size = end - start + 1
                    best = min(best, size)

            result.append(-1 if best == float("inf") else best)

        return result
4. Time & Space Complexity Analysis (Naive)
Time: O(n × q) Space: O(q)
5. Intuition — For Optimization

Sort intervals by start and queries (with original indices) by value. Sweep queries left-to-right: push all intervals whose start ≤ query onto a min-heap keyed by size. Pop intervals from the heap whose end < query (expired). The heap top is the smallest valid interval.

6. Approach — Step-by-Step Algorithm
  1. Sort intervals by start.
  2. Create sorted_queries = sorted((q, i) for i, q in enumerate(queries)).
  3. Initialize result = [-1] * len(queries), heap = [], i = 0.
  4. For each (query, original_index): push all intervals with start <= query as (size, end).
  5. Pop heap entries where end < query (expired intervals).
  6. If heap is non-empty: result[original_index] = heap[0][0].
  7. Return result.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
import heapq

class Solution:
    def minInterval(self, intervals, queries):
        intervals.sort()

        sorted_queries = sorted(
            (query, i)
            for i, query in enumerate(queries)
        )

        result = [-1] * len(queries)
        heap = []
        i = 0

        for query, original_index in sorted_queries:

            # Add all intervals whose start <= query
            while i < len(intervals) and intervals[i][0] <= query:
                start, end = intervals[i]
                size = end - start + 1
                heapq.heappush(heap, (size, end))
                i += 1

            # Remove intervals that ended before this query
            while heap and heap[0][1] < query:
                heapq.heappop(heap)

            if heap:
                result[original_index] = heap[0][0]

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(n log n + q log q) Space: O(n + q)
9. Pattern / Key Takeaway

Pattern — Sort intervals by start + sort queries + Min-Heap by size (lazy-remove expired intervals)

🔥 4 Core Interval Patterns

These four patterns cover every problem in this module. Learn the shape, not just the problem.

Sort by Start

Used by LC 56, 57, 252, 253. After sorting by start, any overlap can only be with the immediately previous interval. A single left-to-right scan is sufficient.

Sort by End (Earliest Finish)

Used by LC 435. When intervals conflict, keep the one ending soonest — it leaves the most room for future intervals. Classic greedy interval scheduling.

Min-Heap of End Times

Used by LC 253. Sort by start, then maintain a min-heap of ongoing meeting end-times. Heap top = earliest room becoming free. If it frees before new start → reuse; else → new room.

Sorted Queries + Min-Heap

Used by LC 1851. Sort intervals and queries independently. Sweep queries left-to-right, adding intervals that started and lazily removing expired ones. Heap keeps best candidate at top.

⭐ The Big Connection — LC 253 vs LC 1851

LC 253 — Meeting Rooms II

Sort by start → min-heap of end times → reuse earliest available room → heap size = answer

LC 1851 — Minimum Interval Query

Sort intervals + sort queries → min-heap of interval sizes → lazy-remove expired → heap top = smallest valid

The reusable insight: Sort events by when they become relevant, then use a heap to keep the best currently valid candidate.
