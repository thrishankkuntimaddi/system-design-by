#LC 226 • 2A. Binary Trees

Invert Binary Tree

Easy LeetCode
1. Problem Statement

Given the root of a binary tree, invert the tree, and return its root (swap left and right subtrees recursively).

2. Understanding & Key Observations

Inverting a tree means swapping every left child with its corresponding right child at every node in the tree.

3. Naive Solution — Recursive Swap

Recursively swap the left and right children.

class Solution:
    def invertTree(self, root):
        if not root:
            return None

        left = self.invertTree(root.left)
        right = self.invertTree(root.right)

        root.left = right
        root.right = left

        return root

public:

            return nullptr;
        }
        left = invertTree(root.left);
        right = invertTree(root.right);
        root.left = right;
        root.right = left;
        return root;
    }
};

4. Time & Space Complexity Analysis (Naive)
Time: O(n) Aux Space: O(h) Output Space: O(n) for tree

h = tree height call stack recursion.

5. Intuition — For Optimization

Iterative BFS avoids recursion depth issues on deep skewed trees.

6. Approach — Step-by-Step Algorithm
  1. If root is None return None.
  2. Push root into BFS queue.
  3. While queue: pop node, swap node.left, node.right = node.right, node.left.
  4. Push left and right children into queue if they exist.
7. Optimized Code (Python 3)

            node = queue.popleft()

            node.left, node.right = node.right, node.left

            if node.left:
                queue.append(node.left)

            if node.right:
                queue.append(node.right)

        return root

Easy LeetCode
1. Problem Statement

Given the root of a binary tree, return its maximum depth (number of nodes along longest path from root to furthest leaf).

2. Understanding & Key Observations

Max depth at root = 1 + max(depth(root.left), depth(root.right)). Base case for empty node is depth 0.

3. Naive Solution — DFS

Recursive postorder traversal returning height at each node.

class Solution:
    def maxDepth(self, root):

            return 0

        return 1 + max(
            self.maxDepth(root.left),
            self.maxDepth(root.right)
        )

        maxDepth(root.left),;
        maxDepth(root.right);
        );
    }
};

            return 0;
        }
        return 1 + max(;
        maxDepth(root.left),;
        maxDepth(root.right);
        );
    }

4. Time & Space Complexity Analysis (Naive)
Time: O(n) Aux Space: O(h)
5. Intuition — For Optimization

Level-order traversal (BFS) processes nodes level-by-level using a queue, incrementing depth counter after each level.

6. Approach — Step-by-Step Algorithm
  1. If not root return 0.
  2. Initialize queue with root and depth = 0.
  3. For each level (loop size of queue): pop node and push non-null children.
  4. Increment depth after processing level.
7. Optimized Code (Python 3)

                node = queue.popleft()

                if node.left:
                    queue.append(node.left)

                if node.right:
                    queue.append(node.right)

            depth += 1

        return depth

Diameter of Binary Tree

Easy LeetCode
1. Problem Statement

Given the root of a binary tree, return the length of the diameter of the tree (longest path between any two nodes).

2. Understanding & Key Observations

The longest path passing through node u is left_height + right_height. The overall diameter is the max of this value across all nodes.

3. Naive Solution

For every node, separately calculate the height of its left and right subtree.

class Solution:
    def diameterOfBinaryTree(self, root):

        def height(node):
            if not node:
                return 0

            return 1 + max(
                height(node.left),
                height(node.right)
            )

        if not root:
            return 0

        left_diameter = self.diameterOfBinaryTree(root.left)
        right_diameter = self.diameterOfBinaryTree(root.right)

        current = height(root.left) + height(root.right)

        return max(current, left_diameter, right_diameter)

4. Time & Space Complexity Analysis (Naive)
Time: O(n^2) worst case Aux Space: O(h)
5. Intuition — For Optimization

Calculate height and diameter in the same bottom-up DFS traversal.

6. Approach — Step-by-Step Algorithm
  1. Initialize diameter = 0.
  2. Define dfs(node): if node is None return 0.
  3. Get left = dfs(node.left) and right = dfs(node.right).
  4. Update diameter = max(diameter, left + right).
  5. Return node height: 1 + max(left, right).

Balanced Binary Tree

Easy LeetCode
1. Problem Statement

Given a binary tree, determine if it is height-balanced (left and right subtree heights differ by at most 1 for every node).

2. Understanding & Key Observations

A tree is balanced if abs(height(left) - height(right)) <= 1 for all nodes.

3. Naive Solution

Repeatedly calculate subtree heights.

class Solution:
    def isBalanced(self, root):

        def height(node):
            if not node:
                return 0

            return 1 + max(
                height(node.left),
                height(node.right)
            )

        if not root:
            return True

        left = height(root.left)
        right = height(root.right)

        if abs(left - right) > 1:
            return False

        return (
            self.isBalanced(root.left) and
            self.isBalanced(root.right)
        )

Recursive comparison.

Subtree of Another Tree

Easy LeetCode
1. Problem Statement

Given roots of root and subRoot, return true if subRoot is a valid subtree of root.

2. Understanding & Key Observations

For every node in root, check whether subRoot is identical to that subtree.

3. Naive Solution

For every node in root, check whether subRoot is identical to the subtree.

class Solution:
    def isSubtree(self, root, subRoot):
        
        def same(a, b):
            if not a and not b:
                return True

            if not a or not b:
                return False

            return (
                a.val == b.val
                and same(a.left, b.left)
                and same(a.right, b.right)
            )

        if not root:
            return False

        if same(root, subRoot):
            return True

        return (
            self.isSubtree(root.left, subRoot)
            or
            self.isSubtree(root.right, subRoot)
        )

6. Approach — Step-by-Step Algorithm
  1. Serialize root and subRoot using preorder traversal into strings with null markers.
  2. Build KMP Partial Match Table (LPS) for pattern string.
  3. Run KMP search to find pattern in text in O(n + m) time.

                serialize(node.right)

import heapq

class Solution:
    def minCostConnectPoints(self, points):
        n = len(points)
        visited = set()
        min_heap = [(0, 0)]  # (cost, point_index)

        total_cost = 0

        while len(visited) < n:
            cost, u = heapq.heappop(min_heap)

            if u in visited:
                continue

            visited.add(u)
            total_cost += cost

            x1, y1 = points[u]

            for v in range(n):
                if v not in visited:
                    x2, y2 = points[v]
                    dist = abs(x1 - x2) + abs(y1 - y2)
                    heapq.heappush(min_heap, (dist, v))

        return total_cost

Network Delay Time

Medium LeetCode
1. Problem Statement

Return minimum time for all n nodes to receive signal from source node k. Return -1 if impossible.

2. Understanding & Key Observations

Single-source shortest path on weighted directed graph with non-negative edge weights → Dijkstra's Algorithm!

3. Naive Solution

Bellman-Ford algorithm relaxing edges N-1 times.

4. Time & Space Complexity Analysis (Naive)
Time: O(V × E) Aux Space: O(V)
5. Intuition — For Optimization

Dijkstra's with Min-Heap pops minimum distance node greedily. Maximum distance in final visited map is total time.

6. Approach — Step-by-Step Algorithm
  1. Build graph adjacency list (neighbor, weight).
  2. Min-heap [(0, k)], distances map = {}.
  3. Pop (time, node). If node visited continue. Save distances[node] = time.
  4. Push unvisited neighbors with time + weight.
  5. Return max(distances.values()) if len(distances) == n else -1.
7. Optimized Code (Python 3)
from collections import defaultdict
import heapq

class Solution:
    def networkDelayTime(self, times, n, k):
        graph = defaultdict(list)

        for u, v, w in times:
            graph[u].append((v, w))

        min_heap = [(0, k)]
        distances = {}

        while min_heap:
            time, node = heapq.heappop(min_heap)

            if node in distances:
                continue

            distances[node] = time

            for neighbor, weight in graph[node]:
                if neighbor not in distances:
                    heapq.heappush(
                        min_heap,
                        (time + weight, neighbor)
                    )

        if len(distances) == n:
            return max(distances.values())

        return -1

Hard LeetCode
1. Problem Statement

Return minimum time t to reach bottom-right (n-1, n-1) from (0,0) in grid of water elevations.

Shortest path where path cost is max(elevation along path). Solved via Modified Dijkstra.

3. Naive Solution

Binary search on time t with BFS check.

4. Time & Space Complexity Analysis (Naive)

Dijkstra's Algorithm with Min-Heap pops grid cells ordered by max_elevation along path.

6. Approach — Step-by-Step Algorithm
  1. Min-heap [(grid[0][0], 0, 0)], visited = {(0,0)}.
  2. Pop (time, r, c). If (r, c) == (n-1, n-1), return time.
  3. Push unvisited neighbors with max(time, grid[nr][nc]).

import heapq

class Solution:
    def swimInWater(self, grid):
        n = len(grid)

        min_heap = [(grid[0][0], 0, 0)]
        visited = {(0, 0)}

        while min_heap:
            time, r, c = heapq.heappop(min_heap)

            if r == n - 1 and c == n - 1:
                return time

            for dr, dc in [
                (1, 0), (-1, 0),
                (0, 1), (0, -1)
            ]:
                nr, nc = r + dr, c + dc

                if (
                    0 <= nr < n and
                    0 <= nc < n and
                    (nr, nc) not in visited
                ):
                    visited.add((nr, nc))
                    heapq.heappush(
                        min_heap,
                        (max(time, grid[nr][nc]), nr, nc)
                    )

        return -1

Alien Dictionary

Hard LeetCode
1. Problem Statement

Given sorted dictionary of alien language words, return valid ordering of letters in alien alphabet. If invalid return "".

2. Understanding & Key Observations

Topological Sort on DAG formed by directed edges comparing adjacent words in dictionary.

3. Naive Solution

Character permutation brute force.

4. Time & Space Complexity Analysis (Naive)
Time: O(26!) Aux Space: O(1)
5. Intuition — For Optimization

Compare adjacent words to extract directed character edges. Post-order DFS topological sort with cycle detection.

6. Approach — Step-by-Step Algorithm
  1. Compare adjacent words w1, w2. If w1 starts with w2 and len(w1) > len(w2) return "".
  2. Find first differing char and add edge w1[j] -> w2[j].
  3. Post-order DFS with cycle detection. Return reversed post-order list.

class Solution:
    def alienOrder(self, words):
        graph = {
            char: set()
            for word in words
            for char in word
        }

        for i in range(len(words) - 1):
            w1, w2 = words[i], words[i + 1]
            min_length = min(len(w1), len(w2))

            if len(w1) > len(w2) and w1[:min_length] == w2[:min_length]:
                return ""

            for j in range(min_length):
                if w1[j] != w2[j]:
                    graph[w1[j]].add(w2[j])
                    break

        visited = {}
        result = []

        def dfs(char):
            if char in visited:
                return visited[char]

            visited[char] = True

            for neighbor in graph[char]:
                if dfs(neighbor):
                    return True

            visited[char] = False
            result.append(char)

            return False

        for char in graph:
            if dfs(char):
                return ""

        return "".join(result[::-1])

Cheapest Flights Within K Stops

Medium LeetCode
1. Problem Statement

Return cheapest price from src to dst with at most k stops. If no path, return -1.

2. Understanding & Key Observations

Shortest path with step limit constraint (at most K+1 edges). Ideal for Bellman-Ford algorithm!

3. Naive Solution

Standard Dijkstra without stop constraint check.

4. Time & Space Complexity Analysis (Naive)
Time: O(E log V) Aux Space: O(V)
5. Intuition — For Optimization

Bellman-Ford algorithm run K+1 iterations using a copy of previous distances array.

6. Approach — Step-by-Step Algorithm
  1. Distance array prices = [inf] * n, prices[src] = 0.
  2. Loop k + 1 times: copy tmp = list(prices). For u, v, w in flights: if prices[u] != inf, update tmp[v] = min(tmp[v], prices[u] + w).
  3. Set prices = tmp. Return prices[dst] if prices[dst] != inf else -1.
7. Optimized Code (Python 3)
class Solution:
    def findCheapestPrice(self, n, flights, src, dst, k):
        prices = [float("inf")] * n
        prices[src] = 0

        for _ in range(k + 1):
            tmp = list(prices)

            for u, v, price in flights:
                if prices[u] == float("inf"):
                    continue

                if prices[u] + price < tmp[v]:
                    tmp[v] = prices[u] + price

            prices = tmp

        if prices[dst] != float("inf"):
            return prices[dst]

        return -1
