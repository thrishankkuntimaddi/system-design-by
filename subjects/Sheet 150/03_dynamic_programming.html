#LC 70 • 3A. 1-D Dynamic Programming

Climbing Stairs

Easy LeetCode
1. Problem Statement

You are climbing a staircase with n steps. Each time you can climb 1 or 2 steps. How many distinct ways can you climb to the top?

2. Understanding & Key Observations

At every step, you can climb either 1 or 2 stairs. To reach step n, you come from n-1 or n-2.

3. Naive Solution — Recursion

Generate every climb step combination by recursively deciding whether to take 1 or 2 steps.

class Solution:
    def climbStairs(self, n):
        def dfs(step):
            if step == n:
                return 1

            if step > n:
                return 0

            return dfs(step + 1) + dfs(step + 2)

        return dfs(0)

5. Intuition — Bottom-Up DP

Subproblem overlap means dp[i] = dp[i-1] + dp[i-2]. We can build bottom-up or optimize space to only 2 variables.

  1. Check base cases: if n <= 2, return n.
  2. Maintain prev2 = 1 and prev1 = 2.
  3. Loop from 3 to n updating current = prev1 + prev2, shifting prev2 = prev1 and prev1 = current.
  4. Return prev1.

Min Cost Climbing Stairs

Easy LeetCode
1. Problem Statement

Given an integer array cost where cost[i] is the cost of i-th step on a staircase. Once you pay the cost, you can climb 1 or 2 steps. Return the minimum cost to reach the top of the floor.

2. Understanding & Key Observations

You can start from step 0 or step 1. At step i, cost incurred to jump is cost[i] + min(cost_of_next_1, cost_of_next_2).

                dfs(i + 2)
            )

        return min(dfs(0), dfs(1))

House Robber

Medium LeetCode
1. Problem Statement

You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed. Adjacent houses have security systems connected, so you cannot rob two adjacent houses. Return maximum money you can rob.

2. Understanding & Key Observations

At every house: Rob it (gain nums[i] + profit from house i-2) OR skip it (keep profit from house i-1).

3. Naive Solution — Recursion

Explore all choices at each house recursively.

    def rob(self, nums):

        def dfs(i):
            if i >= len(nums):
                return 0

            rob = nums[i] + dfs(i + 2)
            skip = dfs(i + 1)

            return max(rob, skip)

        return dfs(0)

Medium LeetCode
1. Problem Statement

Houses form a circle, so the first and last houses are neighbors and cannot both be robbed. Return maximum money you can rob.

2. Understanding & Key Observations

Circular constraint means we split into two linear subproblems: Case 1 (houses 0 ... n-2) and Case 2 (houses 1 ... n-1). Return max of both.

3. Naive Solution — Recursion

Try all subsets while tracking whether the first house was robbed and previous house was robbed.

class Solution:
    def rob(self, nums):

        def dfs(i, first_robbed, previous_robbed):
            if i == len(nums):
                return 0

            skip = dfs(
                i + 1,
                first_robbed,
                False
            )

            take = 0

            if not previous_robbed:
                if i != len(nums) - 1 or not first_robbed:
                    take = nums[i] + dfs(
                        i + 1,
                        first_robbed or i == 0,
                        True
                    )

            return max(skip, take)

        return dfs(0, False, False)

Longest Palindromic Substring

Medium LeetCode
1. Problem Statement

Given a string s, return the longest palindromic substring in s.

2. Understanding & Key Observations

A palindrome expands outward from its center. There are odd-length centers (single char) and even-length centers (between two chars).

3. Naive Solution — Brute Force

Check every substring s[i:j+1] to see if it is a palindrome.

class Solution:
    def longestPalindrome(self, s):

        def is_palindrome(left, right):
            while left < right:
                if s[left] != s[right]:
                    return False

                left += 1
                right -= 1

            return True

        longest = ""

        for i in range(len(s)):
            for j in range(i, len(s)):
                if is_palindrome(i, j):
                    if j - i + 1 > len(longest):
                        longest = s[i:j + 1]

        return longest

#LC 312 • 3B. 2-D Dynamic Programming

Burst Balloons

Hard LeetCode
1. Problem Statement

Burst balloon i to gain nums[i-1] * nums[i] * nums[i+1] coins. Return max total coins.

2. Understanding & Key Observations

Instead of choosing the first balloon to burst, choose the LAST balloon to burst in an interval (left, right)!

3. Naive Solution — Recursion

Try every balloon as the first balloon to burst recursively.

class Solution:
    def maxCoins(self, nums):

        def dfs(nums):
            if not nums:
                return 0

            answer = 0

            for i in range(len(nums)):
                left = nums[i - 1] if i > 0 else 1
                right = nums[i + 1] if i + 1 < len(nums) else 1

                coins = (
                    left *
                    nums[i] *
                    right
                )

                remaining = nums[:i] + nums[i + 1:]

                answer = max(
                    answer,
                    coins + dfs(remaining)
                )

            return answer

        return dfs(nums)

5. Intuition — Interval DP

Pad array with 1 at both ends: nums = [1] + nums + [1]. Evaluate interval lengths from 2 to n. Choose balloon k burst last in (left, right).

6. Approach — Step-by-Step Algorithm
  1. Pad array with boundary 1s: nums = [1] + nums + [1].
  2. Create 2D DP matrix dp of size n x n.
  3. Outer loop length from 2 to n-1; inner loop left from 0 to n - length; right = left + length.
  4. Loop k from left + 1 to right - 1: coins = nums[left] * nums[k] * nums[right]. Update dp[left][right] = max(dp[left][right], dp[left][k] + coins + dp[k][right]).
  5. Return dp[0][n - 1].

Given input string s and pattern p, implement regex matching with '.' (matches any single char) and '*' (matches zero or more of preceding element).

2. Understanding & Key Observations

Recursive branching occurs whenever * appears in pattern. State is represented by pair of indices (i, j) for s and p.

🔥 DP Patterns You Should Master

Instead of memorizing 23 solutions, master these 9 core structural patterns:

1. Take / Skip

Problems: House Robber

dp[i] = max(
    dp[i - 1],
    nums[i] + dp[i - 2]
)

2. Previous States

Problems: Climbing Stairs, Min Cost Climbing Stairs

current = function(previous states)

3. Knapsack

Problems: Coin Change, Coin Change II, Partition Equal Subset Sum, Target Sum

  • 0/1 Knapsack: Use item once → Loop backwards (range(target, num - 1, -1))
  • Unbounded Knapsack: Reuse item → Loop forwards

4. Two-String DP

Problems: LCS, Edit Distance, Distinct Subsequences, Interleaving String, Regex Matching

dp[i][j] = Answer for first i chars of String A and first j chars of String B.

5. Grid DP

Problems: Unique Paths, Longest Increasing Path

Transitions across 2D grid cells: dp[row][column].

6. State Machine DP

Problems: Best Time to Buy and Sell Stock with Cooldown

Model explicit transitions: BUY → SELL → COOLDOWN.

7. Sequence DP

Problems: Longest Increasing Subsequence (LIS)

What is the best optimal answer ending at index i?

8. Interval DP

Problems: Burst Balloons

dp[left][right] — Evaluate choice of k as the last operation inside an interval.

9. DFS + Memoization

Problems: Longest Increasing Path, Regex Matching

State → expensive recursion → repeated states? → memo[state]. The bridge from recursion to DP.
