#LC 217 • 4A. Arrays & Hashing

Contains Duplicate

Easy LeetCode
1. Problem Statement

Given an integer array nums, return true if any value appears at least twice in the array.

2. Understanding & Key Observations

Check for non-unique elements in an array.

3. Naive Solution — Basic Approach

Compare all pairs (i, j) using nested loops.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(1)

Nested loop pairwise comparison.

5. Intuition — For Optimization

Use a Hash Set to track seen numbers in O(1) time per element.

6. Approach — Step-by-Step Algorithm
  1. Set seen = set().
  2. For n in nums: if n in seen return True; else seen.add(n).
  3. Return False.
7. Optimized Code (Python 3)
Python 3 Implementation 
def containsDuplicate(nums: list[int]) -> bool:
    seen = set()
    for n in nums:
        if n in seen:
            return True
        seen.add(n)
    return False
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)

Hash set provides linear time lookup.

Given array nums and target target, return indices of two numbers such that they add up to target.

2. Understanding & Key Observations

Find i, j such that nums[i] + nums[j] == target.

3. Naive Solution — Basic Approach

Check all pairs (i, j) with nested loops.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(1)

Brute force checks N*(N-1)/2 pairs.

5. Intuition — For Optimization

For number n, check if complement target - n exists in HashMap mapping value -> index.

6. Approach — Step-by-Step Algorithm
  1. Map prevMap = {}.

Python 3 Implementation 
def twoSum(nums: list[int], target: int) -> list[int]:
    prevMap = {}  # val -> index
    for i, n in enumerate(nums):
        diff = target - n
        if diff in prevMap:
            return [prevMap[diff], i]
        prevMap[n] = i

Time: O(N) Space: O(N)

Single pass Hash Map lookup.

Medium LeetCode

Given array of strings strs, group anagrams together in any order.

2. Understanding & Key Observations

Strings with identical character counts belong to the same anagram group.

3. Naive Solution — Basic Approach

Sort each word and use sorted string as dictionary key.

4. Time & Space Complexity Analysis (Naive)
Time: O(N * K log K) Space: O(N * K)

K is max string length. Sorting each string takes K log K.

5. Intuition — For Optimization

Use 26-element character count tuple as HashMap key instead of sorting.

6. Approach — Step-by-Step Algorithm
  1. Dict res = defaultdict(list).
  2. For s in strs: count array of size 26. Populate counts. Convert to tuple and append s to res[tuple(count)].

7. Optimized Code (Python 3)
Python 3 Implementation 
from collections import defaultdict

def groupAnagrams(strs: list[str]) -> list[list[str]]:
    res = defaultdict(list)
    for s in strs:
        count = [0] * 26
        for c in s:
            count[ord(c) - ord('a')] += 1
        res[tuple(count)].append(s)
    return list(res.values())
8. Time and Space Complexity Analysis (Optimized)
Time: O(N * K) Space: O(N * K)

Avoids string sorting by using tuple count key.

#LC 347 • 4A. Arrays & Hashing

Top K Frequent Elements

Medium LeetCode
1. Problem Statement

Given integer array nums and integer k, return k most frequent elements.

2. Understanding & Key Observations

Count frequency of elements and return top K keys.

3. Naive Solution — Basic Approach

Sort elements by frequency: Counter(nums).most_common(k).

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(N)

Sorting frequencies takes N log N.

5. Intuition — For Optimization

Bucket Sort: frequency bucket array where index represents frequency count (size N+1).

6. Approach — Step-by-Step Algorithm
  1. Frequency map count = Counter(nums).
  2. Buckets freq = [[] for _ in range(len(nums) + 1)].
  3. Populate freq[c].append(n).
  4. Iterate freq backwards from end, appending elements to res until len(res) == k.
7. Optimized Code (Python 3)
Python 3 Implementation 
def topKFrequent(nums: list[int], k: int) -> list[int]:
    count = {}
    freq = [[] for _ in range(len(nums) + 1)]

    for n in nums:
        count[n] = 1 + count.get(n, 0)
    for n, c in count.items():
        freq[c].append(n)

    res = []
    for i in range(len(freq) - 1, 0, -1):
        for n in freq[i]:
            res.append(n)
            if len(res) == k:
                return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)

Bucket sort achieves strict O(N) linear time.

Product of Array Except Self

Medium LeetCode
1. Problem Statement

Return array output such that output[i] equals product of all elements except nums[i] without division.

2. Understanding & Key Observations

output[i] = (prefix product before i) * (postfix product after i).

3. Naive Solution — Basic Approach

Compute total product and divide by nums[i] (fails on 0s and division restriction).

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(1)

Division prohibited by problem statement.

5. Intuition — For Optimization

Two-pass accumulation: Pass 1 computes prefix products directly into res; Pass 2 multiplies postfix scalar backwards.

6. Approach — Step-by-Step Algorithm
  1. Array res = [1] * len(nums).
  2. Prefix pass: prefix = 1; loop i: res[i] = prefix; prefix *= nums[i].
  3. Postfix pass: postfix = 1; loop i backwards: res[i] *= postfix; postfix *= nums[i].
7. Optimized Code (Python 3)
Python 3 Implementation 
def productExceptSelf(nums: list[int]) -> list[int]:
    res = [1] * len(nums)
    
    prefix = 1
    for i in range(len(nums)):
        res[i] = prefix
        prefix *= nums[i]
        
    postfix = 1
    for i in range(len(nums) - 1, -1, -1):
        res[i] *= postfix
        postfix *= nums[i]
        
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

Result array does not count as extra auxiliary space.

Determine if 9x9 Sudoku board is valid according to Sudoku rules.

No duplicates 1-9 in any row, column, or 3x3 sub-box.

3. Naive Solution — Basic Approach

Check each row, column, and sub-box in 3 separate passes.

4. Time & Space Complexity Analysis (Naive)
Time: O(1) Space: O(1)

9x9 fixed size board.

5. Intuition — For Optimization

Single pass using HashSets: rows[r], cols[c], and squares[(r//3, c//3)].

6. Approach — Step-by-Step Algorithm
  1. Sets cols = defaultdict(set), rows = defaultdict(set), squares = defaultdict(set).
  2. Loop r, c: if board[r][c] == '.' continue.
  3. If val in rows[r] or cols[c] or squares[(r//3, c//3)] return False.
  4. Add val to sets. Return True.
7. Optimized Code (Python 3)
Python 3 Implementation 
from collections import defaultdict

def isValidSudoku(board: list[list[str]]) -> bool:
    cols = defaultdict(set)
    rows = defaultdict(set)
    squares = defaultdict(set)

    for r in range(9):
        for c in range(9):
            if board[r][c] == ".":
                continue
            if (board[r][c] in rows[r] or
                board[r][c] in cols[c] or
                board[r][c] in squares[(r // 3, c // 3)]):
                return False
            cols[c].add(board[r][c])
            rows[r].add(board[r][c])
            squares[(r // 3, c // 3)].add(board[r][c])
    return True
8. Time and Space Complexity Analysis (Optimized)
Time: O(1) Space: O(1)

Fixed 81 grid cells checked in single pass.

Encode and Decode Strings

Medium LeetCode
1. Problem Statement

Design algorithm to encode a list of strings to a single string and decode back.

2. Understanding & Key Observations

Strings can contain any ASCII character (including delimiter symbols). Prefix length encoding solves ambiguity!

3. Naive Solution — Basic Approach

Use delimiter like ',' or '#' without storing length (breaks if string contains delimiter).

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(N)

Fails edge cases where string contains delimiter.

5. Intuition — For Optimization

Encode as length + '#' + string (e.g. 5#hello5#world).

6. Approach — Step-by-Step Algorithm
  1. encode: join len(s) + '#' + s for all strings.
  2. decode: scan string with pointer i. Find delimiter j = s.find('#', i). Extract length = int(s[i:j]). Extract string s[j+1 : j+1+length] and advance i.
7. Optimized Code (Python 3)
Python 3 Implementation 
class Codec:
    def encode(self, strs: list[str]) -> str:
        res = ""
        for s in strs:
            res += str(len(s)) + "#" + s
        return res

    def decode(self, s: str) -> list[str]:
        res = []
        i = 0
        while i < len(s):
            j = i
            while s[j] != "#":
                j += 1
            length = int(s[i:j])
            i = j + 1
            j = i + length
            res.append(s[i:j])
            i = j
        return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)

Length-prefix framing is robust against special characters.

Longest Consecutive Sequence

Medium LeetCode
1. Problem Statement

Given unsorted array nums, return length of longest consecutive elements sequence in O(n) time.

2. Understanding & Key Observations

Number x is start of a sequence iff x - 1 is NOT in set.

3. Naive Solution — Basic Approach

Sort array and scan adjacent differences.

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(1)

Sorting takes O(N log N).

5. Intuition — For Optimization

HashSet lookup allows O(1) checking if n-1 exists to identify sequence start points.

6. Approach — Step-by-Step Algorithm
  1. Set numSet = set(nums).
  2. For n in numSet: if n - 1 not in numSet: calculate sequence length while (n + length) in numSet: length += 1. Update longest = max(longest, length).
7. Optimized Code (Python 3)
Python 3 Implementation 
def longestConsecutive(nums: list[int]) -> int:
    numSet = set(nums)
    longest = 0

    for n in numSet:
        # Check if n is start of a sequence
        if (n - 1) not in numSet:
            length = 1
            while (n + length) in numSet:
                length += 1
            longest = max(longest, length)
            
    return longest
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)

Each element visited at most twice.

3. Naive Solution — Basic Approach

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(N)

Creates full filtered string copy.

5. Intuition — For Optimization

Two pointers l, r skip non-alphanumeric chars in-place with O(1) space.

6. Approach — Step-by-Step Algorithm
  1. Pointers l = 0, r = len(s) - 1.
  2. While l < r: skip non-alphanumeric. Compare s[l].lower() != s[r].lower(). Move l += 1; r -= 1.
7. Optimized Code (Python 3)
Python 3 Implementation 
def isPalindrome(s: str) -> bool:
    l, r = 0, len(s) - 1
    while l < r:
        while l < r and not s[l].isalnum():
            l += 1
        while r > l and not s[r].isalnum():
            r -= 1
        if s[l].lower() != s[r].lower():
            return False
        l += 1
        r -= 1
    return True
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

In-place two pointer check.

Two Sum II - Input Array Is Sorted

1. Problem Statement

Array is already sorted in non-decreasing order. Find two numbers that sum to target (1-indexed).

2. Understanding & Key Observations

Because array is sorted, sum = nums[l] + nums[r]. If sum > target, decrement r. If sum < target, increment l.

3. Naive Solution — Basic Approach

HashMap solution (ignores sorted property).

4. Time & Space Complexity Analysis (Naive)

5. Intuition — For Optimization

Two pointers from opposite ends exploit sorted invariant using O(1) space.

6. Approach — Step-by-Step Algorithm
  1. Pointers l = 0, r = len(nums) - 1.
  2. While l < r: cur = nums[l] + nums[r]. If cur > target r -= 1; elif cur < target l += 1; else return [l + 1, r + 1].

Python 3 Implementation 
def twoSum(numbers: list[int], target: int) -> list[int]:
    l, r = 0, len(numbers) - 1
    while l < r:
        curSum = numbers[l] + numbers[r]
        if curSum > target:
            r -= 1
        elif curSum < target:
            l += 1
        else:
            return [l + 1, r + 1]

Time: O(N) Space: O(1)

O(1) auxiliary space two-pointer approach.

#LC 15 • 4B. Two Pointers

3Sum

Medium LeetCode
1. Problem Statement

Given integer array nums, return all triplets [nums[i], nums[j], nums[k]] such that sum equals 0 and no duplicate triplets.

2. Understanding & Key Observations

Sort array. Fix first element nums[i] and run Two Sum II on remainder array.

3. Naive Solution — Basic Approach

Nested 3 loops testing all triplets and inserting into Set.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^3) Space: O(N)

Brute force triplet testing.

5. Intuition — For Optimization

Sort array. Skip duplicate nums[i] == nums[i-1]. Use two pointers for Two Sum II.

6. Approach — Step-by-Step Algorithm
  1. Sort nums.
  2. For i, a in enumerate(nums): if i > 0 and a == nums[i-1] continue.
  3. Pointers l = i + 1, r = len(nums) - 1.
  4. If sum == 0: append triplet, advance l skipping duplicates nums[l] == nums[l-1].
7. Optimized Code (Python 3)
Python 3 Implementation 
def threeSum(nums: list[int]) -> list[list[int]]:
    res = []
    nums.sort()

    for i, a in enumerate(nums):
        if i > 0 and a == nums[i - 1]:
            continue

        l, r = i + 1, len(nums) - 1
        while l < r:
            threeSum = a + nums[l] + nums[r]
            if threeSum > 0:
                r -= 1
            elif threeSum < 0:
                l += 1
            else:
                res.append([a, nums[l], nums[r]])
                l += 1
                while nums[l] == nums[l - 1] and l < r:
                    l += 1
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N^2) Space: O(1)

Sorting takes O(N log N). Nested loops run in O(N^2).

Medium LeetCode
1. Problem Statement

Given array height, find two lines that together with x-axis form container holding most water.

2. Understanding & Key Observations

Area = min(height[l], height[r]) * (r - l). Shrink container by moving pointer with SMALLER height!

3. Naive Solution — Basic Approach

Check area of all N^2 pairs.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(1)

Evaluates all pairs.

5. Intuition — For Optimization

Two pointers moving inward always move the bottleneck (shorter line) to seek a taller container boundary.

6. Approach — Step-by-Step Algorithm
  1. Pointers l = 0, r = len(height) - 1.
  2. While l < r: area = min(height[l], height[r]) * (r - l). Update res = max(res, area).
  3. If height[l] < height[r] move l += 1; else r -= 1.
7. Optimized Code (Python 3)
Python 3 Implementation 
def maxArea(height: list[int]) -> int:
    l, r = 0, len(height) - 1
    res = 0

    while l < r:
        area = min(height[l], height[r]) * (r - l)
        res = max(res, area)
        if height[l] < height[r]:
            l += 1
        else:
            r -= 1
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

Greedy two-pointer shrink in O(N) time.

#LC 42 • 4B. Two Pointers

Trapping Rain Water

Hard LeetCode
1. Problem Statement

Given n non-negative integers representing elevation map, compute how much water it can trap after raining.

2. Understanding & Key Observations

Water trapped at i = max(0, min(max_left, max_right) - height[i]).

3. Naive Solution — Basic Approach

Precompute maxLeft[i] and maxRight[i] arrays.

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(N)

Requires two aux arrays of size N.

5. Intuition — For Optimization

Two pointers l, r tracking leftMax and rightMax scalars in O(1) space!

6. Approach — Step-by-Step Algorithm
  1. Pointers l = 0, r = len(height) - 1. leftMax = height[l], rightMax = height[r].
  2. While l < r: if leftMax < rightMax: l += 1; leftMax = max(leftMax, height[l]); res += leftMax - height[l].
  3. Else: r -= 1; rightMax = max(rightMax, height[r]); res += rightMax - height[r].
7. Optimized Code (Python 3)
Python 3 Implementation 
def trap(height: list[int]) -> int:
    if not height: return 0
    l, r = 0, len(height) - 1
    leftMax, rightMax = height[l], height[r]
    res = 0

    while l < r:
        if leftMax < rightMax:
            l += 1
            leftMax = max(leftMax, height[l])
            res += leftMax - height[l]
        else:
            r -= 1
            rightMax = max(rightMax, height[r])
            res += rightMax - height[r]
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

Two-pointer space optimized water calculation.

#LC 424 • 4C. Sliding Window

Longest Repeating Character Replacement

Medium LeetCode
1. Problem Statement

Given string s and integer k, return max length of substring containing same letter after substituting at most k characters.

2. Understanding & Key Observations

Window [l, r] is valid iff (window_len - max_frequency_in_window) <= k.

3. Naive Solution — Basic Approach

Check all N^2 window ranges.

4. Time & Space Complexity Analysis (Naive)
Time: O(26 * N^2) Space: O(1)

Subproblem window scans.

5. Intuition — For Optimization

Sliding window dynamically tracking max character frequency maxf. Shrink l when (r-l+1) - maxf > k.

6. Approach — Step-by-Step Algorithm
  1. Frequency map count = {}, l = 0, maxf = 0, res = 0.
  2. For r in range(len(s)): count[s[r]] = 1 + count.get(s[r], 0); maxf = max(maxf, count[s[r]]).
  3. While (r - l + 1) - maxf > k: count[s[l]] -= 1; l += 1.
  4. Update res = max(res, r - l + 1).
7. Optimized Code (Python 3)
Python 3 Implementation 
def characterReplacement(s: str, k: int) -> int:
    count = {}
    res = 0
    l = 0
    maxf = 0

    for r in range(len(s)):
        count[s[r]] = 1 + count.get(s[r], 0)
        maxf = max(maxf, count[s[r]])

        while (r - l + 1) - maxf > k:
            count[s[l]] -= 1
            l += 1

        res = max(res, r - l + 1)
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(26)

Sliding window with frequency map.

4. Time & Space Complexity Analysis (Naive)

Substring search brute force.

6. Approach — Step-by-Step Algorithm
  1. Maps countT = Counter(t), window = {}. have = 0, need = len(countT).
  2. Expand r: update window[c]. If c in countT and window[c] == countT[c]: have += 1.
  3. While have == need: update min window result. Pop s[l]: if window[s[l]] < countT[s[l]] decrement have. l += 1.

def minWindow(s: str, t: str) -> str:
    if not t or not s: return ""
    countT, window = {}, {}
    for c in t: countT[c] = 1 + countT.get(c, 0)

    have, need = 0, len(countT)
    res, resLen = [-1, -1], float("inf")
    l = 0
    for r in range(len(s)):
        c = s[r]
        window[c] = 1 + window.get(c, 0)
        if c in countT and window[c] == countT[c]:
            have += 1

        while have == need:
            if (r - l + 1) < resLen:
                res = [l, r]
                resLen = r - l + 1
            window[s[l]] -= 1
            if s[l] in countT and window[s[l]] < countT[s[l]]:
                have -= 1
            l += 1
    l, r = res
    return s[l : r + 1] if resLen != float("inf") else ""

from collections import deque

def maxSlidingWindow(nums: list[int], k: int) -> list[int]:
    output = []
    q = deque()
    l = r = 0
    
    while r < len(nums):
        while q and nums[q[-1]] < nums[r]:
            q.pop()
        q.append(r)
        
        if l > q[0]:
            q.popleft()
            
        if (r + 1) >= k:
            output.append(nums[q[0]])
            l += 1
        r += 1
        
    return output

LRU Cache

Medium LeetCode
1. Problem Statement

Design a Least Recently Used (LRU) cache with O(1) get and put ops.

2. Understanding & Key Observations

Combine HashMap (key -> Node) with Doubly Linked List (maintains LRU at left, MRU at right).

3. Naive Solution — Basic Approach

4. Time & Space Complexity Analysis (Naive)
Time: O(1) Space: O(Capacity)

Language built-in structure.

5. Intuition — For Optimization

Doubly Linked List node insertion and removal takes O(1) time.

6. Approach — Step-by-Step Algorithm
  1. DLL nodes with prev and next. Dummy left (LRU) and right (MRU) pointers.
  2. get(key): remove node from list, insert at right (MRU), return value.
  3. put(key, val): if key exists remove old node. Insert new node at right. If capacity exceeded, remove left.next (LRU) from map and list.
7. Optimized Code (Python 3)
Python 3 Implementation 
class Node:
    def __init__(self, key, val):
        self.key, self.val = key, val
        self.prev = self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}  # key -> node
        self.left, self.right = Node(0, 0), Node(0, 0)
        self.left.next, self.right.prev = self.right, self.left

    def remove(self, node):
        prev, nxt = node.prev, node.next
        prev.next, nxt.prev = nxt, prev

    def insert(self, node):
        prev, nxt = self.right.prev, self.right
        prev.next = nxt.prev = node
        node.prev, node.next = prev, nxt

    def get(self, key: int) -> int:
        if key in self.cache:
            self.remove(self.cache[key])
            self.insert(self.cache[key])
            return self.cache[key].val
        return -1

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.remove(self.cache[key])
        self.cache[key] = Node(key, value)
        self.insert(self.cache[key])

        if len(self.cache) > self.cap:
            lru = self.left.next
            self.remove(lru)
            del self.cache[lru.key]
