Contains Duplicate

Easy LeetCode
1. Problem Statement

Given an integer array nums, return true if any value appears at least twice in the array, and return false if every element is distinct.

2. Understanding & Key Observations

Need to determine if any elements repeat. Naive pairwise comparison takes quadratic time, while keeping track of seen elements using a hash set enables instant O(1) lookups.

3. Naive Solution — Brute Force

Compare every pair of elements using nested loops.

class Solution:
    def containsDuplicate(self, nums):
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] == nums[j]:
                    return True

        return False

                if sorted(group[0]) == sorted_word:
                    group.append(word)
                    found = True
                    break

            if not found:
                groups.append([word])

        return groups

            nodes[i].next = nodes[i + 1];
        }
        if (nodes) {
            nodes[-1].next = null;
        }
        return nodes[0] if nodes else null;
    }
}

5. Intuition — For Optimization

In-place group reversal: check if k nodes exist using helper get_kth. Reverse group and reconnect links.

6. Approach — Step-by-Step Algorithm
  1. Use dummy = ListNode(0, head), group_prev = dummy.
  2. Find kth node: kth = get_kth(group_prev, k). If None, break.
  3. Save group_next = kth.next.
  4. Reverse subsegment from group_prev.next to group_next.
  5. Reconnect group_prev.next and set group_prev for next group.

Core Algorithmic Building Blocks

The 8 essential mental frameworks that solve all 31 Array, String & Linked List interview problems.

1. Fast Lookup & Membership

Use a Hash Set when checking if an element was previously seen in O(1) time (LC 217, LC 128).

2. Frequency Signatures

Convert string character counts into fixed 26-element tuples as HashMap keys for anagram grouping (LC 242, LC 49, LC 567).

3. Two Pointers Converge / Move

On sorted arrays or symmetric boundaries, converge left & right inward to eliminate O(N²) pair searches (LC 125, LC 167, LC 15, LC 11).

4. Sliding Window Expansion / Shrink

Expand right until window is valid, then shrink left while maintaining running validity metrics (LC 3, LC 424, LC 76).

5. Monotonic Deque

Maintain a deque of indices in strictly decreasing order to answer range maximum queries over moving windows in O(1) amortized time (LC 239).

6. Fast & Slow Pointer Cycle Detection

Floyd's Tortoise & Hare algorithm detects cycles in linked lists and implicit value-index pointer graphs in O(1) space (LC 141, LC 287).

7. Dummy Head Node Pointer Manipulation

Eliminate null-pointer edge cases during list creation, deletion, or merging by prepending a dummy = ListNode(0, head) (LC 21, LC 19, LC 2, LC 25).

8. Interleaved Node Interweaving

Avoid extra O(N) hash map memory by cloning nodes directly next to originals (A -> A' -> B -> B') (LC 138, LC 143).
