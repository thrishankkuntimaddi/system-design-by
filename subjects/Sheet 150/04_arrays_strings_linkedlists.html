#LC 217 • 4A. Arrays & Hashing

Contains Duplicate

Easy LeetCode
1. Problem Statement

Given an integer array nums, return true if any value appears at least twice in the array, and return false if every element is distinct.

2. Understanding & Key Observations

Need to determine if any elements repeat. Naive pairwise comparison takes quadratic time, while keeping track of seen elements using a hash set enables instant O(1) lookups.

3. Naive Solution — Brute Force

Compare every pair of elements using nested loops.

Naive Solution (Python 3) 
class Solution:
    def containsDuplicate(self, nums):
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] == nums[j]:
                    return True

        return False
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(1)
5. Intuition — For Optimization

Need to know whether something was seen before → Hash Set for O(1) membership check.

6. Approach — Step-by-Step Algorithm
  1. Initialize an empty hash set seen.
  2. Iterate through each number in nums.
  3. If current number is in seen, return True.
  4. Otherwise, insert number into seen.
  5. Return False after scanning all elements.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def containsDuplicate(self, nums):
        seen = set()

        for num in nums:
            if num in seen:
                return True

            seen.add(num)

        return False
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Need to know whether something was seen before → Hash Set

Valid Anagram

Easy LeetCode
1. Problem Statement

Given two strings s and t, return true if t is an anagram of s, and false otherwise.

2. Understanding & Key Observations

An anagram uses the exact same characters with identical frequencies.

3. Naive Solution — Brute Force

Sort both strings and compare character by character.

Naive Solution (Python 3) 
class Solution:
    def isAnagram(self, s, t):
        return sorted(s) == sorted(t)
4. Time & Space Complexity Analysis (Naive)
Time: O(n log n) Space: O(n)
5. Intuition — For Optimization

Count character frequencies using a hash map or fixed array of size 26.

6. Approach — Step-by-Step Algorithm
  1. If lengths differ, return False immediately.
  2. Build a frequency count hash map for string s.
  3. Decrement counts while iterating through string t.
  4. If any count goes negative or character missing, return False.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def isAnagram(self, s, t):
        if len(s) != len(t):
            return False

        count = {}

        for char in s:
            count[char] = count.get(char, 0) + 1

        for char in t:
            if char not in count:
                return False

            count[char] -= 1

            if count[char] < 0:
                return False

        return True
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(k)
9. Pattern / Key Takeaway

Pattern — Character frequency → Hash Map / Fixed Array

#LC 1 • 4A. Arrays & Hashing

Two Sum

Easy LeetCode
1. Problem Statement

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

2. Understanding & Key Observations

Find indices i and j such that nums[i] + nums[j] == target.

3. Naive Solution — Brute Force

Check every pair (i, j) using two nested loops.

Naive Solution (Python 3) 
class Solution:
    def twoSum(self, nums, target):
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i, j]

        return []
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(1)
5. Intuition — For Optimization

As we iterate, store previously seen numbers and their indices in a hash map to check for complement target - current.

6. Approach — Step-by-Step Algorithm
  1. Create empty hash map seen storing val -> index.
  2. For each number, compute complement = target - num.
  3. If complement in seen, return [seen[complement], current_index].
  4. Otherwise store seen[num] = current_index.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def twoSum(self, nums, target):
        seen = {}

        for i, num in enumerate(nums):
            complement = target - num

            if complement in seen:
                return [seen[complement], i]

            seen[num] = i

        return []
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Complement lookup (target - current) → Hash Map

#LC 49 • 4A. Arrays & Hashing

Group Anagrams

Medium LeetCode
1. Problem Statement

Given an array of strings strs, group the anagrams together in any order.

2. Understanding & Key Observations

Strings that are anagrams share identical character counts.

3. Naive Solution — Brute Force

Sort each word and compare against sorted versions of existing groups.

Naive Solution (Python 3) 
class Solution:
    def groupAnagrams(self, strs):
        groups = []

        for word in strs:
            found = False
            sorted_word = sorted(word)

            for group in groups:
                if sorted(group[0]) == sorted_word:
                    group.append(word)
                    found = True
                    break

            if not found:
                groups.append([word])

        return groups
4. Time & Space Complexity Analysis (Naive)
Time: O(n² × k log k) Space: O(nk)
5. Intuition — For Optimization

Convert an object's structural characteristics into a hashable signature (26-element character count tuple) as key.

6. Approach — Step-by-Step Algorithm
  1. Use hash map mapping count_tuple -> list_of_words.
  2. For each string, build character frequency array of length 26.
  3. Convert array to tuple key = tuple(count).
  4. Append string to groups[key] and return groups.values().
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def groupAnagrams(self, strs):
        groups = {}

        for word in strs:
            count = [0] * 26

            for char in word:
                count[ord(char) - ord('a')] += 1

            key = tuple(count)

            if key not in groups:
                groups[key] = []

            groups[key].append(word)

        return list(groups.values())
8. Time and Space Complexity Analysis (Optimized)
Time: O(nk) Space: O(nk)
9. Pattern / Key Takeaway

Pattern — Hashable signature / character frequency key → Hash Map

#LC 347 • 4A. Arrays & Hashing

Top K Frequent Elements

Medium LeetCode
1. Problem Statement

Given an integer array nums and an integer k, return the k most frequent elements.

2. Understanding & Key Observations

Count frequencies and extract top k most frequent numbers.

3. Naive Solution — Brute Force

Count frequencies with a map, sort map items by count descending, pick first k.

Naive Solution (Python 3) 
class Solution:
    def topKFrequent(self, nums, k):
        count = {}

        for num in nums:
            count[num] = count.get(num, 0) + 1

        items = sorted(
            count.items(),
            key=lambda x: x[1],
            reverse=True
        )

        return [num for num, freq in items[:k]]
4. Time & Space Complexity Analysis (Naive)
Time: O(n log n) Space: O(n)
5. Intuition — For Optimization

Bucket Sort: frequency is bounded by n, so create array of buckets where index = frequency.

6. Approach — Step-by-Step Algorithm
  1. Build frequency hash map.
  2. Create list of buckets buckets of size n + 1.
  3. Populate buckets[freq].append(num).
  4. Iterate from frequency n down to 1, collecting elements until result length is k.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def topKFrequent(self, nums, k):
        count = {}

        for num in nums:
            count[num] = count.get(num, 0) + 1

        buckets = [[] for _ in range(len(nums) + 1)]

        for num, freq in count.items():
            buckets[freq].append(num)

        result = []

        for freq in range(len(buckets) - 1, 0, -1):
            for num in buckets[freq]:
                result.append(num)

                if len(result) == k:
                    return result

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(n)
9. Pattern / Key Takeaway

Pattern — Frequency + ranking → Bucket Sort / Heap

#LC 238 • 4A. Arrays & Hashing

Product of Array Except Self

Medium LeetCode
1. Problem Statement

Given an integer array nums, return an array answer such that answer[i] is equal to the product of all elements except nums[i] without using division.

2. Understanding & Key Observations

answer[i] = (prefix product before i) * (suffix product after i).

3. Naive Solution — Brute Force

For each index i, iterate over entire array to multiply all elements except i.

Naive Solution (Python 3) 
class Solution:
    def productExceptSelf(self, nums):
        result = []

        for i in range(len(nums)):
            product = 1

            for j in range(len(nums)):
                if i != j:
                    product *= nums[j]

            result.append(product)

        return result
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(n)
5. Intuition — For Optimization

Compute prefix products left-to-right, then multiply suffix products right-to-left in a single output array.

6. Approach — Step-by-Step Algorithm
  1. Initialize result array of size n filled with 1s.
  2. Pass 1: Traverse left-to-right, storing running prefix product in result[i].
  3. Pass 2: Traverse right-to-left, multiplying running suffix product into result[i].
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def productExceptSelf(self, nums):
        n = len(nums)
        result = [1] * n

        prefix = 1

        for i in range(n):
            result[i] = prefix
            prefix *= nums[i]

        suffix = 1

        for i in range(n - 1, -1, -1):
            result[i] *= suffix
            suffix *= nums[i]

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Aux Space: O(1) [Output O(n)]
9. Pattern / Key Takeaway

Pattern — Prefix + Suffix running products

#LC 36 • 4A. Arrays & Hashing

Valid Sudoku

Medium LeetCode
1. Problem Statement

Determine if a 9x9 Sudoku board is valid according to row, column, and 3x3 sub-box rules.

2. Understanding & Key Observations

No duplicate digits (1-9) allowed in any row, column, or 3x3 sub-box.

3. Naive Solution — Brute Force

Check rows, columns, and 3x3 boxes in separate iterative passes.

Naive Solution (Python 3) 
class Solution:
    def isValidSudoku(self, board):
        n = 9

        for r in range(n):
            seen = set()

            for c in range(n):
                if board[r][c] == ".":
                    continue

                if board[r][c] in seen:
                    return False

                seen.add(board[r][c])

        for c in range(n):
            seen = set()

            for r in range(n):
                if board[r][c] == ".":
                    continue

                if board[r][c] in seen:
                    return False

                seen.add(board[r][c])

        for box_r in range(0, n, 3):
            for box_c in range(0, n, 3):
                seen = set()

                for r in range(box_r, box_r + 3):
                    for c in range(box_c, box_c + 3):
                        if board[r][c] == ".":
                            continue

                        if board[r][c] in seen:
                            return False

                        seen.add(board[r][c])

        return True
4. Time & Space Complexity Analysis (Naive)
Time: O(1) [Fixed 9x9] Space: O(1) [Fixed 9x9]
5. Intuition — For Optimization

Track row, column, and box constraints simultaneously in a single matrix pass using 9 sets each.

6. Approach — Step-by-Step Algorithm
  1. Maintain 9 sets for rows, 9 sets for columns, and 9 sets for boxes.
  2. Sub-box index formula: box = (r // 3) * 3 + (c // 3).
  3. Iterate cell (r, c). If value in rows[r], cols[c], or boxes[box], return False.
  4. Insert value into respective sets.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def isValidSudoku(self, board):
        rows = [set() for _ in range(9)]
        cols = [set() for _ in range(9)]
        boxes = [set() for _ in range(9)]

        for r in range(9):
            for c in range(9):
                value = board[r][c]

                if value == ".":
                    continue

                box = (r // 3) * 3 + (c // 3)

                if value in rows[r]:
                    return False

                if value in cols[c]:
                    return False

                if value in boxes[box]:
                    return False

                rows[r].add(value)
                cols[c].add(value)
                boxes[box].add(value)

        return True
8. Time and Space Complexity Analysis (Optimized)
Time: O(1) [Fixed 9x9] Space: O(1) [Fixed 9x9]
9. Pattern / Key Takeaway

Pattern — Multiple simultaneous constraints → Multiple Hash Sets

Encode and Decode Strings

Medium LeetCode
1. Problem Statement

Design an algorithm to encode a list of strings to a single string and decode it back.

2. Understanding & Key Observations

Must handle arbitrary characters including delimiter symbols like # within input strings.

3. Naive Solution — Brute Force

Join using a simple delimiter like '#'. Fails on inputs containing '#'.

Naive Solution (Python 3) 
class Codec:

    def encode(self, strs):
        return "#".join(strs)

    def decode(self, s):
        return s.split("#")
4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(N)
5. Intuition — For Optimization

Prefix each string with its integer length followed by a delimiter (e.g., 5#hello) to read exact byte counts safely.

6. Approach — Step-by-Step Algorithm
  1. Encode: For each word, append str(len(word)) + '#' + word.
  2. Decode: Read digits until # to get length L.
  3. Extract next L characters as word, advance pointer by L.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Codec:

    def encode(self, strs):
        result = ""

        for word in strs:
            result += str(len(word)) + "#" + word

        return result

    def decode(self, s):
        result = []
        i = 0

        while i < len(s):
            j = i

            while s[j] != "#":
                j += 1

            length = int(s[i:j])

            j += 1

            result.append(
                s[j:j + length]
            )

            i = j + length

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)
9. Pattern / Key Takeaway

Pattern — Serialization → Length prefix + delimiter

#LC 128 • 4A. Arrays & Hashing

Longest Consecutive Sequence

Medium LeetCode
1. Problem Statement

Given an unsorted array of integers nums, return the length of the longest consecutive elements sequence in O(n) time.

2. Understanding & Key Observations

Sequence numbers must increase by 1 consecutive step.

3. Naive Solution — Brute Force

For every number, iteratively search if current + 1 exists in list.

Naive Solution (Python 3) 
class Solution:
    def longestConsecutive(self, nums):
        longest = 0

        for num in nums:
            current = num
            length = 1

            while current + 1 in nums:
                current += 1
                length += 1

            longest = max(longest, length)

        return longest
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(1)
5. Intuition — For Optimization

Put numbers in a set. Only initiate sequence count if num - 1 is NOT in set (i.e. start of sequence).

6. Approach — Step-by-Step Algorithm
  1. Convert nums into set numbers.
  2. Iterate elements in numbers.
  3. If num - 1 not in numbers, start counting sequence num + length in numbers.
  4. Update longest = max(longest, length).
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def longestConsecutive(self, nums):
        numbers = set(nums)
        longest = 0

        for num in numbers:

            if num - 1 not in numbers:
                length = 1

                while num + length in numbers:
                    length += 1

                longest = max(
                    longest,
                    length
                )

        return longest
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) avg Space: O(n)
9. Pattern / Key Takeaway

Pattern — Hash Set + Sequence Start Condition (num - 1 not in set)

#LC 125 • 4B. Two Pointers

Valid Palindrome

Easy LeetCode
1. Problem Statement

Determine if a string is a palindrome considering only alphanumeric characters and ignoring cases.

2. Understanding & Key Observations

Ignore spaces and punctuation; check if string equals its reverse.

3. Naive Solution — Brute Force

Filter alphanumeric characters into a new string and reverse it.

Naive Solution (Python 3) 
class Solution:
    def isPalindrome(self, s):
        cleaned = ""

        for char in s:
            if char.isalnum():
                cleaned += char.lower()

        return cleaned == cleaned[::-1]
4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(n)
5. Intuition — For Optimization

Use two pointers converging inward from left and right ends, skipping non-alphanumeric characters in O(1) space.

6. Approach — Step-by-Step Algorithm
  1. Initialize left = 0, right = len(s) - 1.
  2. Advance left while not s[left].isalnum().
  3. Decrement right while not s[right].isalnum().
  4. Compare lowercased characters. If match, move both pointers inward.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def isPalindrome(self, s):
        left = 0
        right = len(s) - 1

        while left < right:

            while left < right and not s[left].isalnum():
                left += 1

            while left < right and not s[right].isalnum():
                right -= 1

            if s[left].lower() != s[right].lower():
                return False

            left += 1
            right -= 1

        return True
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(1)
9. Pattern / Key Takeaway

Pattern — Inward converging Two Pointers

#LC 167 • 4B. Two Pointers

Two Sum II — Input Array Is Sorted

Medium LeetCode
1. Problem Statement

Given a 1-indexed sorted array of integers numbers, find two numbers that add up to target.

2. Understanding & Key Observations

Array is already sorted in non-decreasing order.

3. Naive Solution — Brute Force

Try every pair with two nested loops.

Naive Solution (Python 3) 
class Solution:
    def twoSum(self, numbers, target):
        for i in range(len(numbers)):
            for j in range(i + 1, len(numbers)):
                if numbers[i] + numbers[j] == target:

        return []
4. Time & Space Complexity Analysis (Naive)

  2. Compute total = numbers[left] + numbers[right].
  3. If total == target, return 1-based indices [left + 1, right + 1].
  4. If total < target, move left += 1. Else move right -= 1.

Optimized Solution (Python 3) 
class Solution:

        right = len(numbers) - 1

            total = numbers[left] + numbers[right]

            if total == target:
                return [left + 1, right + 1]

            if total < target:
                left += 1
            else:
                right -= 1

        return []

#LC 15 • 4B. Two Pointers

3Sum

Medium LeetCode
1. Problem Statement

Find all unique triplets [nums[i], nums[j], nums[k]] such that i != j != k and nums[i] + nums[j] + nums[k] == 0.

2. Understanding & Key Observations

Triplets must sum to zero and contain no duplicate triplets in output.

3. Naive Solution — Brute Force

Triple nested loop + set of sorted tuples to eliminate duplicates.

Naive Solution (Python 3) 
class Solution:
    def threeSum(self, nums):
        result = set()
        n = len(nums)

        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    if nums[i] + nums[j] + nums[k] == 0:
                        result.add(
                            tuple(sorted(
                                [nums[i], nums[j], nums[k]]
                            ))
                        )

        return [list(x) for x in result]
4. Time & Space Complexity Analysis (Naive)
Time: O(n³) Space: O(n)
5. Intuition — For Optimization

Sort array. Fix index i, then use two pointers left and right to solve Two Sum II for remainder. Skip duplicate values.

6. Approach — Step-by-Step Algorithm
  1. Sort nums.
  2. Loop i from 0 to n-3. Skip if nums[i] == nums[i-1].
  3. Run Two Pointers on left = i+1, right = n-1.
  4. When match found, append triplet and advance both pointers past duplicate values.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def threeSum(self, nums):
        nums.sort()
        result = []

        n = len(nums)

        for i in range(n - 2):

            if i > 0 and nums[i] == nums[i - 1]:
                continue

            left = i + 1
            right = n - 1

            while left < right:
                total = (
                    nums[i]
                    + nums[left]
                    + nums[right]
                )

                if total == 0:
                    result.append([
                        nums[i],
                        nums[left],
                        nums[right]
                    ])

                    left += 1
                    right -= 1

                    while (
                        left < right
                        and nums[left] == nums[left - 1]
                    ):
                        left += 1

                    while (
                        left < right
                        and nums[right] == nums[right + 1]
                    ):
                        right -= 1

                elif total < 0:
                    left += 1

                else:
                    right -= 1

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(n²) Aux Space: O(1)
9. Pattern / Key Takeaway

Pattern — 3Sum = Sort + Fix One + Two Sum

#LC 11 • 4B. Two Pointers

Container With Most Water

Medium LeetCode
1. Problem Statement

Given an integer array height, find two lines that together with the x-axis form a container containing the most water.

2. Understanding & Key Observations

Area = (right - left) * min(height[left], height[right]).

3. Naive Solution — Brute Force

Check area between all pairs of vertical lines.

Naive Solution (Python 3) 
class Solution:
    def maxArea(self, height):
        answer = 0

        for i in range(len(height)):
            for j in range(i + 1, len(height)):
                width = j - i

                area = width * min(
                    height[i],
                    height[j]
                )

                answer = max(answer, area)

        return answer
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(1)
5. Intuition — For Optimization

Start with widest pointers (left=0, right=n-1). To potentially increase area as width shrinks, move the pointer pointing to the shorter line.

6. Approach — Step-by-Step Algorithm
  1. Place left = 0, right = len(height) - 1.
  2. Compute area = (right - left) * min(height[left], height[right]).
  3. Update answer = max(answer, area).
  4. If height[left] < height[right], move left += 1; else right -= 1.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def maxArea(self, height):
        left = 0
        right = len(height) - 1

        answer = 0

        while left < right:
            width = right - left

            area = width * min(
                height[left],
                height[right]
            )

            answer = max(answer, area)

            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return answer
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(1)
9. Pattern / Key Takeaway

Pattern — Shrinking width → Discard pointer with smaller height

#LC 42 • 4B. Two Pointers

Trapping Rain Water

Hard LeetCode
1. Problem Statement

Given n non-negative integers representing an elevation map where width of each bar is 1, compute how much water it can trap after raining.

2. Understanding & Key Observations

Water trapped at index i = min(max_left, max_right) - height[i].

3. Naive Solution — Brute Force

For every position, scan left and right to find maximum wall heights.

Naive Solution (Python 3) 
class Solution:
    def trap(self, height):

A cycle exists if a node's next pointer visits a previously seen node.

3. Naive Solution — Brute Force

Store visited node references in a hash set.

Naive Solution (Python 3) 
class Solution:
    def hasCycle(self, head):
        visited = set()

        while head:
            if head in visited:
                return True

            visited.add(head)
            head = head.next

        return False
4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(n)
5. Intuition — For Optimization

Floyd's Tortoise and Hare: fast pointer moves 2 steps, slow pointer moves 1 step. If cycle exists, fast will catch slow.

6. Approach — Step-by-Step Algorithm
  1. Set slow = head, fast = head.
  2. While fast and fast.next exist:
  3. Advance slow = slow.next, fast = fast.next.next.
  4. If slow == fast, return True.
  5. Return False if loop finishes.

1. Problem Statement

Given an array of integers nums containing n + 1 integers where each integer is in range [1, n], find the duplicate number without modifying array in O(1) space.

2. Understanding & Key Observations

Map array indices to values as an implicit linked list: index -> nums[index].

3. Naive Solution — Brute Force

Use a hash set to track seen numbers.

Naive Solution (Python 3) 
class Solution:
    def findDuplicate(self, nums):
        seen = set()

        for num in nums:
            if num in seen:
                return num

            seen.add(num)

        return -1
4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(n)
5. Intuition — For Optimization

Treat array as implicit linked list. The duplicate number represents the entrance to a cycle. Apply Floyd's Cycle Detection in 2 phases.

6. Approach — Step-by-Step Algorithm
  1. Phase 1: slow = nums[0], fast = nums[0]. Move slow = nums[slow] and fast = nums[nums[fast]] until they meet.
  2. Phase 2: Reset slow = nums[0]. Advance both pointers 1 step at a time until they meet at cycle entry point.
  3. Return entry point value.

Optimized Solution (Python 3) 
class Solution:
    def findDuplicate(self, nums):
        slow = nums[0]
        fast = nums[0]

        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]

            if slow == fast:
                break

        slow = nums[0]

        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]

        return slow

LRU Cache

Medium LeetCode
1. Problem Statement

Design a data structure that follows the constraints of a Least Recently Used (LRU) cache with O(1) get and put.

2. Understanding & Key Observations

Lookup in O(1) + Order update in O(1) + Eviction in O(1).

3. Naive Solution — Brute Force

Use a hash map for key-value store and a list for access order (O(n) list removal).

Naive Solution (Python 3) 
class LRUCache:

    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = {}
        self.order = []

    def get(self, key):
        if key not in self.cache:
            return -1

        self.order.remove(key)
        self.order.append(key)

        return self.cache[key]

    def put(self, key, value):
        if key in self.cache:
            self.order.remove(key)

        self.cache[key] = value
        self.order.append(key)

        if len(self.cache) > self.capacity:
            oldest = self.order.pop(0)
            del self.cache[oldest]
4. Time & Space Complexity Analysis (Naive)
Get: O(n), Put: O(n) Space: O(capacity)
5. Intuition — For Optimization

HashMap for O(1) key-to-node lookup + Doubly Linked List with dummy head/tail for O(1) node removal and insertion.

6. Approach — Step-by-Step Algorithm
  1. Use doubly linked list nodes (key, value, prev, next).
  2. Dummy left (LRU) and right (Most Recent).
  3. get(key): remove node from list, insert at right, return value.
  4. put(key, val): remove existing if present, insert new node at right. If capacity exceeded, remove left.next node from list & cache.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Node:
    def __init__(self, key=0, value=0):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None


class LRUCache:

    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = {}

        self.left = Node()
        self.right = Node()

        self.left.next = self.right
        self.right.prev = self.left

    def remove(self, node):
        previous = node.prev
        next_node = node.next

        previous.next = next_node
        next_node.prev = previous

    def insert(self, node):
        previous = self.right.prev

        previous.next = node
        node.prev = previous

        node.next = self.right
        self.right.prev = node

    def get(self, key):
        if key not in self.cache:
            return -1

        node = self.cache[key]

        self.remove(node)
        self.insert(node)

        return node.value

    def put(self, key, value):
        if key in self.cache:
            self.remove(self.cache[key])

        node = Node(key, value)

        self.cache[key] = node
        self.insert(node)

        if len(self.cache) > self.capacity:
            lru = self.left.next

            self.remove(lru)
            del self.cache[lru.key]

Get: O(1), Put: O(1) Space: O(capacity)

#LC 25 • 4D. Linked List

Reverse Nodes in k-Group

Hard LeetCode
1. Problem Statement

Reverse the nodes of a linked list k at a time and return its modified list.

2. Understanding & Key Observations

Reverse groups of size k in-place; if remaining nodes < k, keep as is.

3. Naive Solution — Brute Force

Store node references in array, reverse sub-slices of length k, reconnect pointers.

Naive Solution (Python 3) 
class Solution:
    def reverseKGroup(self, head, k):
        nodes = []

        current = head

        while current:
            nodes.append(current)
            current = current.next

        for start in range(0, len(nodes), k):
            end = min(
                start + k,
                len(nodes)
            )

            if end - start < k:
                break

            nodes[start:end] = reversed(
                nodes[start:end]
            )

        for i in range(len(nodes) - 1):
            nodes[i].next = nodes[i + 1]

        if nodes:
            nodes[-1].next = None

        return nodes[0] if nodes else None
4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(n)
5. Intuition — For Optimization

In-place group reversal: check if k nodes exist using helper get_kth. Reverse group and reconnect links.

6. Approach — Step-by-Step Algorithm
  1. Use dummy = ListNode(0, head), group_prev = dummy.
  2. Find kth node: kth = get_kth(group_prev, k). If None, break.
  3. Save group_next = kth.next.
  4. Reverse subsegment from group_prev.next to group_next.
  5. Reconnect group_prev.next and set group_prev for next group.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def reverseKGroup(self, head, k):

        def get_kth(node, k):
            while node and k > 0:
                node = node.next
                k -= 1

            return node

        dummy = ListNode(0, head)
        group_prev = dummy

        while True:
            kth = get_kth(group_prev, k)

            if not kth:
                break

            group_next = kth.next

            # Reverse group
            previous = group_next
            current = group_prev.next

            while current != group_next:
                next_node = current.next

                current.next = previous

                previous = current
                current = next_node

            old_start = group_prev.next

            group_prev.next = kth
            group_prev = old_start

        return dummy.next
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Aux Space: O(1)
9. Pattern / Key Takeaway
