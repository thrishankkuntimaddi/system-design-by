#LC 136 • 12. Bit Manipulation

Single Number

Easy LeetCode
1. Problem Statement

Every number in the array appears exactly twice except one. Find that single number. You must solve it in O(n) time and O(1) space.

2. Understanding & Key Observations

XOR has two golden properties: x ^ x = 0 (pairs cancel) and x ^ 0 = x (identity). XOR-ing all elements causes every duplicate pair to vanish, leaving only the unique number.

3. Naive Solution — Brute Force

Use a hash set: add unseen numbers, remove them when seen a second time. Whatever remains is the answer.

class Solution:
    def singleNumber(self, nums):
        seen = set()

        for num in nums:
            if num in seen:
                seen.remove(num)
            else:
                seen.add(num)

        return seen.pop()
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        unordered_set<int> seen;
        for (auto num : nums) {
            if (seen.count(num)) {
                seen.remove(num);
            }
            else:;
            seen.insert(num);
        }
        return seen.pop_back();
    }
};

    public int singleNumber(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int num : nums) {
            if (seen.contains(num)) {
                seen.remove(num);

4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(n)
5. Intuition — For Optimization

XOR all elements together. Paired numbers cancel to 0. The single unpaired number XOR'd with 0 returns itself.

6. Approach — Step-by-Step Algorithm
  1. Initialize answer = 0.
  2. For each num in nums: answer ^= num.
  3. Return answer.
7. Optimized Code (Python 3)

Time: O(n) Space: O(1)
9. Pattern / Key Takeaway

Pattern — Pairs + one unique → XOR all elements (x ^ x = 0, x ^ 0 = x)

#LC 191 • 12. Bit Manipulation

Number of 1 Bits

Easy LeetCode
1. Problem Statement

Given an unsigned integer, return the number of set bits (1s) in its binary representation (Hamming weight).

2. Understanding & Key Observations

n & (n-1) clears the lowest set bit. Repeating this until n == 0 tells us exactly how many 1-bits exist — one iteration per set bit, not per total bit.

3. Naive Solution — Brute Force

Check all 32 bits one by one using n & 1 and right-shift.

class Solution:
    def hammingWeight(self, n):
        count = 0

        for _ in range(32):
            if n & 1:
                count += 1

            n >>= 1

        return count
class Solution {
public:
    int hammingWeight(int n) {
        count = 0;
        for (int _ = 0; _ < 32; ++_) {
            if (n & 1) {
                count += 1;
            }
            n >>= 1;
        }
        return count;
    }
};
class Solution {
    public int hammingWeight(int n) {
        count = 0;
        for (int _ = 0; _ < 32; ++_) {
            if (n & 1) {
                count += 1;
            }
            n >>= 1;
        }
        return count;
    }
}
4. Time & Space Complexity Analysis (Naive)
Time: O(32) = O(1) Space: O(1)
5. Intuition — For Optimization

n - 1 flips the lowest set bit and all bits below it. So n & (n-1) removes exactly the lowest 1-bit. Each iteration costs one set bit — loop runs exactly k times where k is the Hamming weight.

6. Approach — Step-by-Step Algorithm
  1. Initialize count = 0.
  2. While n != 0: n &= n - 1; count += 1.
  3. Return count.
7. Optimized Code (Python 3)

Time: O(k) — k = number of set bits Space: O(1)
9. Pattern / Key Takeaway

Pattern — n & (n-1) removes the lowest set bit — loop runs once per 1-bit

#LC 338 • 12. Bit Manipulation

Counting Bits

Easy LeetCode
1. Problem Statement

Given n, return an array of length n+1 where result[i] is the number of 1-bits in i.

2. Understanding & Key Observations

Right-shifting a number by 1 removes its last bit: num >> 1 has the same 1-bits as num minus the contribution of its last bit. So bits[num] = bits[num >> 1] + (num & 1) — build on already-computed results.

3. Naive Solution — Brute Force

For each number 0..n, count its 1-bits independently using n & (n-1).

class Solution:
    def countBits(self, n):
        result = []

        for num in range(n + 1):
            count = 0
            x = num

            while x:
                x &= x - 1
                count += 1

            result.append(count)

        return result
class Solution {
public:
    vector<vector<int>> countBits(int n) {
        vector<vector<int>> result;
        for (int num = 0; num < n + 1; ++num) {
            count = 0;
            x = num;
            while (x) {
                x &= x - 1;
                count += 1;
            }
            result.push_back(count);
        }
        return result;
    }
};
class Solution {
    public List<List<Integer>> countBits(int n) {
        List<List<Integer>> result = new ArrayList<>();
        for (int num = 0; num < n + 1; ++num) {
            count = 0;
            x = num;
            while (x) {
                x &= x - 1;
                count += 1;
            }
            result.add(count);
        }
        return result;
    }
}
4. Time & Space Complexity Analysis (Naive)
Time: O(n log n) Space: O(n) output
5. Intuition — For Optimization

DP recurrence: bits[num] = bits[num >> 1] + (num & 1). Removing the last bit gives a smaller number whose bit count is already known.

6. Approach — Step-by-Step Algorithm
  1. Initialize result = [0] * (n + 1).
  2. For num in range(1, n+1):
  3. result[num] = result[num >> 1] + (num & 1).
  4. Return result.
7. Optimized Code (Python 3)

#LC 190 • 12. Bit Manipulation

Reverse Bits

Easy LeetCode
1. Problem Statement

Reverse the bits of a given 32-bit unsigned integer and return the result.

2. Understanding & Key Observations

Extract the rightmost bit of n using n & 1, shift it into the leftmost available position of result using result <<= 1 then result |= n & 1, then right-shift n. Repeat 32 times.

3. Naive Solution — Brute Force

Build a binary string of n, reverse it, then reconstruct the integer.

class Solution:
    def reverseBits(self, n):
        binary = ""

        for _ in range(32):
            binary += str(n & 1)
            n >>= 1

        result = 0

        for bit in binary:
            result = (result << 1) | int(bit)

        return result
class Solution {
public:
    vector<int> reverseBits(int n) {
        binary = "";
        for (int _ = 0; _ < 32; ++_) {
            binary += str(n & 1);
            n >>= 1;
        }
        result = 0;
        for (auto bit : binary) {
            result = (result << 1) | int(bit);
        }
        return result;
    }
};
class Solution {

            binary += str(n & 1);
            n >>= 1;

4. Time & Space Complexity Analysis (Naive)
Time: O(32) = O(1) Space: O(32) = O(1)
5. Intuition — For Optimization

Per-iteration: shift result left to make room, OR in the lowest bit of n, then right-shift n. After 32 iterations the bits are fully reversed.

6. Approach — Step-by-Step Algorithm
  1. Initialize result = 0.
  2. Repeat 32 times: result <<= 1, result |= n & 1, n >>= 1.
  3. Return result.
7. Optimized Code (Python 3)

#LC 268 • 12. Bit Manipulation

Missing Number

Easy LeetCode
1. Problem Statement

Given an array containing n distinct numbers from [0, n], return the one missing number.

2. Understanding & Key Observations

XOR the complete range 0..n with every element of the array. Present numbers cancel in pairs; only the missing number has no partner to cancel with.

3. Naive Solution — Brute Force

Put all numbers in a set; scan 0..n for the missing one.

class Solution:
    def missingNumber(self, nums):
        n = len(nums)
        values = set(nums)

        for num in range(n + 1):
            if num not in values:
                return num

        return -1
class Solution {
public:
    bool missingNumber(vector<int>& nums) {
        n = nums.size();
        values = set(nums);
        for (int num = 0; num < n + 1; ++num) {
            if (num !in values) {
                return num;
            }
        }
        return -1;
    }
};
class Solution {
    public boolean missingNumber(int[] nums) {
        n = nums.length;
        values = set(nums);
        for (int num = 0; num < n + 1; ++num) {
            if (num !in values) {

            }
        }

4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(n)
5. Intuition — For Optimization

Start with answer = n. For each index i, XOR in both i and nums[i]. Every index 0..n-1 is covered, and each present number cancels. The missing number survives.

6. Approach — Step-by-Step Algorithm
  1. Initialize answer = n.
  2. For i, num in enumerate(nums): answer ^= i, answer ^= num.
  3. Return answer.
7. Optimized Code (Python 3)

#LC 371 • 12. Bit Manipulation

Sum of Two Integers

Medium LeetCode
1. Problem Statement

Calculate a + b without using the operators + or -.

2. Understanding & Key Observations

a ^ b computes the sum bit-by-bit ignoring carries. (a & b) << 1 produces the carry bits shifted into position. Repeat, treating the carry as the new addend, until there is no carry left.

3. Naive Solution — Brute Force

In Python, just return a + b — but this violates the constraint.

class Solution:
    def getSum(self, a, b):
        return a + b  # violates constraint
class Solution {
public:
    int getSum(int a, int b) {
        return a + b  # violates constraint;
    }
};
class Solution {
    public int getSum(int a, int b) {
        return a + b  # violates constraint;
    }
}
4. Time & Space Complexity Analysis (Naive)
Time: O(1) Space: O(1)
5. Intuition — For Optimization

Binary addition: XOR gives the digit sum without carry; AND gives where carries occur, shifted left one position. Mask to 32 bits to simulate fixed-width arithmetic. Handle sign extension at the end for negative results.

6. Approach — Step-by-Step Algorithm
  1. Set MASK = 0xFFFFFFFF (32 bits), MAX_INT = 0x7FFFFFFF.
  2. While b != 0: compute carry = (a & b) << 1.
  3. a = (a ^ b) & MASK, b = carry & MASK.
  4. If a <= MAX_INT return a, else return ~(a ^ MASK) (sign-extend negative).
7. Optimized Code (Python 3)
class Solution:
    def getSum(self, a, b):
        MASK = 0xFFFFFFFF
        MAX_INT = 0x7FFFFFFF

        while b != 0:
            carry = (a & b) << 1
            a = (a ^ b) & MASK
            b = carry & MASK

        if a <= MAX_INT:
            return a

        return ~(a ^ MASK)

#LC 7 • 12. Bit Manipulation

Reverse Integer

Medium LeetCode
1. Problem Statement

Given a signed 32-bit integer x, return x with its digits reversed. If the reversed value overflows the 32-bit signed range [-2³¹, 2³¹-1], return 0.

2. Understanding & Key Observations

Extract digits right-to-left using x % 10 and rebuild the reversed number using result * 10 + digit. Handle sign separately. Check overflow against 32-bit bounds before returning.

3. Naive Solution — Brute Force

Convert to string, reverse, convert back to int, then check overflow.

class Solution:
    def reverse(self, x):
        sign = -1 if x < 0 else 1
        x = abs(x)

        reversed_num = int(str(x)[::-1])
        reversed_num *= sign

        if (
            reversed_num < -(2 ** 31)
            or reversed_num > 2 ** 31 - 1
        ):
            return 0

        return reversed_num

5. Intuition — For Optimization

Digit extraction: x % 10 gives the last digit; x //= 10 removes it. Accumulate into result = result * 10 + digit. Multiply sign back in at the end and validate the 32-bit range.

6. Approach — Step-by-Step Algorithm
  1. Store sign = -1 if x < 0 else 1, then x = abs(x).
  2. Initialize result = 0.
  3. While x > 0: digit = x % 10, result = result * 10 + digit, x //= 10.
  4. result *= sign.
  5. If result is outside [-2³¹, 2³¹-1]: return 0; else return result.
7. Optimized Code (Python 3)

🔥 6 Bit Tricks to Memorize

These operations underlie every problem in this module. Learn the primitives, not the solutions.

Check last bit (parity)

n & 1
Returns 1 if odd, 0 if even. Used in LC 338 (Counting Bits) and LC 190 (Reverse Bits).

Remove lowest set bit

n &= n - 1
Clears the rightmost 1. Loop runs exactly k times where k = Hamming weight. Core of LC 191.

Power of 2 check

n > 0 and (n & (n-1)) == 0
Powers of 2 have exactly one 1-bit, so n-1 flips all lower bits and AND gives 0.

XOR cancellation

x ^ x = 0    x ^ 0 = x
Pairs cancel to 0; the lone value survives. Used directly in LC 136 and LC 268.

Bit shift arithmetic

n >> 1 → divide by 2 / strip last bit
n << 1 → multiply by 2 / shift left
Core of LC 338 DP and LC 190 reversal.

Binary addition with bits

a ^ b = sum without carry
(a & b) << 1 = carry bits
Repeat until carry = 0. That's all of LC 371.
