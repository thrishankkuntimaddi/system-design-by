#LC 136 • Bit Manipulation

Single Number

Easy LeetCode
1. Problem Statement

Given non-empty array of integers nums where every element appears twice except for one, find that single element.

2. Understanding & Key Observations

XOR property: a ^ a = 0 and a ^ 0 = a. XORing all numbers cancels out pairs, leaving single number!

3. Naive Solution — Basic Approach

Frequency HashSet / HashMap.

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(N)

Extra memory for hash set.

5. Intuition — For Optimization

XOR bitwise accumulation in O(1) space.

6. Approach — Step-by-Step Algorithm
  1. res = 0.
  2. For n in nums: res ^= n. Return res.
7. Optimized Code (Python 3)
Python 3 Implementation 
def singleNumber(nums: list[int]) -> int:
    res = 0
    for n in nums:
        res ^= n
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

XOR trick cancels duplicate pairs.

#LC 191 • Bit Manipulation

Number of 1 Bits

Easy LeetCode
1. Problem Statement

Write function taking positive integer n and returning number of set bits (Hamming weight).

2. Understanding & Key Observations

Trick: n & (n - 1) flips the lowest set bit to 0 in a single operation!

3. Naive Solution — Basic Approach

Shift all 32 bits one by one and check n & 1.

4. Time & Space Complexity Analysis (Naive)
Time: O(32) Space: O(1)

32 bit shifts.

5. Intuition — For Optimization

Brian Kernighan's Algorithm (n &= n - 1) loops ONLY as many times as set bits!

6. Approach — Step-by-Step Algorithm
  1. res = 0.
  2. While n: n &= (n - 1); res += 1. Return res.
7. Optimized Code (Python 3)
Python 3 Implementation 
def hammingWeight(n: int) -> int:
    res = 0
    while n:
        n &= (n - 1)
        res += 1
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(Set Bits) Space: O(1)

Brian Kernighan's bit clearing algorithm.

#LC 338 • Bit Manipulation

Counting Bits

Easy LeetCode
1. Problem Statement

Given integer n, return array ans of length n + 1 where ans[i] is number of 1's in binary representation of i.

2. Understanding & Key Observations

dp[i] = 1 + dp[i - offset] where offset is highest power of 2 <= i.

3. Naive Solution — Basic Approach

Count 1 bits for each number independently from 0 to N.

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(1)

O(N log N) bit counts.

5. Intuition — For Optimization

1D DP tabulating set bit count reusing previous power-of-two offset results.

6. Approach — Step-by-Step Algorithm
  1. dp = [0] * (n + 1); offset = 1.
  2. For i from 1..n: if offset * 2 == i offset = i; dp[i] = 1 + dp[i - offset].
7. Optimized Code (Python 3)
Python 3 Implementation 
def countBits(n: int) -> list[int]:
    dp = [0] * (n + 1)
    offset = 1

    for i in range(1, n + 1):
        if offset * 2 == i:
            offset = i
        dp[i] = 1 + dp[i - offset]

    return dp
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

1D DP offset technique.

#LC 190 • Bit Manipulation

Reverse Bits

Easy LeetCode
1. Problem Statement

Reverse bits of a given 32-bit unsigned integer.

2. Understanding & Key Observations

Extract bit at pos i using (n >> i) & 1, and shift left to (31 - i) position in result.

3. Naive Solution — Basic Approach

Convert to binary string, reverse string, convert back to int.

4. Time & Space Complexity Analysis (Naive)
Time: O(32) Space: O(32)

String conversion.

5. Intuition — For Optimization

Bitwise operations shift extracted bit directly to reverse position.

6. Approach — Step-by-Step Algorithm
  1. res = 0.
  2. For i from 0..31: bit = (n >> i) & 1; res = res | (bit << (31 - i)). Return res.
7. Optimized Code (Python 3)
Python 3 Implementation 
def reverseBits(n: int) -> int:
    res = 0
    for i in range(32):
        bit = (n >> i) & 1
        res = res | (bit << (31 - i))
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(1) Space: O(1)

32 bitwise shifts.

#LC 268 • Bit Manipulation

Missing Number

Easy LeetCode
1. Problem Statement

Given array nums containing n distinct numbers in range [0, n], return missing number.

2. Understanding & Key Observations

Sum formula: expected = n * (n + 1) // 2. Missing number = expected - sum(nums). OR XOR 0..n with array elements.

3. Naive Solution — Basic Approach

Sort array and check nums[i] != i.

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(1)

Sorting overhead.

5. Intuition — For Optimization

XOR 0..n with array elements in O(1) space without integer overflow.

6. Approach — Step-by-Step Algorithm
  1. res = len(nums).
  2. For i, n in enumerate(nums): res += (i - n). Return res.
7. Optimized Code (Python 3)
Python 3 Implementation 
def missingNumber(nums: list[int]) -> int:
    res = len(nums)
    for i, n in enumerate(nums):
        res += (i - n)
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

Single pass arithmetic sum.

#LC 371 • Bit Manipulation

Sum of Two Integers

Medium LeetCode
1. Problem Statement

Calculate sum of two integers a and b without using + or - operators.

2. Understanding & Key Observations

XOR a ^ b calculates sum without carry. AND (a & b) << 1 calculates carry!

3. Naive Solution — Basic Approach

Iterative incrementing.

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(1)

Linear increment.

5. Intuition — For Optimization

Adder logic using XOR for sum and AND-left-shift for carry with 32-bit mask handling in Python.

6. Approach — Step-by-Step Algorithm
  1. Mask 0xFFFFFFFF.
  2. While b != 0: carry = (a & b) << 1; a = (a ^ b) & mask; b = carry & mask.
  3. Return a if a <= 0x7FFFFFFF else ~(a ^ mask).
7. Optimized Code (Python 3)
Python 3 Implementation 
def getSum(a: int, b: int) -> int:
    mask = 0xFFFFFFFF
    while b != 0:
        tmp = (a & b) << 1
        a = (a ^ b) & mask
        b = tmp & mask
    return a if a <= 0x7FFFFFFF else ~(a ^ mask)
8. Time and Space Complexity Analysis (Optimized)
Time: O(1) Space: O(1)

Bitwise adder simulation.

#LC 7 • Bit Manipulation

Reverse Integer

Medium LeetCode
1. Problem Statement

Given signed 32-bit integer x, return x with its digits reversed. Return 0 if overflow [-2^31, 2^31 - 1].

2. Understanding & Key Observations

Pop digits from back: pop = x % 10. Push to reversed integer: res = res * 10 + pop. Check 32-bit bounds before pushing.

3. Naive Solution — Basic Approach

Convert to string, reverse string, convert back to int.

4. Time & Space Complexity Analysis (Naive)
Time: O(log X) Space: O(log X)

String conversion.

5. Intuition — For Optimization

Modulo 10 digit extraction and overflow bound checks.

6. Approach — Step-by-Step Algorithm
  1. Bound constants MIN = -2147483648, MAX = 2147483647.
  2. res = 0. While x: digit = math.fmod(x, 10); x = int(x / 10).
  3. Check overflow before multiplying res * 10. Return res.
7. Optimized Code (Python 3)
Python 3 Implementation 
import math

def reverse(x: int) -> int:
    MIN, MAX = -2147483648, 2147483647
    res = 0
    while x:
        digit = int(math.fmod(x, 10))
        x = int(x / 10)
        if res > MAX // 10 or (res == MAX // 10 and digit >= MAX % 10):
            return 0
        if res < MIN // 10 or (res == MIN // 10 and digit <= MIN % 10):
            return 0
        res = (res * 10) + digit
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(log X) Space: O(1)

Digit extraction with overflow checking.
