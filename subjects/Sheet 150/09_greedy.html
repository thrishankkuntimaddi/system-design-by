#LC 53 • 9. Greedy

Maximum Subarray

Medium LeetCode
1. Problem Statement

Given an integer array nums, find the contiguous subarray with the largest sum and return its sum.

2. Understanding & Key Observations

The key question at each position: is it better to extend the current running sum, or start fresh? Discarding negative prefixes is the locally-optimal choice that gives the globally optimal answer.

3. Naive Solution — Brute Force

Try every possible subarray. For each starting index, scan right and track the running sum.

class Solution:
    def maxSubArray(self, nums):
        answer = float("-inf")

        for i in range(len(nums)):
            total = 0

            for j in range(i, len(nums)):
                total += nums[j]
                answer = max(answer, total)

        return answer

4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(1)
5. Intuition — For Optimization

At each index, either extend the previous subarray or start a new one. If current + nums[i] < nums[i] the prefix actively hurts us — discard it. This is Kadane's Algorithm (also a 1-D DP recurrence).

6. Approach — Step-by-Step Algorithm
  1. Initialize current = answer = nums[0].
  2. Iterate i from index 1 to end.
  3. At each step: current = max(nums[i], current + nums[i]).
  4. Update answer = max(answer, current).
  5. Return answer.
7. Optimized Code (Python 3)

#LC 55 • 9. Greedy

Jump Game

Medium LeetCode
1. Problem Statement

Given array nums where nums[i] is the maximum jump length from index i, return True if you can reach the last index.

2. Understanding & Key Observations

All we need is whether the end is reachable — not how. At each index track the furthest position currently reachable. If we reach an index that exceeds our current reach, it's impossible.

3. Naive Solution — Brute Force

DFS from index 0: try every valid jump length recursively.

class Solution:
    def canJump(self, nums):
        n = len(nums)

        def dfs(index):
            if index >= n - 1:
                return True

            max_jump = nums[index]

            for jump in range(1, max_jump + 1):
                if dfs(index + jump):
                    return True

            return False

        return dfs(0)

        for (int jump = 1; jump < max_jump + 1; ++jump) {
            if (dfs(index + jump)) {
                return true;
            }
        }
        return false;

public:

        return dfs(0);

5. Intuition — For Optimization

Scan left-to-right maintaining farthest — the furthest index reachable so far. If i > farthest at any point, we are stranded.

6. Approach — Step-by-Step Algorithm
  1. Initialize farthest = 0.
  2. Iterate i from 0 to end.
  3. If i > farthest: return False (gap in reachability).
  4. Update farthest = max(farthest, i + nums[i]).
  5. After the loop, return True.

#LC 45 • 9. Greedy

Jump Game II

Medium LeetCode
1. Problem Statement

Given nums, return the minimum number of jumps to reach the last index. It is guaranteed you can always reach the end.

2. Understanding & Key Observations

Think of each jump as a BFS 'level'. Within the current jump's reach, find the position that extends the frontier farthest. When we exhaust the current level, increment jumps and start the next level.

3. Naive Solution — Brute Force

DFS trying all jump lengths from each position, tracking minimum jumps.

class Solution:
    def jump(self, nums):
        n = len(nums)
        answer = float("inf")

        def dfs(index, jumps):
            nonlocal answer

            if index >= n - 1:
                answer = min(answer, jumps)
                return

            if jumps >= answer:
                return

            for jump in range(1, nums[index] + 1):
                dfs(index + jump, jumps + 1)

        dfs(0, 0)

        return answer

    void dfs(int index, int jumps, vector<int>& nums) {
        nonlocal answer;
        if (index >= n - 1) {
            answer = min(answer, jumps);
            return;
        }
        if (jumps >= answer) {
            return;

4. Time & Space Complexity Analysis (Naive)
Time: O(2ⁿ) worst case Space: O(n)
5. Intuition — For Optimization

Greedy BFS: treat each jump as expanding to the next 'level'. Within the current range [prev_end+1 … current_end], find the furthest reach. When i == current_end you must jump — increment and extend.

6. Approach — Step-by-Step Algorithm
  1. Initialize jumps = 0, current_end = 0, farthest = 0.
  2. Iterate i from 0 to n-2 (last index never needs a jump from it).
  3. Update farthest = max(farthest, i + nums[i]).
  4. When i == current_end: increment jumps, set current_end = farthest.
  5. Return jumps.
7. Optimized Code (Python 3)

                farthest,
                i + nums[i]
            )

            if i == current_end:
                jumps += 1
                current_end = farthest

        return jumps

#LC 134 • 9. Greedy

Gas Station

Medium LeetCode
1. Problem Statement

Given gas[i] and cost[i] for a circular route, find the starting station index from which you can complete the full circuit (or return -1).

2. Understanding & Key Observations

If starting at s causes a fuel deficit at station i, then no station between s and i can work either — they inherit the same or worse prefix. Jump directly to i+1.

3. Naive Solution — Brute Force

Try every station as a start, simulate the full circuit for each.

class Solution:
    def canCompleteCircuit(self, gas, cost):
        n = len(gas)

        for start in range(n):
            fuel = 0
            possible = True

            for i in range(n):
                index = (start + i) % n
                fuel += gas[index]
                fuel -= cost[index]

                if fuel < 0:
                    possible = False
                    break

            if possible:
                return start

        return -1

public:

                    break;
                }
            }
            if (possible) {
                return start;
            }
        }
        return -1;
    }

4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(1)
5. Intuition — For Optimization

Two insights: (1) A solution exists if and only if sum(gas) >= sum(cost). (2) Whenever running fuel goes negative, every station from start to i is invalid — skip them all and try i+1.

6. Approach — Step-by-Step Algorithm
  1. If sum(gas) < sum(cost): return -1 immediately.
  2. Initialize start = 0, fuel = 0.
  3. Iterate each station i: add gas[i] - cost[i] to fuel.
  4. If fuel < 0: set start = i + 1, reset fuel = 0.
  5. Return start.

#LC 846 • 9. Greedy

Hand of Straights

Medium LeetCode
1. Problem Statement

Given an array of card values hand and an integer groupSize, return True if you can rearrange all cards into consecutive groups of size groupSize.

2. Understanding & Key Observations

The smallest available card must start a group — there is nothing smaller to put before it. Greedily consume groups starting from the minimum each time.

3. Naive Solution — Brute Force

Sort, then repeatedly remove groups starting from the smallest element using list.remove().

class Solution:
    def isNStraightHand(self, hand, groupSize):
        if len(hand) % groupSize != 0:
            return False

        hand.sort()

        while hand:
            first = hand[0]

            for value in range(first, first + groupSize):
                if value not in hand:
                    return False

                hand.remove(value)

        return True

4. Time & Space Complexity Analysis (Naive)
Time: O(n²) — list.remove() is O(n) Space: O(1) auxiliary
5. Intuition — For Optimization

Use a frequency map. Iterate sorted unique keys. For the smallest key with count > 0, try to consume frequency copies of each of the next groupSize cards. If any is short, return False.

6. Approach — Step-by-Step Algorithm
  1. Return False if len(hand) % groupSize != 0.
  2. Build count = Counter(hand).
  3. Iterate first in sorted(count).
  4. Skip if count[first] == 0.
  5. Set frequency = count[first].
  6. For each value in [first, first+groupSize): if count[value] < frequency return False; subtract frequency.
  7. Return True.
7. Optimized Code (Python 3)

#LC 1899 • 9. Greedy

Merge Triplets to Form Target Triplet

Medium LeetCode
1. Problem Statement

Given a list of triplets and a target triplet, you can merge any two triplets by taking the element-wise max. Return True if you can form the target.

2. Understanding & Key Observations

Merging uses max(), so any triplet where one coordinate exceeds the target can never be used — it would permanently overshoot that coordinate. Filter those out and check if the remaining triplets collectively cover every coordinate of the target.

3. Naive Solution — Brute Force

DFS trying all subsets: include or exclude each triplet, merge, and check against target.

class Solution:
    def mergeTriplets(self, triplets, target):
        n = len(triplets)

        def dfs(index, current):
            if current == target:
                return True

            if index == n:
                return False

            if dfs(index + 1, current):
                return True

            triplet = triplets[index]

            if all(
                triplet[i] <= target[i]
                for i in range(3)
            ):
                merged = [
                    max(current[i], triplet[i])
                    for i in range(3)
                ]

                if dfs(index + 1, merged):
                    return True

            return False

        return dfs(0, [0, 0, 0])

5. Intuition — For Optimization

Discard every triplet where any coordinate exceeds the target (merging would lock us above target). Among the remaining valid triplets, check whether we can find the exact target values at each coordinate position.

6. Approach — Step-by-Step Algorithm
  1. Initialize found = [False, False, False].
  2. For each triplet: if any triplet[i] > target[i], skip it entirely.
  3. Otherwise, for each position i: if triplet[i] == target[i], set found[i] = True.
  4. Return all(found).

#LC 763 • 9. Greedy

Partition Labels

Medium LeetCode
1. Problem Statement

Given string s, partition it into as many parts as possible so that each letter appears in at most one part. Return the lengths of each partition.

2. Understanding & Key Observations

Once a character appears in a partition, every later occurrence of that character must be in the same partition. Knowing each character's last occurrence lets us greedily expand a partition's boundary until it becomes self-contained.

3. Naive Solution — Brute Force

Scan partitions naively: expand each window until no character inside it has a last occurrence outside the window.

class Solution:
    def partitionLabels(self, s):
        result = []
        start = 0

        while start < len(s):
            chars = set()
            end = start

            while end < len(s):
                chars.add(s[end])

#LC 678 • 9. Greedy

Valid Parenthesis String

Medium LeetCode
1. Problem Statement

Given string s containing '(', ')', and '*' (where '*' can be '(', ')', or empty), return True if it is valid.

2. Understanding & Key Observations

Instead of branching on every '*', track the range of possible open-parenthesis balances: [low, high]. high < 0 means even the most optimistic interpretation is invalid. low == 0 at the end means there's at least one valid interpretation.

3. Naive Solution — Brute Force

Backtracking: try all three interpretations of each '*' recursively.

class Solution:
    def checkValidString(self, s):

        def dfs(index, balance):
            if balance < 0:
                return False

            if index == len(s):
                return balance == 0

            char = s[index]

            if char == "(":
                return dfs(index + 1, balance + 1)

            if char == ")":
                return dfs(index + 1, balance - 1)

            # Try '*' as '(', ')', or ''
            return (
                dfs(index + 1, balance + 1)
                or dfs(index + 1, balance - 1)
                or dfs(index + 1, balance)
            )

        return dfs(0, 0)

4. Time & Space Complexity Analysis (Naive)
Time: O(3ⁿ) Space: O(n) recursion
5. Intuition — For Optimization

Track a range [low, high] of possible open balances. '(' increments both. ')' decrements both. '*' shrinks low and grows high. If high < 0, definitely invalid. Clamp low at 0 (balance can't go below 0 in any valid string).

6. Approach — Step-by-Step Algorithm
  1. Initialize low = 0, high = 0.
  2. For each char in s:
  3. '(': low += 1; high += 1.
  4. ')': low -= 1; high -= 1.
  5. '*': low -= 1; high += 1.
  6. If high < 0: return False.
  7. Clamp: low = max(low, 0).
  8. Return low == 0.

🔥 5 Reusable Greedy Patterns

These patterns repeat across all Greedy problems in interviews. Recognise the shape, not just the problem.

Furthest Reachable

LC 55. Scan left-to-right. Maintain the furthest index reachable so far. If current index exceeds it — gap detected, return False.

Current Range → Next Range

LC 45. Within the current reachable range find the position that extends farthest. When the range is exhausted, move to the next. BFS without a queue.

Last Occurrence Boundary

LC 763. Pre-compute each character's last index. As you scan, expand the window boundary to cover every last occurrence seen. Commit a partition when i == end.

Candidate Elimination

LC 134 / LC 1899. Prove that a failed candidate eliminates an entire range of alternatives. Skip them all in O(1) and jump forward.

Track a Range of States

LC 678. Instead of branching into every possible state (exponential), track [min_possible, max_possible]. Collapses O(3ⁿ) to O(n) time and O(1) space.

🎯 The Central Greedy Question

"What information can I keep from the past that lets me safely discard all the choices I no longer need?"

Greedy doesn't mean reckless — it means proving that the locally optimal choice can never be improved by reconsidering earlier decisions. The moment you can articulate that proof for a problem, you've found the greedy solution.
