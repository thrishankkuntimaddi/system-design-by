#LC 53 • Greedy

Maximum Subarray

Medium LeetCode
1. Problem Statement

Find contiguous subarray with largest sum in integer array nums.

2. Understanding & Key Observations

Kadane's Algorithm: if running current sum becomes negative, reset it to 0.

3. Naive Solution — Basic Approach

Compute sum of all N^2 subarrays.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(1)

Nested loop sum.

5. Intuition — For Optimization

Negative prefix sums can never contribute to a maximum subarray sum.

6. Approach — Step-by-Step Algorithm
  1. maxSub = nums[0], curSum = 0.
  2. For n in nums: if curSum < 0 reset curSum = 0. curSum += n. maxSub = max(maxSub, curSum).
7. Optimized Code (Python 3)
Python 3 Implementation 
def maxSubArray(nums: list[int]) -> int:
    maxSub = nums[0]
    curSum = 0

    for n in nums:
        if curSum < 0:
            curSum = 0
        curSum += n
        maxSub = max(maxSub, curSum)
    return maxSub
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

Kadane's Algorithm.

#LC 55 • Greedy

Jump Game

Medium LeetCode
1. Problem Statement

Return true if you can reach last index starting at index 0.

2. Understanding & Key Observations

Work backwards! Target index goal starts at len(nums) - 1. If i + nums[i] >= goal, move goal to i.

3. Naive Solution — Basic Approach

Recursive DFS exploring all jump distances.

4. Time & Space Complexity Analysis (Naive)
Time: O(2^N) Space: O(N)

Exponential branching.

5. Intuition — For Optimization

Greedy backward shifting of target goal post in single pass.

6. Approach — Step-by-Step Algorithm
  1. Goal goal = len(nums) - 1.
  2. Loop i from len(nums) - 2 down to 0: if i + nums[i] >= goal update goal = i.
  3. Return goal == 0.
7. Optimized Code (Python 3)
Python 3 Implementation 
def canJump(nums: list[int]) -> bool:
    goal = len(nums) - 1

    for i in range(len(nums) - 2, -1, -1):
        if i + nums[i] >= goal:
            goal = i

    return goal == 0
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

Greedy backward shift.

#LC 45 • Greedy

Jump Game II

Medium LeetCode
1. Problem Statement

Return minimum number of jumps to reach last index.

2. Understanding & Key Observations

BFS level-by-level greedy search: current level window is [l, r]. Next level right boundary is max(i + nums[i]) for i in [l, r].

3. Naive Solution — Basic Approach

1-D DP array dp[i] = 1 + min(dp[i + j]).

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(N)

1D DP array.

5. Intuition — For Optimization

Implicit BFS sliding window ranges compute min jumps in linear O(N) time and O(1) space.

6. Approach — Step-by-Step Algorithm
  1. res = 0, l = 0, r = 0.
  2. While r < len(nums) - 1: furthest index farthest = max(i + nums[i] for i in range(l, r+1)). Update l = r + 1, r = farthest, res += 1.
7. Optimized Code (Python 3)
Python 3 Implementation 
def jump(nums: list[int]) -> int:
    res = 0
    l = r = 0

    while r < len(nums) - 1:
        farthest = 0
        for i in range(l, r + 1):
            farthest = max(farthest, i + nums[i])
        l = r + 1
        r = farthest
        res += 1

    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

Implicit BFS sliding window.

#LC 134 • Greedy

Gas Station

Medium LeetCode
1. Problem Statement

Return starting gas station index to complete circular circuit once clockwise. If impossible return -1.

2. Understanding & Key Observations

If sum(gas) < sum(cost), impossible return -1. Otherwise, if current tank becomes negative starting from start, reset start = i + 1.

3. Naive Solution — Basic Approach

Simulate circular route from every starting station.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(1)

Nested circuit simulation.

5. Intuition — For Optimization

Single pass greedy resetting start index when tank < 0.

6. Approach — Step-by-Step Algorithm
  1. If sum(gas) < sum(cost) return -1.
  2. total = 0, start = 0.
  3. For i in range(len(gas)): total += gas[i] - cost[i]. If total < 0: total = 0; start = i + 1.
  4. Return start.
7. Optimized Code (Python 3)
Python 3 Implementation 
def canCompleteCircuit(gas: list[int], cost: list[int]) -> int:
    if sum(gas) < sum(cost):
        return -1

    total = 0
    res = 0
    for i in range(len(gas)):
        total += (gas[i] - cost[i])
        if total < 0:
            total = 0
            res = i + 1
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

Single pass greedy solution.

#LC 846 • Greedy

Hand of Straights

Medium LeetCode
1. Problem Statement

Rearrange cards into groups of groupSize consecutive cards. Return true if possible.

2. Understanding & Key Observations

Always start group from SMALLEST card available in frequency map.

3. Naive Solution — Basic Approach

Sort array and search for consecutive groups removing elements from list.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(N)

List removal.

5. Intuition — For Optimization

Min-Heap + Frequency Hash Map guarantees smallest start card is processed first.

6. Approach — Step-by-Step Algorithm
  1. If len(hand) % groupSize != 0 return False.
  2. Count frequencies. Min-heap minH = list(count.keys()); heapify.
  3. While minH: first = minH[0]. For i from first to first + groupSize - 1: if i not in count return False; decrement frequency. Pop from heap when frequency reaches 0.
7. Optimized Code (Python 3)
Python 3 Implementation 
import heapq
from collections import Counter

def isNStraightHand(hand: list[int], groupSize: int) -> bool:
    if len(hand) % groupSize != 0:
        return False
        
    count = Counter(hand)
    minH = list(count.keys())
    heapq.heapify(minH)
    
    while minH:
        first = minH[0]
        for i in range(first, first + groupSize):
            if i not in count:
                return False
            count[i] -= 1
            if count[i] == 0:
                if i != minH[0]:
                    return False
                heapq.heappop(minH)
    return True
8. Time and Space Complexity Analysis (Optimized)
Time: O(N log N) Space: O(N)

Min-heap + Frequency counter.

#LC 1899 • Greedy

Merge Triplets to Form Target Triplet

Medium LeetCode
1. Problem Statement

Return true if you can form target triplet by taking elementwise max of selected triplets.

2. Understanding & Key Observations

Filter out any triplet where ANY element exceeds target (t[0] > target[0] or t[1] > target[1] or t[2] > target[2]).

3. Naive Solution — Basic Approach

Check all subset combinations of triplets.

4. Time & Space Complexity Analysis (Naive)
Time: O(2^N) Space: O(N)

Subsets.

5. Intuition — For Optimization

Track set of target indices matched by valid non-exceeding triplets.

6. Approach — Step-by-Step Algorithm
  1. Set good = set().
  2. For t in triplets: if t[0] > target[0] or t[1] > target[1] or t[2] > target[2] continue.
  3. For i, val in enumerate(t): if val == target[i]: good.add(i).
  4. Return len(good) == 3.
7. Optimized Code (Python 3)
Python 3 Implementation 
def mergeTriplets(triplets: list[list[int]], target: list[int]) -> bool:
    good = set()

    for t in triplets:
        if t[0] > target[0] or t[1] > target[1] or t[2] > target[2]:
            continue
        for i, v in enumerate(t):
            if v == target[i]:
                good.add(i)

    return len(good) == 3
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

Single pass filtering.

#LC 763 • Greedy

Partition Labels

Medium LeetCode
1. Problem Statement

Partition string into maximum number of parts so each letter appears in at most one part.

2. Understanding & Key Observations

Map each character to its LAST seen index in string. Expand current partition right boundary to max(last_index).

3. Naive Solution — Basic Approach

Build character occurrence ranges and run interval merging.

4. Time & Space Complexity Analysis (Naive)
Time: O(N log N) Space: O(N)

Interval sorting.

5. Intuition — For Optimization

HashMap storing last index of each character enables linear O(N) greedy partition.

6. Approach — Step-by-Step Algorithm
  1. Dict lastIndex = {c: i for i, c in enumerate(s)}.
  2. size = 0, end = 0, res = [].
  3. For i, c in enumerate(s): size += 1; end = max(end, lastIndex[c]). If i == end: append size to res; reset size = 0.
7. Optimized Code (Python 3)
Python 3 Implementation 
def partitionLabels(s: str) -> list[int]:
    lastIndex = {c: i for i, c in enumerate(s)}
    res = []
    size, end = 0, 0

    for i, c in enumerate(s):
        size += 1
        end = max(end, lastIndex[c])
        if i == end:
            res.append(size)
            size = 0
            
    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(26)

Single pass greedy partition.

#LC 678 • Greedy

Valid Parenthesis String

Medium LeetCode
1. Problem Statement

String contains '(', ')', '*' where '*' can be '(', ')' or empty. Return true if valid.

2. Understanding & Key Observations

Track range of possible open parenthesis count [leftMin, leftMax].

3. Naive Solution — Basic Approach

Branching DFS testing all 3 choices for every '*' wildcard.

4. Time & Space Complexity Analysis (Naive)
Time: O(3^N) Space: O(N)

Branching DFS.

5. Intuition — For Optimization

Greedy tracking of min and max open parenthesis counts in single pass.

6. Approach — Step-by-Step Algorithm
  1. leftMin = 0, leftMax = 0.
  2. For c in s: if c == '(' leftMin += 1; leftMax += 1; elif c == ')' leftMin -= 1; leftMax -= 1; else ('*') leftMin -= 1; leftMax += 1.
  3. If leftMax < 0 return False. Clamp leftMin = max(leftMin, 0).
  4. Return leftMin == 0.
7. Optimized Code (Python 3)
Python 3 Implementation 
def checkValidString(s: str) -> bool:
    leftMin, leftMax = 0, 0

    for c in s:
        if c == "(":
            leftMin, leftMax = leftMin + 1, leftMax + 1
        elif c == ")":
            leftMin, leftMax = leftMin - 1, leftMax - 1
        else:
            leftMin, leftMax = leftMin - 1, leftMax + 1
        if leftMax < 0:
            return False
        if leftMin < 0:
            leftMin = 0
            
    return leftMin == 0
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

Greedy range tracking in O(1) space.
