#LC 78 • Recursion & Backtracking

Subsets

Medium LeetCode
1. Problem Statement

Given an integer array nums containing unique elements, return all possible subsets (the power set). The solution must not contain duplicate subsets. The subsets can be returned in any order.

2. Understanding

For every element, we have two decisions: take or don't take. For n elements, there are 2^n possible subsets. Both naive binary decision-tree traversal and loop-based incremental backtracking generate all 2^n subsets.

3. Naive Solution

Generate every subset by recursively deciding whether to take or not take each element.

Naive Python Solution 
class Solution:
    def subsets(self, nums):
        result = []

        def backtrack(index, current):
            if index == len(nums):
                result.append(current[:])
                return

            # Don't take nums[index]
            backtrack(index + 1, current)

            # Take nums[index]
            current.append(nums[index])
            backtrack(index + 1, current)
            current.pop()

        backtrack(0, [])
        return result
4. Naive Complexity
Time: O(n × 2^n) Aux Space: O(n) recursion + current path Output Space: O(n × 2^n)

There are 2^n subsets, and copying each subset can take O(n).

5. Intuition — For Optimization

The standard optimized backtracking version builds subsets incrementally. At each level of recursion, append the current path to result, then try adding each remaining candidate starting from start index.

6. Algorithm / Approach
  1. Define backtrack(start, current).
  2. Every current state is a valid subset, so append a copy to result.
  3. Loop i from start to len(nums) - 1.
  4. Append nums[i] to current.
  5. Recurse with backtrack(i + 1, current).
  6. Pop nums[i] to backtrack.
7. Code — Python 3 (Optimized)
Optimized Python Solution 
class Solution:
    def subsets(self, nums):
        result = []

        def backtrack(start, current):
            result.append(current[:])

            for i in range(start, len(nums)):
                current.append(nums[i])
                backtrack(i + 1, current)
                current.pop()

        backtrack(0, [])
        return result
8. Optimized Complexity
Time: O(n × 2^n) Aux Space: O(n) Output Space: O(n × 2^n)
9. Pattern / Key Takeaway

Both have the same asymptotic complexity. The optimized version has a cleaner subset-generation pattern.

#LC 39 • Recursion & Backtracking

Combination Sum

Medium LeetCode
1. Problem Statement

Given candidates and target, find combinations whose sum equals target. Elements can be reused.

2. Understanding

Let T = target and k = len(candidates). The recursion depth can be approximately T when the smallest candidate is 1. We must avoid generating permutations of the same combination.

3. Naive Solution

Try every candidate at every step without pruning.

Naive Python Solution 
class Solution:
    def combinationSum(self, candidates, target):
        result = []

        def backtrack(current, total):
            if total == target:
                result.append(current[:])
                return

            if total > target:
                return

            for num in candidates:
                current.append(num)
                backtrack(current, total + num)
                current.pop()

        backtrack([], 0)
        return result
4. Naive Complexity
Time: O(k^T) worst case Aux Space: O(T) Output Space: depends on number of valid combinations

Recursion depth can be approximately T when the smallest candidate is 1.

5. Intuition — For Optimization

Use start index to avoid generating the same combination in different orders, and sort candidates to break the loop early when a candidate exceeds the remaining target.

6. Algorithm / Approach
  1. Sort candidates array.
  2. Define backtrack(start, remaining, current).
  3. If remaining == 0, append current[:] to result and return.
  4. Iterate i from start to len(candidates) - 1.
  5. If candidates[i] > remaining, break early (pruning).
  6. Append candidate, call backtrack(i, remaining - num, current) (pass i to allow reuse), and pop.
7. Code — Python 3 (Optimized)
Optimized Python Solution 
class Solution:
    def combinationSum(self, candidates, target):
        result = []
        candidates.sort()

        def backtrack(start, remaining, current):
            if remaining == 0:
                result.append(current[:])
                return

            for i in range(start, len(candidates)):
                num = candidates[i]

                if num > remaining:
                    break

                current.append(num)

                # i, not i + 1, because we can reuse the same number
                backtrack(i, remaining - num, current)

                current.pop()

        backtrack(0, target, [])
        return result
8. Optimized Complexity
Time: O(k^T) worst case Aux Space: O(T) Output Space: O(number of combinations × T)
9. Pattern / Key Takeaway

The important optimization is avoiding permutations of the same combination and pruning candidates larger than the remaining target.

#LC 46 • Recursion & Backtracking

Permutations

Medium LeetCode
1. Problem Statement

Generate all permutations of distinct numbers.

2. Understanding

Drawing tokens in different orders creates distinct permutations (n! arrangements). At each level, choose an unused element.

3. Naive Solution

At every level, scan the entire array and choose an unused element using if num in current, which costs O(n) per check.

Naive Python Solution 
class Solution:
    def permute(self, nums):
        result = []

        def backtrack(current):
            if len(current) == len(nums):
                result.append(current[:])
                return

            for num in nums:
                if num in current:
                    continue

                current.append(num)
                backtrack(current)
                current.pop()

        backtrack([])
        return result
4. Naive Complexity
Time: O(n × n!) Aux Space: O(n) Output Space: O(n × n!)

There are n! permutations, and checking membership with if num in current costs O(n).

5. Intuition — For Optimization

Use a boolean used[] array to keep track of used elements in O(1) time instead of checking membership in current path.

6. Algorithm / Approach
  1. Initialize used = [False] * len(nums).
  2. Define backtrack(current).
  3. If len(current) == len(nums), append copy to result.
  4. Loop i from 0 to len(nums) - 1. If used[i], skip.
  5. Set used[i] = True, append nums[i], recurse, pop, and set used[i] = False.
7. Code — Python 3 (Optimized)
Optimized Python Solution 
class Solution:
    def permute(self, nums):
        result = []
        used = [False] * len(nums)

        def backtrack(current):
            if len(current) == len(nums):
                result.append(current[:])
                return

            for i in range(len(nums)):
                if used[i]:
                    continue

                used[i] = True
                current.append(nums[i])

                backtrack(current)

                current.pop()
                used[i] = False

        backtrack([])
        return result
8. Optimized Complexity
Time: O(n × n!) Aux Space: O(n) Output Space: O(n × n!)
9. Pattern / Key Takeaway

Although the asymptotic time remains O(n × n!), the optimized solution removes the repeated O(n) membership search.

#LC 90 • Recursion & Backtracking

Subsets II

Medium LeetCode
1. Problem Statement

Array may contain duplicates. We need unique subsets.

2. Understanding

When input elements contain duplicates, standard subset branching generates identical subsets multiple times.

3. Naive Solution

Generate all 2^n subsets and put them into a set to eliminate duplicate subsets.

Naive Python Solution 
class Solution:
    def subsetsWithDup(self, nums):
        result = set()

        def backtrack(index, current):
            if index == len(nums):
                result.add(tuple(current))
                return

            # Don't take
            backtrack(index + 1, current)

            # Take
            current.append(nums[index])
            backtrack(index + 1, current)
            current.pop()

        backtrack(0, [])
        return [list(x) for x in result]
4. Naive Complexity
Time: O(n × 2^n) Aux Space: O(n) Output/Set Space: O(n × 2^n) worst case
5. Intuition — For Optimization

Sort the array and skip duplicate choices at the same recursion level.

6. Algorithm / Approach
  1. Sort nums.
  2. Define backtrack(start, current) and append current[:].
  3. Loop i from start to len(nums) - 1.
  4. If i > start and nums[i] == nums[i - 1], continue.
  5. Append nums[i], call backtrack(i + 1, current), and pop.
7. Code — Python 3 (Optimized)
Optimized Python Solution

    def subsetsWithDup(self, nums):
        nums.sort()
        result = []

        def backtrack(start, current):
            result.append(current[:])

            for i in range(start, len(nums)):
                if i > start and nums[i] == nums[i - 1]:
                    continue

                current.append(nums[i])
                backtrack(i + 1, current)
                current.pop()

        backtrack(0, [])
        return result
8. Optimized Complexity
Time: O(n × 2^n) worst case Aux Space: O(n) Output Space: O(n × 2^n) worst case
9. Pattern / Key Takeaway

Critical Pattern: if i > start and nums[i] == nums[i - 1]: continue
Skip duplicates at the same recursion level, but allow duplicates at different levels.

#LC 40 • Recursion & Backtracking

Combination Sum II

Medium LeetCode
1. Problem Statement

Each candidate can be used only once, and candidates may contain duplicates. Find unique combinations summing to target.

2. Understanding

Combines single-use constraint with duplicate candidate values. We cannot reuse an element (use i + 1) and must prune duplicate sibling choices.

3. Naive Solution

Generate combinations recursively and use a set to remove duplicates.

Naive Python Solution 
class Solution:
    def combinationSum2(self, candidates, target):
        result = set()
        candidates.sort()

        def backtrack(index, remaining, current):
            if remaining == 0:
                result.add(tuple(current))
                return

            if index == len(candidates) or remaining < 0:
                return

            # Don't choose
            backtrack(index + 1, remaining, current)

            # Choose
            current.append(candidates[index])
            backtrack(
                index + 1,
                remaining - candidates[index],
                current
            )
            current.pop()

        backtrack(0, target, [])
        return [list(x) for x in result]
4. Naive Complexity
Time: O(2^n × n) worst case Aux Space: O(n) Output/Set Space: O(2^n × n)
5. Intuition — For Optimization

Sort array, skip duplicate choices at the same level (i > start and candidates[i] == candidates[i - 1]), and prune when candidates[i] > remaining.

6. Algorithm / Approach
  1. Sort candidates.
  2. Define backtrack(start, remaining, current).
  3. If remaining == 0, append copy to result.
  4. Loop i from start to len(candidates) - 1.
  5. Skip duplicates at same level: if i > start and candidates[i] == candidates[i - 1]: continue.
  6. Break if candidates[i] > remaining.
  7. Recurse with i + 1 because each element can be used once.
7. Code — Python 3 (Optimized)
Optimized Python Solution 
class Solution:
    def combinationSum2(self, candidates, target):
        candidates.sort()
        result = []

        def backtrack(start, remaining, current):
            if remaining == 0:
                result.append(current[:])
                return

            for i in range(start, len(candidates)):
                # Skip duplicate choices at the same level
                if i > start and candidates[i] == candidates[i - 1]:
                    continue

                # Since sorted, no later value can work
                if candidates[i] > remaining:
                    break

                current.append(candidates[i])

                # i + 1 because each element can be used once
                backtrack(
                    i + 1,
                    remaining - candidates[i],
                    current
                )

                current.pop()

        backtrack(0, target, [])
        return result
8. Optimized Complexity
Time: O(2^n × n) worst case Aux Space: O(n) Output Space: O(number of valid combinations × n)
9. Pattern / Key Takeaway

Important Difference:
Combination Sum uses backtrack(i, ...) (can reuse the same element).
Combination Sum II uses backtrack(i + 1, ...) (cannot reuse it).

#LC 79 • Recursion & Backtracking

Word Search

Medium LeetCode
1. Problem Statement

Find whether a word exists in a grid by moving up/down/left/right.

2. Understanding

Let R = rows, C = columns, L = word length. The first character can start from R × C cells. After that, there are up to 4 choices initially and at most 3 choices afterward because we don't immediately revisit the previous cell.

3. Naive Solution

Try every cell as the starting position and recursively explore all four directions.

Naive Python Solution 
class Solution:
    def exist(self, board, word):
        rows = len(board)
        cols = len(board[0])

        def dfs(r, c, index):
            if index == len(word):
                return True

            if r < 0 or r >= rows or c < 0 or c >= cols:
                return False

            if board[r][c] != word[index]:
                return False

            original = board[r][c]
            board[r][c] = '#'

            found = (
                dfs(r + 1, c, index + 1) or
                dfs(r - 1, c, index + 1) or
                dfs(r, c + 1, index + 1) or
                dfs(r, c - 1, index + 1)
            )

            board[r][c] = original
            return found

        for r in range(rows):
            for c in range(cols):
                if dfs(r, c, 0):
                    return True

        return False
4. Naive Complexity
Time: O(R × C × 4 × 3^(L-1)) Aux Space: O(L)
5. Intuition — For Optimization

Prune impossible searches before DFS: check whether the word's character frequency exists in the board, search from the rarer end of the word (reverse if board_count[word[0]] > board_count[word[-1]]), and use in-place marking.

6. Algorithm / Approach
  1. Count character frequencies in board and word using Counter.
  2. If board lacks any character required by word, return False.
  3. If board_count[word[0]] > board_count[word[-1]], reverse word to start search from the rarer end.
  4. Run DFS from matching start cells using in-place '#' cell marking and backtracking.
7. Code — Python 3 (Optimized)
Optimized Python Solution 
from collections import Counter

class Solution:
    def exist(self, board, word):
        rows = len(board)
        cols = len(board[0])

        board_count = Counter(
            cell
            for row in board
            for cell in row
        )

        word_count = Counter(word)

        for char, count in word_count.items():
            if board_count[char] < count:
                return False

        # Start from the rarer character
        if board_count[word[0]] > board_count[word[-1]]:
            word = word[::-1]

        def dfs(r, c, index):
            if index == len(word):
                return True

            if (
                r < 0 or r >= rows or
                c < 0 or c >= cols or
                board[r][c] != word[index]
            ):
                return False

            temp = board[r][c]
            board[r][c] = '#'

            found = (
                dfs(r + 1, c, index + 1) or
                dfs(r - 1, c, index + 1) or
                dfs(r, c + 1, index + 1) or
                dfs(r, c - 1, index + 1)
            )

            board[r][c] = temp
            return found

        for r in range(rows):
            for c in range(cols):
                if board[r][c] == word[0]:
                    if dfs(r, c, 0):
                        return True

        return False
8. Optimized Complexity
Time: O(R × C × 4 × 3^(L-1)) Aux Space: O(L) Extra preprocessing: O(R × C + L)
9. Pattern / Key Takeaway

The optimization mainly improves practical pruning (character counting & rarer-end search), rather than changing the worst-case exponential bound.

#LC 131 • Recursion & Backtracking

Palindrome Partitioning

Medium LeetCode
1. Problem Statement

Partition a string such that every substring is a palindrome. Example for "aab": ["a", "a", "b"], ["aa", "b"].

2. Understanding

There can be exponentially many partitions. Checking substring palindromes on the fly adds repeated O(n) work.

3. Naive Solution

At every position, try every possible substring and check whether it is a palindrome with string == string[::-1].

Naive Python Solution 
class Solution:
    def partition(self, s):
        result = []

        def is_palindrome(string):
            return string == string[::-1]

        def backtrack(start, current):
            if start == len(s):
                result.append(current[:])
                return

            for end in range(start + 1, len(s) + 1):
                substring = s[start:end]

                if is_palindrome(substring):
                    current.append(substring)
                    backtrack(end, current)
                    current.pop()

        backtrack(0, [])
        return result
4. Naive Complexity
Time: O(n × 2^n) approximately Aux Space: O(n) Output Space: O(n × 2^n)

The palindrome check itself can cost O(n) per substring check.

5. Intuition — For Optimization

Precompute whether every substring is a palindrome using 2D Dynamic Programming in O(n^2) time before backtracking.

6. Algorithm / Approach
  1. Build 2D boolean array palindrome[n][n].
  2. Set single characters palindrome[i][i] = True.
  3. Fill DP table for lengths 2 to n: palindrome[left][right] = True if characters match and inner substring is palindrome.
  4. Backtrack from start = 0, using palindrome[start][end] for O(1) checks.
7. Code — Python 3 (Optimized)
Optimized Python Solution 
class Solution:
    def partition(self, s):
        n = len(s)

        palindrome = [[False] * n for _ in range(n)]

        for i in range(n):
            palindrome[i][i] = True

        for length in range(2, n + 1):
            for left in range(n - length + 1):
                right = left + length - 1

                if s[left] == s[right]:
                    if length == 2 or palindrome[left + 1][right - 1]:
                        palindrome[left][right] = True

        result = []

        def backtrack(start, current):
            if start == n:
                result.append(current[:])
                return

            for end in range(start, n):
                if palindrome[start][end]:
                    current.append(s[start:end + 1])
                    backtrack(end + 1, current)
                    current.pop()

        backtrack(0, [])
        return result
8. Optimized Complexity
Palindrome DP: O(n^2) Time: O(n^2 + n × 2^n) Aux Space: O(n^2) DP + O(n) recursion Output Space: O(n × 2^n)
9. Pattern / Key Takeaway

Precompute expensive repeated checks → Backtracking becomes cleaner and faster.

#LC 17 • Recursion & Backtracking

Letter Combinations of a Phone Number

Medium LeetCode
1. Problem Statement

Given digits 2–9, generate all possible letter combinations. Example for "23": ad, ae, af, bd, be, bf, cd, ce, cf.

2. Understanding

Each digit gives at most 4 choices. For n digits, total combinations is O(4^n).

3. Naive Solution

Build all combinations using recursion with a dictionary lookup for key mapping.

Naive Python Solution 
class Solution:
    def letterCombinations(self, digits):
        if not digits:
            return []

        phone = {
            '2': 'abc',
            '3': 'def',
            '4': 'ghi',
            '5': 'jkl',
            '6': 'mno',
            '7': 'pqrs',
            '8': 'tuv',
            '9': 'wxyz'
        }

        result = []

        def backtrack(index, current):
            if index == len(digits):
                result.append("".join(current))
                return

            for char in phone[digits[index]]:
                current.append(char)
                backtrack(index + 1, current)
                current.pop()

        backtrack(0, [])
        return result
4. Naive Complexity
Time: O(4^n × n) Aux Space: O(n) Output Space: O(4^n × n)
5. Intuition — For Optimization

Use a list of mappings and construct the string directly with index offsets (ord(digits[index]) - ord('0')).

6. Algorithm / Approach
  1. Return [] if digits is empty.
  2. Initialize array phone indexed from 0 to 9.
  3. Define backtrack(index, current).
  4. If index == len(digits), append "".join(current) to result.
  5. Get mapped string using phone[ord(digits[index]) - ord('0')].
  6. Loop through characters, append, recurse index + 1, and pop.
7. Code — Python 3 (Optimized)
Optimized Python Solution 
class Solution:
    def letterCombinations(self, digits):
        if not digits:
            return []

        phone = [
            "",
            "",
            "abc",
            "def",
            "ghi",
            "jkl",
            "mno",
            "pqrs",
            "tuv",
            "wxyz"

                current.pop()

        return result
8. Optimized Complexity
Time: O(4^n × n) Aux Space: O(n) Output Space: O(4^n × n)
9. Pattern / Key Takeaway

Again, the asymptotic complexity doesn't change much; the optimization is primarily cleaner/faster implementation.

#LC 51 • Recursion & Backtracking

N-Queens

Hard LeetCode
1. Problem Statement

Place n queens on an n × n board so that no two queens attack each other.

2. Understanding

At each row, we have up to n choices. Placements must be checked for column, positive diagonal (row + col), and negative diagonal (row - col) collisions.

3. Naive Solution

Try placing a queen in every column of every row, then check whether the board is valid with an is_safe helper function scanning the board in O(n) time.

Naive Python Solution 
class Solution:
    def solveNQueens(self, n):
        result = []
        board = [["."] * n for _ in range(n)]

        def is_safe(row, col):
            # Check column
            for r in range(row):
                if board[r][col] == "Q":
                    return False

            # Check upper-left diagonal
            r, c = row - 1, col - 1
            while r >= 0 and c >= 0:
                if board[r][c] == "Q":
                    return False
                r -= 1
                c -= 1

            # Check upper-right diagonal
            r, c = row - 1, col + 1
            while r >= 0 and c < n:
                if board[r][c] == "Q":
                    return False
                r -= 1
                c += 1

            return True

        def backtrack(row):
            if row == n:
                result.append(
                    ["".join(r) for r in board]
                )
                return

            for col in range(n):
                if is_safe(row, col):
                    board[row][col] = "Q"
                    backtrack(row + 1)
                    board[row][col] = "."

        backtrack(0)
        return result
4. Naive Complexity
Time: O(n^2 × n!) approx Aux Space: O(n^2) board + O(n) recursion Output Space: O(number of solutions × n^2)

At each row, we have up to n choices. The validity check costs O(n).

5. Intuition — For Optimization

Instead of scanning the board every time, maintain three sets: columns, positive diagonals (row + col), and negative diagonals (row - col). Then checking whether a position is safe becomes O(1).

6. Algorithm / Approach
  1. Initialize board and three hash sets: columns, positive_diagonals, negative_diagonals.
  2. Define backtrack(row). If row == n, add formatted board to result.
  3. Loop col from 0 to n - 1.
  4. If col in columns, row + col in positive_diagonals, or row - col in negative_diagonals, skip.
  5. Place "Q", add to all 3 sets, recurse row + 1, and then backtrack (remove "Q" and remove from sets).
7. Code — Python 3 (Optimized)
Optimized Python Solution 
class Solution:
    def solveNQueens(self, n):
        result = []

        board = [["."] * n for _ in range(n)]

        columns = set()
        positive_diagonals = set()  # row + col
        negative_diagonals = set()  # row - col

        def backtrack(row):
            if row == n:
                result.append(
                    ["".join(r) for r in board]
                )
                return

            for col in range(n):
                if col in columns:
                    continue

                if row + col in positive_diagonals:
                    continue

                if row - col in negative_diagonals:
                    continue

                # Place queen
                board[row][col] = "Q"
                columns.add(col)
                positive_diagonals.add(row + col)
                negative_diagonals.add(row - col)

                backtrack(row + 1)

                # Backtrack
                board[row][col] = "."
                columns.remove(col)
                positive_diagonals.remove(row + col)
                negative_diagonals.remove(row - col)

        backtrack(0)

        return result
8. Optimized Complexity
Safety Check: O(1) Time: O(n × n!) approx Aux Space: O(n^2) board + O(n) sets/recursion Output Space: O(number of solutions × n^2)
9. Pattern / Key Takeaway

Safety check is reduced to O(1) using sets for columns and diagonals. The search itself remains exponential (O(n × n!) approx).
