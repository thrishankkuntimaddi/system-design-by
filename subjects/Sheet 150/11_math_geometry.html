#LC 48 • Math & Geometry

Rotate Image

Medium LeetCode
1. Problem Statement

Rotate n x n 2D matrix by 90 degrees clockwise in-place.

2. Understanding & Key Observations

Two steps: 1) Transpose matrix (swap matrix[i][j] with matrix[j][i]); 2) Reverse each row!

3. Naive Solution — Basic Approach

Allocate new N x N matrix and set new_mat[j][n-1-i] = mat[i][j].

4. Time & Space Complexity Analysis (Naive)
Time: O(N^2) Space: O(N^2)

Allocates extra matrix.

5. Intuition — For Optimization

Transpose + Row Reversal achieves 90 degree clockwise rotation in O(1) extra space.

6. Approach — Step-by-Step Algorithm
  1. Transpose matrix: loop i from 0..N-1, j from i+1..N-1: swap matrix[i][j], matrix[j][i].
  2. Reverse each row: row.reverse() for row in matrix.
7. Optimized Code (Python 3)
Python 3 Implementation 
def rotate(matrix: list[list[int]]) -> None:
    N = len(matrix)
    # Transpose
    for i in range(N):
        for j in range(i + 1, N):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

    # Reverse rows
    for i in range(N):
        matrix[i].reverse()
8. Time and Space Complexity Analysis (Optimized)
Time: O(N^2) Space: O(1)

In-place matrix rotation.

#LC 54 • Math & Geometry

Spiral Matrix

Medium LeetCode
1. Problem Statement

Given an m x n matrix, return all elements of matrix in spiral order.

2. Understanding & Key Observations

Maintain 4 boundary pointers: left, right, top, bottom. Traverse perimeter clockwise, then shrink boundaries.

3. Naive Solution — Basic Approach

Simulation with visited boolean array tracking direction vectors.

4. Time & Space Complexity Analysis (Naive)
Time: O(M * N) Space: O(M * N)

Visited matrix.

5. Intuition — For Optimization

Four boundary pointers shrink grid inward clockwise.

6. Approach — Step-by-Step Algorithm
  1. Pointers left = 0, right = COLS-1, top = 0, bottom = ROWS-1.
  2. While left <= right and top <= bottom: traverse top row -> top += 1; traverse right col -> right -= 1; traverse bottom row -> bottom -= 1; traverse left col -> left += 1.
7. Optimized Code (Python 3)
Python 3 Implementation 
def spiralOrder(matrix: list[list[int]]) -> list[int]:
    res = []
    left, right = 0, len(matrix[0])
    top, bottom = 0, len(matrix)

    while left < right and top < bottom:
        # Top row
        for i in range(left, right):
            res.append(matrix[top][i])
        top += 1

        # Right col
        for i in range(top, bottom):
            res.append(matrix[i][right - 1])
        right -= 1

        if not (left < right and top < bottom):
            break

        # Bottom row
        for i in range(right - 1, left - 1, -1):
            res.append(matrix[bottom - 1][i])
        bottom -= 1

        # Left col
        for i in range(bottom - 1, top - 1, -1):
            res.append(matrix[i][left])
        left += 1

    return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(M * N) Space: O(1)

4 boundary pointer shrink.

#LC 73 • Math & Geometry

Set Matrix Zeroes

Medium LeetCode
1. Problem Statement

If an element is 0, set its entire row and column to 0 in-place.

2. Understanding & Key Observations

Use first row and first column of the matrix itself as marker indicators to achieve O(1) space!

3. Naive Solution — Basic Approach

Use separate boolean arrays row[M] and col[N].

4. Time & Space Complexity Analysis (Naive)
Time: O(M * N) Space: O(M + N)

Extra row/col arrays.

5. Intuition — For Optimization

First row and first col store 0-flags. Extra variable rowZero tracks if row 0 itself needs zeroing.

6. Approach — Step-by-Step Algorithm
  1. Flag rowZero = False.
  2. Pass 1: if matrix[r][c] == 0 set matrix[0][c] = 0 and if r > 0 set matrix[r][0] = 0 else rowZero = True.
  3. Pass 2: fill zeroes based on markers for r > 0, c > 0. Zero col 0 if matrix[0][0] == 0. Zero row 0 if rowZero == True.
7. Optimized Code (Python 3)
Python 3 Implementation 
def setZeroes(matrix: list[list[int]]) -> None:
    ROWS, COLS = len(matrix), len(matrix[0])
    rowZero = False

    for r in range(ROWS):
        for c in range(COLS):
            if matrix[r][c] == 0:
                matrix[0][c] = 0
                if r > 0:
                    matrix[r][0] = 0
                else:
                    rowZero = True

    for r in range(1, ROWS):
        for c in range(1, COLS):
            if matrix[0][c] == 0 or matrix[r][0] == 0:
                matrix[r][c] = 0

    if matrix[0][0] == 0:
        for r in range(ROWS):
            matrix[r][0] = 0

    if rowZero:
        for c in range(COLS):
            matrix[0][c] = 0
8. Time and Space Complexity Analysis (Optimized)
Time: O(M * N) Space: O(1)

In-place row/col marker storage.

Happy Number

Easy LeetCode
1. Problem Statement

Replace number by sum of squares of its digits repeatedly until it equals 1 (Happy) or loops infinitely in a cycle.

2. Understanding & Key Observations

Detect cycle using HashSet or Floyd's Fast/Slow Pointers!

3. Naive Solution — Basic Approach

HashSet of visited digit sums.

4. Time & Space Complexity Analysis (Naive)
Time: O(log N) Space: O(log N)

HashSet storage.

5. Intuition — For Optimization

Sum of squares of digits function sumSquare(n). Fast/slow pointers find cycles in O(1) space.

6. Approach — Step-by-Step Algorithm
  1. Helper sumSquare(n): return sum of int(digit)**2.
  2. Set visit = set(). While n not in visit: visit.add(n); n = sumSquare(n); if n == 1 return True.
  3. Return False.
7. Optimized Code (Python 3)
Python 3 Implementation 
def isHappy(n: int) -> bool:
    visit = set()

    def sumSquare(n):
        output = 0
        while n:
            digit = n % 10
            output += digit ** 2
            n = n // 10
        return output

    while n not in visit:
        visit.add(n)
        n = sumSquare(n)
        if n == 1:
            return True
    return False

Time: O(log N) Space: O(log N)

Plus One

Easy LeetCode
1. Problem Statement

Given large integer as digits array, increment integer by one and return resulting digits.

2. Understanding & Key Observations

Iterate backwards: if digits[i] < 9, increment and return. Else set digits[i] = 0.

3. Naive Solution — Basic Approach

Convert digits to string -> int -> increment -> digits array.

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(N)

String conversion.

5. Intuition — For Optimization

In-place digit modification with carry handling.

6. Approach — Step-by-Step Algorithm
  1. Loop i from len(digits)-1 down to 0: if digits[i] < 9 digits[i] += 1 and return digits. Else digits[i] = 0.
  2. If all 9s, return [1] + digits.
7. Optimized Code (Python 3)
Python 3 Implementation 
def plusOne(digits: list[int]) -> list[int]:
    for i in range(len(digits) - 1, -1, -1):
        if digits[i] < 9:
            digits[i] += 1
            return digits
        digits[i] = 0
    return [1] + digits
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(1)

In-place digit increment.

#LC 50 • Math & Geometry

Pow(x, n)

Medium LeetCode
1. Problem Statement

Calculate x raised to power n (i.e., x^n).

2. Understanding & Key Observations

Binary Exponentiation (Divide and Conquer): x^n = (x^2)^(n/2) if even; x * x^(n-1) if odd.

3. Naive Solution — Basic Approach

Multiply x by itself N times.

4. Time & Space Complexity Analysis (Naive)
Time: O(N) Space: O(1)

Linear loop.

5. Intuition — For Optimization

Binary Exponentiation reduces power computation from O(N) to O(log N).

6. Approach — Step-by-Step Algorithm
  1. Define helper(x, n): if x == 0 return 0; if n == 0 return 1.
  2. res = helper(x * x, n // 2). Return x * res if n % 2 else res.
  3. Main function: res = helper(x, abs(n)). Return res if n >= 0 else 1 / res.
7. Optimized Code (Python 3)
Python 3 Implementation 
def myPow(x: float, n: int) -> float:
    def helper(x, n):
        if x == 0: return 0
        if n == 0: return 1

        res = helper(x * x, n // 2)
        return x * res if n % 2 else res

    res = helper(x, abs(n))
    return res if n >= 0 else 1 / res
8. Time and Space Complexity Analysis (Optimized)
Time: O(log N) Space: O(log N)

Binary Exponentiation.

Multiply Strings

Medium LeetCode
1. Problem Statement

Given two non-negative integers num1 and num2 represented as strings, return product as string without built-in BigInt.

2. Understanding & Key Observations

Column-by-column multiplication. Result length is at most len(num1) + len(num2). Digit i times digit j affects position i + j and i + j + 1.

3. Naive Solution — Basic Approach

Convert string characters to integers manually using ord().

4. Time & Space Complexity Analysis (Naive)
Time: O(N * M) Space: O(N + M)

Column multiplication.

5. Intuition — For Optimization

Reverse strings and accumulate products into result array res[i + j].

6. Approach — Step-by-Step Algorithm
  1. If either string is "0" return "0".
  2. Array res = [0] * (len(num1) + len(num2)). Reverse both strings.
  3. Loop i, j: digit = int(num1[i]) * int(num2[j]); res[i + j] += digit; res[i + j + 1] += res[i + j] // 10; res[i + j] %= 10.
  4. Reverse res and trim leading zeroes.
7. Optimized Code (Python 3)
Python 3 Implementation 
def multiply(num1: str, num2: str) -> str:
    if "0" in [num1, num2]:
        return "0"

    res = [0] * (len(num1) + len(num2))
    num1, num2 = num1[::-1], num2[::-1]

    for i1 in range(len(num1)):
        for i2 in range(len(num2)):
            digit = int(num1[i1]) * int(num2[i2])
            res[i1 + i2] += digit
            res[i1 + i2 + 1] += res[i1 + i2] // 10
            res[i1 + i2] %= 10

    res, beg = res[::-1], 0
    while beg < len(res) and res[beg] == 0:
        beg += 1

    return "".join(map(str, res[beg:]))
8. Time and Space Complexity Analysis (Optimized)
Time: O(N * M) Space: O(N + M)

Standard long multiplication simulation.

#LC 2013 • Math & Geometry

Detect Squares

Medium LeetCode
1. Problem Statement

Design data structure supporting add(point) and count(point) (number of ways to choose 3 points forming axis-aligned square).

2. Understanding & Key Observations

For query point (px, py), find points (x, y) on diagonal (where abs(px - x) == abs(py - y) > 0). Third & fourth points are (px, y) and (x, py).

3. Naive Solution — Basic Approach

Check all 3-point combinations.

4. Time & Space Complexity Analysis (Naive)
Time: O(N^3) Space: O(N)

Combinatorial 3-point search.

5. Intuition — For Optimization

Frequency Map + Diagonal point search calculates total square configurations in O(Points) time.

6. Approach — Step-by-Step Algorithm
  1. Dict ptsCount = defaultdict(int), list pts = [].
  2. add(point): increment frequency and append point.
  3. count(point): for x, y in pts: if abs(py - y) != abs(px - x) or x == px or y == py continue. Multiply ptsCount[(x, py)] * ptsCount[(px, y)] and sum.
7. Optimized Code (Python 3)
Python 3 Implementation 
from collections import defaultdict

class DetectSquares:
    def __init__(self):
        self.ptsCount = defaultdict(int)
        self.pts = []

    def add(self, point: list[int]) -> None:
        self.ptsCount[tuple(point)] += 1
        self.pts.append(point)

    def count(self, point: list[int]) -> int:
        res = 0
        px, py = point
        for x, y in self.pts:
            if (abs(py - y) != abs(px - x)) or x == px or y == py:
                continue
            res += self.ptsCount[(x, py)] * self.ptsCount[(px, y)]
        return res
8. Time and Space Complexity Analysis (Optimized)
Time: O(N) Space: O(N)

Diagonal point scanning.
