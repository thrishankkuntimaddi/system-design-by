#LC 48 • 11. Math & Geometry

Rotate Image

Medium LeetCode
1. Problem Statement

Rotate an n × n matrix 90° clockwise in-place. You must do this without allocating another matrix.

2. Understanding & Key Observations

A 90° clockwise rotation maps matrix[r][c] → result[c][n-1-r]. Instead of allocating a new matrix, two sequential in-place operations achieve the same result: first transpose (flip across the main diagonal), then reverse each row.

3. Naive Solution — Brute Force

Allocate a second matrix, copy cells to their rotated positions, then copy back.

Naive Solution (Python 3) 
class Solution:
    def rotate(self, matrix):
        n = len(matrix)

        result = [
            [0] * n
            for _ in range(n)
        ]

        for r in range(n):
            for c in range(n):
                result[c][n - 1 - r] = matrix[r][c]

        for r in range(n):
            for c in range(n):
                matrix[r][c] = result[r][c]
4. Time & Space Complexity Analysis (Naive)
Time: O(n²) Space: O(n²)
5. Intuition — For Optimization

Two in-place operations compose to give a 90° rotation:

① Transpose: swap matrix[r][c] with matrix[c][r] for all r < c.
② Reverse each row: call row.reverse().

No extra memory needed.

6. Approach — Step-by-Step Algorithm
  1. Transpose: for r in range(n), for c in range(r+1, n): swap matrix[r][c] ↔ matrix[c][r].
  2. Reverse rows: for each row in matrix: row.reverse().
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def rotate(self, matrix):
        n = len(matrix)

        # Step 1 — Transpose
        for r in range(n):
            for c in range(r + 1, n):
                matrix[r][c], matrix[c][r] = (
                    matrix[c][r],
                    matrix[r][c]
                )

        # Step 2 — Reverse each row
        for row in matrix:
            row.reverse()
8. Time and Space Complexity Analysis (Optimized)
Time: O(n²) Space: O(1)
9. Pattern / Key Takeaway

Pattern — 90° clockwise = Transpose + Reverse rows (counter-clockwise = Transpose + Reverse columns)

#LC 54 • 11. Math & Geometry

Spiral Matrix

Medium LeetCode
1. Problem Statement

Given an m × n matrix, return all elements in spiral order.

2. Understanding & Key Observations

Track four boundaries: top, bottom, left, right. Process the outermost ring in four sweeps (→ ↓ ← ↑), then shrink boundaries inward and repeat.

3. Naive Solution — Brute Force

Use a visited boolean matrix and change direction when hitting a boundary or visited cell.

Naive Solution (Python 3) 
class Solution:
    def spiralOrder(self, matrix):
        rows = len(matrix)
        cols = len(matrix[0])
        visited = [
            [False] * cols
            for _ in range(rows)
        ]
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        result = []
        r = c = direction = 0

        for _ in range(rows * cols):
            result.append(matrix[r][c])
            visited[r][c] = True

            nr = r + directions[direction][0]
            nc = c + directions[direction][1]

            if (
                nr < 0 or nr >= rows
                or nc < 0 or nc >= cols
                or visited[nr][nc]
            ):
                direction = (direction + 1) % 4
                nr = r + directions[direction][0]
                nc = c + directions[direction][1]

            r, c = nr, nc

        return result
4. Time & Space Complexity Analysis (Naive)
Time: O(mn) Space: O(mn)
5. Intuition — For Optimization

Maintain four boundary variables. Process the current ring's four edges in order, then shrink each boundary inward. Guard against single-row or single-column cases before the ← and ↑ sweeps.

6. Approach — Step-by-Step Algorithm
  1. Initialize top=0, bottom=rows-1, left=0, right=cols-1.
  2. While top <= bottom and left <= right:
  3. → Append matrix[top][left..right]; increment top.
  4. ↓ Append matrix[top..bottom][right]; decrement right.
  5. ← If top <= bottom: append matrix[bottom][right..left] reversed; decrement bottom.
  6. ↑ If left <= right: append matrix[bottom..top][left] reversed; increment left.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def spiralOrder(self, matrix):
        result = []
        top = 0
        bottom = len(matrix) - 1
        left = 0
        right = len(matrix[0]) - 1

        while top <= bottom and left <= right:

            # Left → Right
            for c in range(left, right + 1):
                result.append(matrix[top][c])
            top += 1

            # Top → Bottom
            for r in range(top, bottom + 1):
                result.append(matrix[r][right])
            right -= 1

            if top <= bottom:
                # Right → Left
                for c in range(right, left - 1, -1):
                    result.append(matrix[bottom][c])
                bottom -= 1

            if left <= right:
                # Bottom → Top
                for r in range(bottom, top - 1, -1):
                    result.append(matrix[r][left])
                left += 1

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(mn) Space: O(1) auxiliary
9. Pattern / Key Takeaway

Pattern — Four shrinking boundaries — process outermost ring, collapse inward, repeat

#LC 73 • 11. Math & Geometry

Set Matrix Zeroes

Medium LeetCode
1. Problem Statement

Given an m × n matrix, if any cell is 0, set its entire row and column to 0. Do it in-place.

2. Understanding & Key Observations

Store which rows and columns need zeroing — but use the matrix itself as the storage. The first row and first column act as marker arrays. Handle them separately at the end.

3. Naive Solution — Brute Force

Use two sets to record which rows and columns contain zeros, then zero them.

Naive Solution (Python 3) 
class Solution:
    def setZeroes(self, matrix):
        rows = set()
        cols = set()

        for r in range(len(matrix)):
            for c in range(len(matrix[0])):
                if matrix[r][c] == 0:
                    rows.add(r)
                    cols.add(c)

        for r in rows:
            for c in range(len(matrix[0])):
                matrix[r][c] = 0

        for c in cols:
            for r in range(len(matrix)):
                matrix[r][c] = 0
4. Time & Space Complexity Analysis (Naive)
Time: O(mn) Space: O(m+n)
5. Intuition — For Optimization

Repurpose matrix[0][c] and matrix[r][0] as markers for columns and rows. Pre-check if the first row or column itself contains a zero so they can be handled last without ambiguity.

6. Approach — Step-by-Step Algorithm
  1. Check first_row_zero = any(matrix[0][c] == 0 for c) and first_col_zero = any(matrix[r][0] == 0 for r).
  2. For r in 1..rows, c in 1..cols: if matrix[r][c] == 0, set matrix[r][0] = 0 and matrix[0][c] = 0.
  3. Zero rows 1..rows where matrix[r][0] == 0.
  4. Zero cols 1..cols where matrix[0][c] == 0.
  5. If first_row_zero: zero entire row 0. If first_col_zero: zero entire col 0.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def setZeroes(self, matrix):
        rows = len(matrix)
        cols = len(matrix[0])

        first_row_zero = any(
            matrix[0][c] == 0
            for c in range(cols)
        )
        first_col_zero = any(
            matrix[r][0] == 0
            for r in range(rows)
        )

        # Use first row/col as markers
        for r in range(1, rows):
            for c in range(1, cols):
                if matrix[r][c] == 0:
                    matrix[r][0] = 0
                    matrix[0][c] = 0

        # Zero marked rows
        for r in range(1, rows):
            if matrix[r][0] == 0:
                for c in range(1, cols):
                    matrix[r][c] = 0

        # Zero marked columns
        for c in range(1, cols):
            if matrix[0][c] == 0:
                for r in range(1, rows):
                    matrix[r][c] = 0

        # Handle first row and column
        if first_row_zero:
            for c in range(cols):
                matrix[0][c] = 0

        if first_col_zero:
            for r in range(rows):
                matrix[r][0] = 0
8. Time and Space Complexity Analysis (Optimized)
Time: O(mn) Space: O(1)
9. Pattern / Key Takeaway

Pattern — Use the input matrix itself as metadata — repurpose first row and column as markers

#LC 202 • 11. Math & Geometry

Happy Number

Easy LeetCode
1. Problem Statement

A number is happy if repeatedly replacing it with the sum of the squares of its digits eventually reaches 1. Return True if the number is happy.

2. Understanding & Key Observations

An unhappy number never reaches 1 — it enters a cycle. The process of digit-squaring is a value transformation that either terminates at 1 or loops. Floyd's cycle detection handles both cases without storing visited states.

3. Naive Solution — Brute Force

Keep a seen set; stop when 1 is reached or a repeated value is detected.

Naive Solution (Python 3) 
class Solution:
    def isHappy(self, n):
        seen = set()

        while n != 1:
            if n in seen:
                return False

            seen.add(n)

            total = 0

            while n > 0:
                digit = n % 10
                total += digit * digit
                n //= 10

            n = total

        return True
4. Time & Space Complexity Analysis (Naive)
Time: O(log n) — bounded digit states Space: O(log n)
5. Intuition — For Optimization

Model the transformation as a linked-list-style sequence. A happy number converges to the cycle 1 → 1 → …; an unhappy number enters another cycle. Floyd's slow/fast pointers detect the cycle in O(1) space.

6. Approach — Step-by-Step Algorithm
  1. Define next_number(num): extract digits, return sum of their squares.
  2. Initialize slow = n, fast = next_number(n).
  3. While fast != 1 and slow != fast: advance slow one step, fast two steps.
  4. Return fast == 1.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def isHappy(self, n):

        def next_number(num):
            total = 0

            while num > 0:
                digit = num % 10
                total += digit * digit
                num //= 10

            return total

        slow = n
        fast = next_number(n)

        while fast != 1 and slow != fast:
            slow = next_number(slow)
            fast = next_number(next_number(fast))

        return fast == 1
8. Time and Space Complexity Analysis (Optimized)
Time: O(log n) — bounded digit states Space: O(1)
9. Pattern / Key Takeaway

Pattern — Repeated value transformation → cycle or termination → Floyd's Cycle Detection (same family as LC 141)

#LC 66 • 11. Math & Geometry

Plus One

Easy LeetCode
1. Problem Statement

Given a large integer represented as a digit array, increment it by one and return the result as a digit array.

2. Understanding & Key Observations

Incrementing from right-to-left naturally handles carry propagation. The only edge case: if all digits are 9, every digit becomes 0 and a new leading 1 must be prepended.

3. Naive Solution — Brute Force

Reconstruct the integer, add 1, convert back to a digit array.

Naive Solution (Python 3) 
class Solution:
    def plusOne(self, digits):
        number = 0

        for digit in digits:
            number = number * 10 + digit

        number += 1

        return [int(d) for d in str(number)]
4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(n)
5. Intuition — For Optimization

Walk right-to-left. If the digit is < 9: increment it and return immediately (carry stops). If it is 9: set it to 0 and continue (carry propagates). If we exhaust the array, prepend a 1.

6. Approach — Step-by-Step Algorithm
  1. Iterate i from len(digits)-1 down to 0.
  2. If digits[i] < 9: increment and return digits.
  3. Else: set digits[i] = 0, continue.
  4. After the loop (all 9s case): return [1] + digits.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def plusOne(self, digits):
        for i in range(len(digits) - 1, -1, -1):
            if digits[i] < 9:
                digits[i] += 1
                return digits

            digits[i] = 0

        return [1] + digits
8. Time and Space Complexity Analysis (Optimized)
Time: O(n) Space: O(1) auxiliary
9. Pattern / Key Takeaway

Pattern — Right-to-left carry propagation — stop as soon as carry disappears

#LC 50 • 11. Math & Geometry

Pow(x, n)

Medium LeetCode
1. Problem Statement

Implement pow(x, n) — raise x to the power n. n may be negative.

2. Understanding & Key Observations

Multiplying x by itself n times is O(n). Binary exponentiation observes that x^n = (x²)^(n/2), halving the exponent each step — this gives O(log n).

3. Naive Solution — Brute Force

Multiply x by itself n times in a loop.

Naive Solution (Python 3) 
class Solution:
    def myPow(self, x, n):
        if n < 0:
            x = 1 / x
            n = -n

        result = 1

        for _ in range(n):
            result *= x

        return result
4. Time & Space Complexity Analysis (Naive)
Time: O(n) Space: O(1)
5. Intuition — For Optimization

If n is even: x^n = (x²)^(n//2) — square x and halve n. If n is odd: multiply the current x into result first, then halve. Negative n → invert x.

6. Approach — Step-by-Step Algorithm
  1. If n < 0: set x = 1/x, n = -n.
  2. Initialize result = 1.
  3. While n > 0: if n % 2 == 1, multiply result *= x.
  4. Square: x *= x; halve: n //= 2.
  5. Return result.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def myPow(self, x, n):
        if n < 0:
            x = 1 / x
            n = -n

        result = 1

        while n:
            if n % 2 == 1:
                result *= x

            x *= x
            n //= 2

        return result
8. Time and Space Complexity Analysis (Optimized)
Time: O(log n) Space: O(1)
9. Pattern / Key Takeaway

Pattern — Binary Exponentiation — halve the exponent at each step by squaring the base

#LC 43 • 11. Math & Geometry

Multiply Strings

Medium LeetCode
1. Problem Statement

Given two non-negative integers as strings, return their product as a string. You may not convert them to integers directly.

2. Understanding & Key Observations

Digit i of num1 multiplied by digit j of num2 contributes to position i+j+1 in the result array (of size n+m). Propagate carry leftward to position i+j.

3. Naive Solution — Brute Force

Convert both strings to integers, multiply, return the result as a string. (Violates the problem constraint but useful baseline.)

Naive Solution (Python 3) 
class Solution:
    def multiply(self, num1, num2):
        return str(int(num1) * int(num2))
4. Time & Space Complexity Analysis (Naive)
Time: O(n + m) Space: O(n + m)
5. Intuition — For Optimization

Simulate elementary-school long multiplication. Use a result array of size n+m. For each pair of digits at indices (i, j), add their product to result[i+j+1] and propagate the carry to result[i+j]. Strip leading zeros at the end.

6. Approach — Step-by-Step Algorithm
  1. Return '0' if either input is '0'.
  2. Allocate result = [0] * (n + m).
  3. Nested loops i from n-1 to 0, j from m-1 to 0.
  4. product = int(num1[i]) * int(num2[j]); add to result[i+j+1].
  5. Carry: result[i+j] += result[i+j+1] // 10; result[i+j+1] %= 10.
  6. Strip leading zeros and join digits into a string.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
class Solution:
    def multiply(self, num1, num2):
        if num1 == "0" or num2 == "0":
            return "0"

        n = len(num1)
        m = len(num2)
        result = [0] * (n + m)

        for i in range(n - 1, -1, -1):
            for j in range(m - 1, -1, -1):
                product = int(num1[i]) * int(num2[j])
                pos = i + j + 1

                result[pos] += product
                result[pos - 1] += result[pos] // 10
                result[pos] %= 10

        # Strip leading zeros
        start = 0
        while start < len(result) - 1 and result[start] == 0:
            start += 1

        return "".join(str(d) for d in result[start:])
8. Time and Space Complexity Analysis (Optimized)
Time: O(n × m) Space: O(n + m)
9. Pattern / Key Takeaway

Pattern — String arithmetic — position array: digit[i] × digit[j] maps to index i+j+1, carry propagates to i+j

#LC 2013 • 11. Math & Geometry

Detect Squares

Medium LeetCode
1. Problem Statement

Design a data structure that supports add(point) and count(point). For count, return the number of axis-aligned squares that can be formed using the query point as one corner.

2. Understanding & Key Observations

For a query point (x, y) and a diagonal point (x2, y2) to form an axis-aligned square: |x2-x| == |y2-y| (non-zero). The other two corners are then (x2, y) and (x, y2). Count = product of frequencies of all three non-query corners.

3. Naive Solution — Brute Force

Store all points in a list; for each count query, scan all pairs and check the square condition.

Naive Solution (Python 3) 
from collections import Counter

class DetectSquares:

    def __init__(self):
        self.points = Counter()

    def add(self, point):
        self.points[tuple(point)] += 1

    def count(self, point):
        x, y = point
        answer = 0

        for (x2, y2), cnt_diag in self.points.items():
            if x2 == x or y2 == y:
                continue

            if abs(x2 - x) != abs(y2 - y):
                continue

            answer += (
                cnt_diag
                * self.points[(x2, y)]
                * self.points[(x, y2)]
            )

        return answer
4. Time & Space Complexity Analysis (Naive)
add: O(1), count: O(P) — P = distinct points Space: O(P)
5. Intuition — For Optimization

Group points by their x-coordinate. For each unique x2 ≠ x, the diagonal candidate's y value must be exactly y ± side where side = |x2 - x|. Only two candidate y2 values need checking — constant per x2.

6. Approach — Step-by-Step Algorithm
  1. Store self.points = defaultdict(Counter) where self.points[x][y] = frequency.
  2. add(x, y): self.points[x][y] += 1.
  3. count(x, y): iterate over all distinct x2 in self.points (skip x2 == x).
  4. side = abs(x2 - x). Check y2 ∈ {y + side, y - side}.
  5. For each valid y2: answer += points[x2][y2] × points[x][y2] × points[x2][y].
  6. Return answer.
7. Optimized Code (Python 3)
Optimized Solution (Python 3) 
from collections import defaultdict, Counter

class DetectSquares:

    def __init__(self):
        # points[x][y] = frequency
        self.points = defaultdict(Counter)

    def add(self, point):
        x, y = point
        self.points[x][y] += 1

    def count(self, point):
        x, y = point
        answer = 0

        for x2, ys in self.points.items():
            if x2 == x:
                continue

            side = abs(x2 - x)

            # Two possible diagonal y-coords
            for y2 in (y + side, y - side):
                if y2 not in ys:
                    continue

                cnt_diag   = ys[y2]           # (x2, y2)
                cnt_corner = self.points[x][y2] # (x,  y2)
                cnt_base   = self.points[x2][y] # (x2, y )

                answer += cnt_diag * cnt_corner * cnt_base

        return answer
8. Time and Space Complexity Analysis (Optimized)
add: O(1), count: O(distinct x-coords) Space: O(P)
9. Pattern / Key Takeaway

Pattern — Coordinate frequency map — axis-aligned square: |Δx| == |Δy|; count = product of three corner frequencies

Group 1 — Matrix

Four boundary variables: top, bottom, left, right. Process outermost ring in four sweeps (→↓←↑), then shrink each boundary inward.

Zeroes (LC 73)

Repurpose matrix[r][0] and matrix[0][c] as zero-markers. Pre-check the first row and column before overwriting them.

Group 2 — Number / Math

Happy Number (LC 202)

Digit-sum-of-squares = value transformation. Converges to 1 or cycles. Floyd slow/fast pointers — same as LC 141 Linked List Cycle.

Plus One (LC 66)

Right-to-left carry: digit < 9 → increment and stop. digit == 9 → set 0 and carry left. All 9s? Prepend [1].

Pow(x, n) (LC 50)

Binary Exponentiation: if n is odd, absorb one x into result; then square x and halve n. O(n) → O(log n). Fundamental technique beyond LC.

Multiply Strings (LC 43)

Digit at index i of num1 × digit at j of num2 → position i+j+1. Carry propagates to i+j. Strip leading zeros at end.

Group 3 — Geometry
